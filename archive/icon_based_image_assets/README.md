# Archived icon-based image asset work

This archive preserves the former at-icons image asset direction, its production rules, documentation, scripts, and experiment manifests. It is historical material, not the current image production standard. The replacement image asset basis has not been selected yet.

Previously created image files remain in their original locations with their contents unchanged. This includes the SVG/PNG/JPG files in `assets/shared_art_study/` and the Rule Rewrite art files in `modules/rule_rewriting/art/`. Their `.import` sidecars remain alongside them.

## Archive contents

- `rules/legacy_at_icons_production_rules.md` — preserved production rules and historical Kit-specific art requirements.
- `docs/AT_ICONS_INKSCAPE_WORKFLOW.md` — the detailed Inkscape assembly workflow.
- `assets/shared_art_study/` — non-image study documents, manifests, license copy, and generator.
- `modules/rule_rewriting/art/` — art README and SVG/PNG generation scripts; the already created images remain in the project.
- `tools/` — candidate checker and Inkscape symbol setup script.

The experiment outputs remain under `assets/shared_art_study/` so existing image paths do not change. This archive contains no replacement art base and does not authorize new image creation.
