# at-icons 조합 방식 실험

이 문서는 `assets/shared_art_study/`에서 옮긴 과거 실험 기록이다. 기존 산출 이미지들은 [`assets/shared_art_study/`](../../../../assets/shared_art_study/)에 원래 위치와 내용 그대로 남아 있다. 현재 제작 기준으로 사용하지 않는다.

기록된 당시 규칙은 [Inkscape 조립 워크플로](../../docs/AT_ICONS_INKSCAPE_WORKFLOW.md)와 [A·B 레퍼런스의 적용 범위](../../../../docs/research/visual_reference/STYLE_AND_CAMERA_REFERENCE.md)에 남아 있다.

당시 `assets/shared_art_study/`에 있던 옛 격자 보드, 후보, manifest, 생성 콘셉트, 아트 생성 코드와 `adaptive_retest/`의 나무 SVG·크기별 PNG는 모두 **무효한 실험 산출물**이다. 이미지 파일만 원래 위치에 보존하고 새 작업의 시작 자료, 평가 근거, 완성 증거로 사용하지 않는다. 특히 `candidate_tree.svg`라는 이름은 후보 승인을 뜻하지 않는다.

새 실험은 빈 Inkscape 문서에서 실제 at-icons 심볼을 순차적으로 조립한다. 원본 픽토그램 의미의 직접 재사용과 자르기·크롭·클리핑·마스킹을 금지한다. 실패한 형상을 색이나 크기만 바꾸며 반복하지 않고, 실루엣을 만드는 다른 조합을 시험한다.

원본은 `res://addons/at-icons/node2d/`의 618개 SVG였다. [Inkscape 심볼 보관본](../../../../assets/shared_art_study/inkscape_symbols/tin-at-icons-node2d.svg)과 [라이선스](AT_ICONS_LICENSE.txt)를 보존한다.
