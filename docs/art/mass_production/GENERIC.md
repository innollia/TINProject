## 다른 컴퓨터와 git
- 저장소: `C:\projects\TINProject`, 브랜치 `kit/05-stone-story-rpg`, 원격 `origin`.
- 시작할 때: 지금 브랜치가 `kit/05-stone-story-rpg`인지 확인하고 `git pull --no-rebase origin kit/05-stone-story-rpg`로 최신을 받는다. 이 파일과 COMMON.md, `assets\art\top_down_action_rpg\jobs\h0-icon-mood-v02\tool`이 있는지 확인한다.

- 올리기: 단계(A, B, C)가 끝날 때마다 자기 파일만 커밋하고 올린다.
  1. `git add -- <자기 작업 폴더들> <자기 목록 파일>`
  2. `git commit -m "art(gNN): <묶음> <단계> 완료" -- <같은 경로들>` (경로를 꼭 붙인다. 같은 저장소를 쓰는 다른 세션의 파일이 섞여 들어가지 않게 한다.)
  3. `git pull --no-rebase origin kit/05-stone-story-rpg` 후 `git push origin kit/05-stone-story-rpg`
- 다른 세션과 동시에 git을 쓰다가 `index.lock` 오류가 나면 30초 기다렸다 다시 한다. push가 거절되면 다시 pull한 뒤 push한다. 충돌이 나면 고치지 말고 멈춰서 알린다. 강제 push, reset, 다른 세션 파일의 add는 하지 않는다.
