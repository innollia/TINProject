# 개인 화풍 코어

버전: `0.1`
갱신: 2026-09-26
범위: TINProject 이미지 자산의 공통 렌더 문법. 캐릭터 정체성, 세계관, 의상, 구체 색은 프로젝트 아트 층이 정한다.

## 구조와 명암

- 주변 면보다 매우 어두운 유색 구조선. 굵기 변화로 얼굴·의상 구조를 읽힌다.
- 얼굴 중앙은 고정된 코선을 복제하지 않고 인물별 안면 능선으로 큰 면을 조직한다.
- 얼굴은 기본색, 주 그림자, 작은 밝은 면의 3단 구조다. 면 내부에는 제한된 붓질을 허용한다.
- 큰 일러스트의 형태 관계를 보존하며 작은 스프라이트에서는 구조선과 명암 단계를 줄인다.

## 색과 재질

- 넓은 면은 낮은 채도, 정체성색 1–2개는 중간 채도, 초점의 높은 채도는 작은 면적으로 사용한다.
- 피부, 천, 금속, 목재, 종이는 서로 다른 내부 붓결과 반사를 가진다. 모든 재질에 같은 질감 필터를 덮지 않는다.
- 피부는 매트한 큰 면, 머리카락은 방향이 읽히는 덩어리, 천은 접힘의 힘 방향, 금속은 좁고 끊긴 반사를 기본으로 한다.
- UI의 넓은 정보면은 내부 브러시 채움을 쓸 수 있다. 글자와 작은 아이콘은 깨끗하게 유지한다.

## 자산 크기별 번역

- 캐릭터판과 큰 일러스트: 얼굴·손·재질의 내부 붓질을 읽을 수 있게 한다.
- 게임플레이 스프라이트: 비율과 색 관계를 유지하고 구조선 수, 명암, 붓질을 줄인다.
- UI: 정보 우선순위를 유지하며 큰 면만 질감을 사용한다.

## A/B Style Reference의 역할

- `docs/research/visual_reference/user_style_A.png`: 얼굴 명암 면, 피부·큰 색면의 내부 붓결, 머리카락 덩어리의 회화적 밝기 변화를 참고한다.
- `docs/research/visual_reference/user_style_B.png`: 구조선 강약, 의상 구조, 실루엣 정리, 인물·배경 밀도 대비, 배경 덩어리의 콜라주성을 참고한다.
- 두 이미지의 인물 얼굴형, 헤어스타일, 의상, 장식, 포즈, 구체 모티프와 정확한 색 조합은 가져오지 않는다.

## 금지

- 모든 얼굴에 동일한 안면선과 눈을 반복하지 않는다.
- 모든 표면을 플라스틱 광택이나 동일 브러시로 만들지 않는다.
- 자동적인 기괴함, 무작위 장식, 과한 bloom·bokeh, 무의미한 텍스트를 넣지 않는다.
