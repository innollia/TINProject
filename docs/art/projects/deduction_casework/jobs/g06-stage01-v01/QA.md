## read 도구로 직접 본 것

1. 인물 1차(서 있는 미라): 머리가 작고 다리가 길고 가운 얼룩이 짙었다 → 머리 비율 1/4.8, 엉덩이 높이 0.465, 가운 얼룩 0.25→0.12, 명암 경계 0.42로 고침. 3/4 시점의 가까운 쪽이 반대로 잡혀 은핀이 오른귀에 붙던 문제를 뼈대에서 바로잡음.
2. 주실험실 배경 1차: 벽 위쪽이 모자라 오른쪽 위에 빈 삼각형, 판벽이 너무 밝음, 바닥·벽 얼룩이 같은 크기로 반복 → 벽 높이 5.2m, 판벽 색 낮춤, 얼룩을 크고 드물게(밀도 0.28→0.08, 크기 70→120~150).
3. 사물함 문 얼룩이 위장무늬처럼 촘촘 → 크고 드문 녹 얼룩으로.
4. 과제보드 확대: 자석이 검은 재질 명암을 받아 반쪽이 새까맸다 → 자석 색별 재질(magnet_red/blue/yellow/green) 추가. CCTV 프레임의 보드도 같은 배열·모양으로 다시 그림.
5. 스케치 두 장: 스프링이 쪽 가운데에 있었고 종이 얼룩이 많았다 → 스프링을 위쪽으로, 확대 종이 얼룩을 약하게.
6. EEG 선반의 전선이 과녁(spiral 아이콘)으로 읽힘 → 늘어진 고리 두 개로 교체.
7. 배경+물건 확인용 4장: 실험대·자극 책상·프린터·보드·시계·응급상자·거즈·소독약병이 쿼터뷰 방 안에서 서로 맞는 크기로 보임. 관찰부스는 벽이 넓어 의자와 EEG 선반을 더함.
