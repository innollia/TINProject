# g06-stage02-v01 QA

전부 candidate. 사람을 배경 위에 합친 그림은 만들지 않았다(가족사진 속 인물은 사진이라는 물건의 내용).

## read 도구로 직접 본 것

1. 배경+물건 5장: 현관(대리석 체크·조문 물건·신발 줄), 식당(여섯 의자·Guest 자리), 서재(책장·열린 금고·소파·책상), 하인구역(종 판·열쇠판·책상), 묘지(비·담·묘비·발자국·집 외벽) 모두 크기·자리 관계가 맞게 읽힘.
2. 1차에서 고친 것: 현관 문짝·우산꽂이가 너무 밝음 → 문짝 한 단계 어둡게, 우산꽂이 금속색. 밤 외벽이 밝은 회색 판자처럼 보임 → 어두운 석벽색. 실라의 치마 재질이 빠져 회색 판처럼 나옴 → `skirt_dark` 추가, 앉은 자세에서는 치마가 허벅지를 따라가게 도구 수정.
3. 가족사진 3장: 세피아 인화지 안에 인물 2~4명, 결혼식·가족 단체 구분됨.
4. 금고 빈 칸(70px)과 보존커버 등 두께(70px)가 같은 치수로 그려짐. 끈 눌림 두 줄씩.

## 아쉬운 점

- 쿼터뷰 현관에 정면 그림 신발 줄을 놓아 원근이 조금 어긋난다.
- 젖은 외투(옷걸이·Guest 의자)가 검은 판처럼 단순하다.
- 쓰러진 실라는 팔다리가 막대라 늘어진 느낌이 약하다.
- 식탁보가 큰 사각 덩어리로 보인다.
