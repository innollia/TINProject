# 중세 콜라주 은행 — 완성 오브젝트 300개 계획

## 목표와 집계 단위

목표는 **서로 구분되는 게임용 오브젝트 300개**다. 관절별 PNG 300장이나 원화 조각 300장이 아니다. 한 오브젝트는 게임에서 한 개체로 배치·장착·상호작용할 수 있는 완성된 결과물이다. 사람·동물·괴물은 머리부터 발끝까지 조립된 개체 하나를 1개로 센다. 검·방패·가구·나무·건물처럼 독립적으로 배치하거나 장착하는 물건도 각각 완성되면 1개다. 배경 전체를 한 장으로 만든 장면은 이 목표에 넣지 않는다.

파츠 수, 이미지젠 호출 수, 원화 수, GIF 수, 포즈·방향 수, 같은 오브젝트의 색·날개·장비 변형 수는 오브젝트 수가 아니다. 같은 기사에 날개를 붙였다 떼거나 방패 그림을 바꿔도 기사 1개다. 검이나 방패는 기사와 별도로 사용 가능한 독립 오브젝트로 완성한 경우에만 각각 1개로 셀 수 있다. 단순 재색칠·좌우 반전·크기 변경은 새 오브젝트가 아니다. 한 장의 이미지젠 시트에서 열 조각을 잘라도 0개 또는 그 조각들로 **완성한 개체 수**만 센다.

현재의 과거 수치 `22/300`(기사의 팔다리·무기·날개)와 `56/300`(v06 분리 PNG)은 **잘못된 집계이므로 폐기**한다. 파일은 보존한다. 현 시점에 v05 기사에는 조립 미리보기 1종이 있고, v06에는 말·용·용병의 미조립 파츠와 독립 오브젝트가 될 소품·풍경 후보가 있다. 이 자료만으로 300개 목표의 완료 수를 올리지 않는다. v02–v04의 기존 결과도 삭제하지 않고 아래 기준으로 개별 감사한 뒤 등록한다.

## 오브젝트 완료 조건

각 오브젝트는 `OBJECT_REGISTER.md`에 고유 ID 한 행을 갖는다. `후보`는 작업 상태이며 `완료`와 다르다. 다음을 모두 충족할 때만 **제작 완료 후보 1개**로 센다.

1. 다른 등록 오브젝트와 실루엣·구조·용도 중 적어도 하나가 실질적으로 다른 독립 개체다. 단순 상태·장비·색 변형을 새 ID로 쪼개지 않는다.
2. 실제 투명 RGBA 오브젝트 원본과 필요한 조립 파츠가 있으며, 사용한 역사 원화의 출처·라이선스와 이미지젠 원본이 남아 있다.
3. 전체가 조립된 게임 표시 크기 미리보기와 배치·장착 피벗이 있다. 사람·동물·괴물은 끊긴 관절이나 빠진 신체가 없어야 한다. 분리 소품은 손잡이 또는 설치 지점이 정해져야 한다.
4. 사용에 필요한 상태가 구현돼 있다. 이동 개체는 정지·이동과 계획된 핵심 행동을 연속 프레임 또는 실제 장면으로 제시한다. 문·용기·장치는 열림/닫힘 등 계획한 상태가 있어야 한다. 정적 바위·나무는 불필요한 애니메이션을 억지로 만들지 않는다.
5. 실제 게임 화면 크기에서 콜라주라는 점이 읽히고, 단일 그림 한 폭처럼 보이거나 이음새가 구멍으로 벌어지지 않는다. 사용 장면을 직접 확인하지 못했다면 `검수 대기`로 기록한다.

사용자의 Gold Standard 승인 수는 별도로 기록한다. 제작 완료 후보와 사용자 승인본을 섞어 보고하지 않는다. 원본을 보존하고 기계적 투명화·크롭·피벗 정렬만 파생 처리하며, 실패한 그림은 이미지젠 국소 편집 또는 재생성으로 되돌린다.

## 제작 순서

1. `OBJECT_REGISTER.md`에 만들 오브젝트의 이름과 구별점을 먼저 적는다. 기존 v02–v06 결과는 파일을 보존한 채 독립 개체로 조립·배치 가능한지 감사한다. 등록되지 않은 파츠 더미를 목표 숫자로 치지 않는다.
2. 이미지젠으로 역사 그림에서 인물·동물·괴물·장비·건물·나무·가구 등의 누끼 원본을 만든다. 사람과 동물은 필요한 관절 파츠를 같은 개체의 부속으로 생성한다. 원본은 `source_cutouts/`에 그대로 보관하고 개별 파생 PNG를 만든다. 우선 기존 54개 CC0 원화를 쓰고, 필요한 소재가 없을 때만 출처를 늘린다.
3. 인물·동물·괴물은 한 개체씩 전신 조립 후 `tools/proc_bake`와 게임 런타임의 동작을 확인한다. 몸의 끌림, 발 접지, 관절 연속성, 손과 장비의 결합을 연속 프레임에서 본다. 정적 오브젝트는 설치 피벗과 장면 배치를 확인한다.
4. 완성된 개체의 조립 그림·움직임·독립 파일·출처를 등록 행에 연결한다. 실패는 행에 남기고 보완한다. 비슷한 결과를 수만 채우려고 복제하지 않는다.
5. 사람, 동물·괴물, 장비·도구, 자연물·가구, 건물·장치가 모두 포함되도록 생산한다. 범주별 숫자는 사용자가 확정하지 않았으므로 임의 할당량을 사용자 결정으로 적지 않는다. 주기적으로 종류와 실루엣 편중을 확인한다.

## 보고 숫자
