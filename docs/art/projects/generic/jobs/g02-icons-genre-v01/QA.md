# g02-icons-genre-v01 QA

전부 candidate. 승인·반려는 사용자만 한다.

## 확인한 것 (read 도구로 시트를 직접 봄)

- A: 모아 보기 시트로 가장자리 잘림·조각 어긋남을 확인했다.
- 총은 수평으로 만든 뒤 통째로 비스듬히 돌려 부품이 어긋나지 않게 했다.
- 16칸 시트는 목록 순서로 칸 번호가 고정이고, 아직 없는 아이콘 칸은 비워 둔다.
- B: 통조림의 찌그러짐이 물린 자국처럼 보여, 보물 지도 위쪽 말린 부분이 세로 막대로 나와 각각 한 번 고침.
- C: 단분자 칼의 빛나는 날이 128px에서 가늘다. 태엽 열쇠 손잡이가 고리 두 개처럼 보인다(고치지 않음).
