# g07-devices-v01 QA

전부 candidate. 승인·반려는 사용자만 한다.

## A 단계 확인 (read 도구로 직접 봄)
- 빌드 전 계산으로 두 가지를 바로잡음: 개찰구 회전 팔이 너무 낮았음(허리 높이 0.85 m로 올림), 등대 렌즈 놋쇠 띠가 렌즈 아래로 벗어나 있었음(렌즈 몸통 높이에 맞춤).
- `preview\review_A1_devices.png`: 교환대(쉼·통화 중), 무전 책상(꺼짐·켜짐), 분류 선반(빔·가득), 엑스선 검색대(꺼짐·켜짐). 고칠 것 없음.
- `preview\review_A2_devices.png`: 개찰구(잠김·열림), 등대 렌즈(꺼짐·켜짐), 해치(닫힘·열림), 금전 등록기(닫힘·열림), 증거 게시판(빈 판·핀과 실). 고칠 것 없음.

## B 단계 확인
- 빌드 전 계산으로 바로잡음: 종 부표 갑판·틀·종 높이(부표 윗면에 맞춤), 잠망경 바닥 구멍 위치, 진열장 펠트·유리틀 위치.
- `preview\review_B1_devices.png`, `review_B2_devices.png`.
  - 고침 1: 검문 부스 지붕이 커다란 민판으로 보였다 → 이음선, 앞 테, 환기구, 경광등을 얹음. 무적 나팔이 확성기 아이콘을 잘라 붙인 어색한 모양이었다 → 삼각형 원뿔 + 입구 테·검은 입구로 다시 조립(`review_B3_devices_fix.png`).
  - 가장자리 검사에서 잘림: 사물함 열린 문(고침 1: 안쪽으로 옮기고 기울기 줄임), 밸브 배관 윗끝(고침 1: 플랜지를 달아 캔버스 안에서 끝냄, 고침 2: 캔버스 높이 256). 다시 검사해 0.
- 잠망경 기둥이 캔버스 위로 나가는 것은 천장으로 이어지는 모습이라 일부러 둔 것이다.

## 아쉬운 점
- 엑스선 검색대 윗면이 넓은 베이지 판이라 조금 밋밋하다.
- 개찰구 삼발 팔은 옆면이 보이지 않는 시점이라 몸통 오른쪽 가장자리에 붙은 것처럼 보인다.
