## 확인한 것 (read 도구로 직접 봄, 자산당 수정 최대 2번)
- A: A 9개 시트(sheet_A_1)를 직접 봄. 1차 수정 5개: 마른 나무 잔가지(번개 모양이 그대로 읽힘 → 갈라진 가지 막대), 전나무 층 가장자리(삼각형 톱니 → 뾰족한 풀잎 끝), 참나무(꼭대기 외톨이 잎 제거, 가장자리 작은 잎 덩이 추가), 풀 무더기(새싹 아이콘이 읽힘 → 풀잎만), 큰 바위(오른쪽 어두운 면 추가). 나머지 4개는 1회로 통과.
- B: B 6개 시트(sheet_B_1)를 직접 봄. 1차 수정 3개: 저주받은 나무(가지 끝 소용돌이 아이콘이 그대로 읽힘 → 굽은 가지, 구름 모양 잎 → 늘어진 누더기 잎), 대나무(잎맥 있는 잎 아이콘 → 가는 창 모양 잎), 선인장(팔이 몸통과 떨어져 보임 → 연결부를 몸통 안까지). 그루터기·과일 나무·야자수는 1회로 통과.
- C: C 5개 시트(sheet_C_1)를 직접 봄. 수정: 벚나무(떨어진 꽃잎이 윤곽선 때문에 검은 점처럼 보임 → 윤곽선 없는 납작한 꽃잎). 갈대·작은 돌 무더기·폭포 바위·수정 바위는 1회로 통과.

## 아쉬운 점
- 참나무 수관은 아직 둥근 구름 덩이에 가깝다(잎 덩이 윤곽이 매끈함).
- 풀·꽃처럼 작은 것은 V1 윤곽선 두께 그대로라 선이 두껍게 보인다.
- 야자수 줄기 마디가 관을 이어 붙인 것처럼 딱딱하다.
- 작은 폭포는 정지 그림이라 물 흐름 애니메이션이 없다.
