# g05-fantasy-v01 QA

전부 candidate. 승인·반려는 사용자만 한다.

## 확인한 것 (read 도구로 직접 봄)

- A 15종 45장: 5~6종마다 모아 보기 시트를 보고 고쳤다. 최종 시트 `preview\review_A_fantasy_1.png`, `preview\review_A_fantasy_2.png`.
- `tool\check_edges.py`: 모든 그림·그림자·발광 레이어가 가장자리에서 잘리지 않음(통과).
- 고친 것(자산당 2번 이하):
  - 고블린: 몸통이 방패 모양으로 읽혀 배불뚝이 몸통으로 바꾸고 목을 넣음. 입이 한쪽으로 치우친 초승달이라 대칭 입으로 바꿈. 공격 팔을 따로 그림(단검을 머리 위로).
  - 오크·골렘: 공격 무기·주먹이 위쪽에서 잘려 낮춤. 피격 때 오른쪽이 잘려 흔들림을 줄임.
  - 트롤·미노타우로스: 몽둥이·망치가 바닥을 뚫어 어깨에 걸치거나 바닥에 짚는 자세로 바꿈.
  - 미믹: 기본 자세에서 평범한 상자로 보여 뚜껑을 살짝 열어 이빨과 눈이 보이게 함.
  - 골렘: 바위 아이콘의 틈으로 뒤가 비쳐 어두운 채움을 뒤에 깔아 금처럼 보이게 함.
  - 리자드맨: 방패 테 아이콘(반지)이 입체 고리로 보여 평평한 테로 바꿈.
  - 하피: 피격 때 날개가 좌우 가장자리에서 잘려 날개를 조금 줄이고 기울기를 줄임.
  - 그림자: 흐린 그림자 아래쪽이 캔버스에서 잘려 자동으로 안으로 올리게 함.

## 아쉬운 점

- 붓자국 무늬(명암 경계의 얼룩)가 큰 면에서 위장 무늬처럼 보인다. V1 설정 그대로라 세션마다 바꾸지 않았다(COMMON.md).
- 미노타우로스 얼굴은 소보다 곰처럼 읽힐 때가 있다. 뿔과 코뚜레로 구분된다.
- 그리폰 날개는 새 날개 아이콘 하나를 키운 것이라 깃털 결이 단순하다.
- 불 정령 몸 전체가 발광 레이어(`_emit.png`)에도 들어가 있다. 게임 조명에서 너무 밝으면 발광 세기를 낮춰 쓰면 된다.
