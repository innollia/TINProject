# g05 목록 — 모든 장르의 생물(사람이 아닌 것 전부)

세션 g05(범용 에셋). 규칙: `docs\art\mass_production\COMMON.md` + `GENERIC.md`. 결과는 전부 candidate이고 승인은 사용자만 한다. 아이콘 조합으로만 만든다.

- 합계 146개: A 42 / B 43 / C 61.
- 2026-09-27 마무리(사용자 지시: 전체 이미지가 목표 3000장을 넘음, 새 자산 시작 금지): 완료 138개(A 42·B 43·C 53), 건너뜀 8개(g05-genre-v01의 C 8개).
- 장르별 개수: 중세 판타지 47, 다크 판타지·고딕 32, 동양 판타지 14, 현대·도시 8, 호러·오컬트 7, SF·우주 4, 사이버펑크 4, 스팀펑크 4, 포스트아포칼립스 4, 해적·바다 14, 서부 8. 판타지 계열(93개)이 가장 두껍다.
- 사람(인간)은 g02 담당이라 넣지 않았다. 고블린·오크·수인·흡혈귀·유령·해골 병사·안드로이드·로봇처럼 사람이 아닌 것은 전부 여기 있다.
- BS2 목록(`g01_bs2_inventory.md`)의 g05 몫 83종은 전부 넣었고 비고에 BS2라고 적었다(묶어서 한 항목으로 만든 것은 비고에 함께 적음).
- 생물의 공격 효과(불꽃, 번개, 피격 섬광)는 g01·g02 담당이라 그리지 않는다. 공격·피격은 자세로만 보여 준다.
