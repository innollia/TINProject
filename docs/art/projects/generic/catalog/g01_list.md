# g01 목록 — 판타지 계열·장르 없는 아이콘, UI, 효과, 겹침 무늬

2026-09-27 g01 세션(KiroCrew 서브에이전트). 전부 candidate이고 승인은 사용자만 한다. 그림은 at-icons 모양을 잘라 겹친 조합으로만 만들고, 글자·숫자·워터마크는 넣지 않는다(느낌표·물음표·음표 같은 기호는 도형으로 조립).

- BS2 보강: 이 컴퓨터에는 BLACK SOULS II가 없다(Steam 라이브러리, C·D 드라이브의 게임·사용자 폴더를 찾아봄). 그래서 `g01_bs2_inventory.md`는 그대로 두고, 그 파일의 g01 몫을 이 목록에 전부 옮겼다(비고 칸의 BS2).
- 장르: 공통 = 장르 없음(어느 판타지에나 쓰는 기본형), 중세 = 중세 판타지, 다크 = 다크 판타지·고딕, 동양 = 동양 판타지.
- 작업 폴더: `assets\art\generic\jobs\g01-icons-v01`, `g01-ui-v01`, `g01-fx-v01`, `g01-overlays-v01` (+ 같은 이름의 `docs\art\projects\generic\jobs\...`).
- 형식 줄임말: 아이콘 = 128×128 한 장 + 한 줄 16개 시트 / 9칸 = 글자 없는 9-slice 한 장(여백 px는 manifest `meta.nine_slice`) / 5프레임 = 칸 5개를 한 줄로 이은 시트 + 칸별 PNG / 이음 = 가장자리가 이어지는 반복 무늬.
- 상태: 대기 / 완료 / 건너뜀.
