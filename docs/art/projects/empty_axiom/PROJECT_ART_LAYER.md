# 《빈 공리》 프로젝트 아트 층

프로젝트 ID: `empty_axiom`
적용 코어: `docs/art/PERSONAL_STYLE_CORE.md` 버전 `0.3`
범위: Golden Idol 형식의 《빈 공리》 인물·공간·소품 이미지.

## 세계와 정서

- 근현대 아날로그 연구·행정·생활 공간. 목재, 금속, 베이클라이트풍 플라스틱, 두꺼운 종이, 천, 유리의 사용감이 이어진다.
- 장면은 정돈된 시설 속 절차가 어긋난 흔적을 보여 준다. 과도한 공포 장식이나 미래형 화면을 추가하지 않는다.
- 색은 프로젝트 비주얼 바이블의 관계형 팔레트를 따른다. 넓은 면은 저채도이고 인물 식별색과 실제 단서만 작은 면적으로 강조한다.
- 주광원 하나를 기준으로 얼굴·손·핵심 물건의 대비를 조절한다.

## 정체성과 화면

- 인물·의상·소품은 `docs/golden_idol_story/`의 Stage 정본과 13A·13A-4가 소유한다.
- 장소·카메라·물리 단서는 같은 폴더의 13B·13E·13F·13G가 소유한다.
- 캐릭터판은 인물 정체성 확인용 한 장이다. 사건 장면으로 확대하지 않는다.
- 조사 화면은 원경 구조, 중경 생활·직업 물건, 근경 비교 단서가 연결되어야 한다.
- Primary Reference의 조사 화면·정보 비교 문법은 따르되 원작의 캐릭터, 고유 자산, 문구, 배치를 복제하지 않는다.

## 형태와 UI

- 비정상 신체를 프로젝트 전역에 자동 적용하지 않는다. 사건 정본이 요구하는 상태만 표현한다.
- 문서와 기계 라벨은 세계 안의 물리적 매체로 취급한다. 생성 이미지에 정확한 문자·숫자를 맡기는 경우 자산별 brief가 검증 방법을 지정한다.

## 활성 자산군

- `character_plates`: 인물 동일성 검토용. 현재 승인된 Gold Standard는 없다. 후보는 사용자 검토 전까지 기준 이미지가 아니다.
- `investigation_characters`: 조사 장면에 합성할 투명 배경 인물. 인물 1명·사건 상태 1개·포즈 1개가 제작 단위다. 캐릭터판의 배경·확대 컷을 포함하지 않는다. 첫 대상은 [Stage 1 미라](asset_briefs/mira_ben_stage01_cutout.md)이며 렌즈집은 손에 든 상태로 확정했다. 카메라·배치 규격과 새 생성 경로를 준비한다.
