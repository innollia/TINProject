- 기획 정본: [Kit 04](../../../../plans/kits/04_TOP_DOWN_ACTION_RPG_KIT/README.md), [큰 배경 제작](../../../../plans/kits/04_TOP_DOWN_ACTION_RPG_KIT/13_LAYERED_ENVIRONMENT_PRODUCTION.md).
- 개인 화풍: [코어 v0.2](../../PERSONAL_STYLE_CORE.md). 환경에도 A의 큰 명암 면 분할과 형태·재질을 따르는 내부 붓결을 적용한다. B는 유색 구조선의 강약·끊김, 실루엣·밀도 계층과 배경 평면의 겹침을 담당한다. 얼굴이 없다는 이유로 A 전체를 제외하지 않는다. 얼굴 고유 구조만 인물 제작에 한정한다.
- 세계: The Undersign Basin. 회복·인정·권한을 다루는 유능하지만 서로 다른 분류를 쓰는 기관들. Alice, BLACK SOULS의 고유 지형·상징·인물 복제 금지.
- 공간은 제도의 실제 기능과 비용을 보여 준다. 무작위 눈·이빨·혈흔·기괴한 장식을 추가해 분위기를 대신하지 않는다.
- 카메라: 지면 기준 하향각 60°의 정사영 top-down(수직에서 30° 기울어짐), 방위 고정, world/UI 분리. 벽·가구 옆면을 허용하고 지면 깊이축 단축을 통일한다. BG는 장면 전체 그림+필요한 분리 레이어이며 tile grid에 구속되지 않는다.
- 활성 시험 자산군: environment_background. 독립 소품/가림 레이어는 이 가족의 샘플 구성으로 검수한다. 인물·전투 적·초상 제작을 이번 배경 샘플에 끼워 넣지 않는다.
- H0 샘플 재질/색 제안: 분필빛 회보라 광물성 바닥, 자주색에 가까운 짙은 구조선, 탁한 청동 기능 부품, 소량의 바랜 종이색. 공식 기획이 재질을 미리 정했다고 주장하지 않는다. 다른 region의 색을 이 샘플로 통일하지 않는다.
- 조명: 상부 확산광, 넓은 면의 값 분리, 국소 접촉 그림자. 스포트라이트/비네트로 통로를 가리지 않는다.
- UI: 기존 09의 어두운 contextual 면, native text·focus·bar. 배경에 글자·HUD·focus·대화창을 굽지 않는다.
- 샘플 brief: [H0 Arrival Well](asset_briefs/h0_layered_environment_pilot.md).
- 현재 생성기의 기존 화풍 실패 기록을 준수한다. '샘플'도 공통 생성기 게이트를 우회하지 않는다. 이번 H0 그림은 A 누락·일반 던전 렌더 수렴으로 반려됐다. 사용자 방향 검토 전 병렬 양산/approved 이동을 하지 않으며, 실패 후보를 화풍 기준으로 재사용하지 않는다.
