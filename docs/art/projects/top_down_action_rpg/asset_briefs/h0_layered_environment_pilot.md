# H0 Arrival Well 접근 구역 — 큰 배경 샘플

작성: 2026-09-26. 상태: 문서 고정 후 기준 합성본 시험. 이번 배치·재질은 검토용 미술 설계이며 기존 domain 데이터 변경을 뜻하지 않는다.

## 근거와 범위

[지역 기획 §7.1](../../../../../plans/kits/04_TOP_DOWN_ACTION_RPG_KIT/02_WORLD_STATE_AND_ROUTES.md)은 건조한 중앙 선반, 원형 Arrival Well, 네 방향 계단·tram·수로, Counterweight Map, 지하 return lift, 비어 있는 Crown Well을 명시한다. [제작 계약](../../../../../plans/kits/04_TOP_DOWN_ACTION_RPG_KIT/13_LAYERED_ENVIRONMENT_PRODUCTION.md)을 적용한다.

이 샘플은 H0 전체가 아니라 Arrival Well과 접수 공간을 연결하는 한 구역이다. 다른 구역의 Counterweight Map·Crown Well·전차·수로를 화면에 억지로 모두 넣지 않는다. H0의 5개 external route를 아래 3개의 화면 경계 통로로 대체하지 않는다.

## 출력과 시점

- ID: `h0_arrival_approach_pilot_v01`.
- 기준 canvas: 2560×1440, opaque PNG/sRGB, 목표 density 2px/world unit.
- 논리 구역: (0,0,1280,720). 아래 좌표는 제안 배치이며 실제 구현 manifest가 아니다.
- 정사영 60° top-down: 지면 기준 하향각 60°, 수직에서 30° 기울어짐. 방위 고정, 소실점/지평선 없음. 벽·가구의 옆면과 높이를 표현하며 배경·소품·배우의 투영을 통일한다.
- master는 합성 기준이며 runtime base로 중복 사용하지 않는다.
- 생성기가 목표보다 작은 크기를 반환하면 원본 크기를 기록하고 QHD 미충족으로 표시한다. 확대만으로 통과시키지 않는다.

사람·적·시체·눈·식물·왕관·혈흔·읽을 수 있는 글자는 없다. 인물 스케일을 확인할 검수 마커는 이후 별도 합성 preview에만 추가할 수 있다.

## 레이어 제작 예정

| 파일 역할 | 포함 | alpha/pivot |
|---|---|---|
| master_composite | 위 모든 요소가 제 위치에 있는 기준 그림 | opaque / canvas 원점 |
| base_clean | 고정 우물·바닥·벽. counter와 전경 보 및 소유 그림자 제거 후 뒤쪽 표면 복원 | opaque / master와 동일 canvas |
| prop_counter | 접수 counter와 그 위 빈 서식, 필요한 접촉 그림자 별도 | transparent / 접지 중심 (250,265)에 대응 |
| foreground_beam | 낮은 앞쪽 가림 구조 | transparent / 동일 원점 또는 crop origin 명시 |
| preview_reassembled | 위 레이어를 같은 좌표로 조립한 검수 이미지 | 납품 증거, runtime asset 아님 |

잘라낸 자리를 비우는 것으로 끝내지 않는다. 국소 편집 후 나머지 건축·우물 위치·바닥 특징이 이동하면 반려한다. 모든 파생 파일을 한 번에 제작하지 않고 master의 시점·길·재질을 먼저 검수한다.

## compact visual contract

1. 장면 전체를 한 번에 그린 큰 배경. atlas/grid/타일 이음 표시 없음.
2. A 원본의 큰 명암 면과 형태·재질별 방향성 내부 붓결, B 원본의 유색 구조선 압력·끊김과 밀도 계층을 역할별 적용한다. 인물·의상·눈·식물·정확한 색 복제 금지. 전 표면에 같은 질감 필터를 얹어 대체하지 않는다.
3. 마른 회보라 바닥, 짙은 자주 구조선, 탁한 청동 조인트. 다른 지역에 대한 확정 팔레트 아님.
4. 원형 Arrival Well을 오른쪽 위에, 접수 counter를 왼쪽에, 조용하고 넓은 남북 통로와 오른쪽 통로를 유지.
5. counter와 왼쪽 아래 가로보는 나중에 분리할 수 있게 실루엣을 명료하게. 그 뒤 바닥 복원은 후속 clean-base 편집으로 수행.
6. 인물·문자·UI·격자·원작 모티프·무작위 기괴 장식 금지.

## 샘플 검수와 중단

master에서 시점/동선/분리 대상/스케일/붓결을 먼저 판정한다. 하나라도 필수 기준을 놓치면 전체 양산을 시작하지 않는다. 현재 결과를 사용자 승인·실제 게임 해상도 검수·레이어 납품 완료로 세지 않는다.

후속 분리 때: 동일 캔버스 재합성, 물체 제거의 뒤쪽 표면, 밝은/어두운 바탕의 alpha, 그림자 잔상, 비대상 영역 drift를 확인한다. 실제 세 해상도·입력·충돌 검수는 통합 이후 별도다.

## 현재 제작 상태

기준 합성본 1개는 사용자 화풍 지적 후 반려했다. 실제 출력 1672×941이며 A 참조 누락·공통 생성기 게이트 우회·일반 렌더 수렴이 문제다. 카메라 목표는 사용자 정정으로 60°이며 기존 수직 명세와 그 기준의 시점 미달 판정은 철회한다. [검수 기록](h0_layered_environment_pilot_QA.md)에 파일·실제 과거 prompt·판정을 보존한다. 레이어 분리는 미실시. 실패한 기존 이미지를 후속 스타일 입력으로 사용하지 않는다.
