# h0-icon-collage-v01 — 검수 기록

2026-09-27. **판정: candidate. 사용자 검토 대기.** 에이전트 자체 검토 2회 후 멈춤. 승인·Gold Standard 승격 없음.

## 1. 예전 시도(archive/icon_based_image_assets)가 멈춘 이유

- 규칙이 너무 좁았다. 자르기·클리핑·마스킹이 금지였고, 2026-09 밀도 실험은 회전·미러·개별 크기 변경·겹침까지 막았다. 48 px 칸에 위치와 색만 바꿔 놓을 수 있어서 모자이크처럼 보였고, 손·눈·연필 같은 원래 그림 뜻이 먼저 읽혔다.
- 코드로 그림 만드는 것이 금지였다. 그래서 Inkscape를 화면 조작으로 한 조각씩 다뤄야 했다. 작업량 때문에 성능이 낮은 모델을 썼고(사용자 설명), 나무 후보는 덩어리 하나에 잎 두 장 수준에서 멈췄다.
- 명암·선·60° 시점 규칙이 없었다. 평면 재색칠뿐이었다. Rule Rewrite 그림은 손으로 그린 도형 위에 아이콘 조각을 장식으로 얹은 것이었다.
- 사용자가 2026-09-25에 보관 처리하고 GPT 그림 방식으로 바꿨다. 그 방식도 이후 불합격했다.

## 2. 이번에 바꾼 것

- 레시피(JSON)를 읽어 그리는 코드 조합 도구를 만들었다. 자르기(사각·반쪽·직선·다각형·다른 아이콘 빼기·반전), 늘리기, 회전, 반전, 9분할 늘리기, 겹치기, 덩어리 합치기를 쓸 수 있다.
- 모든 조각 위에 같은 칠하기 규칙을 입혔다. 2단 명암과 거친 경계, 그림자 쪽이 굵고 밝은 쪽이 끊기는 짙은 유색선, 재질별 아이콘 도장 붓자국, 부품 사이 그림자, 60° 윗면·앞면 돌출, 별도 레이어의 접촉 그림자다.
- 60° 규칙(지면 ×0.866, 높이 ×0.5)을 배경·사물·캐릭터에 같이 적용했다.
- 끊겨도 이어서 할 수 있는 빌드와, 파일마다 사용 아이콘 SHA-256 기록을 추가했다.

## 6. 남은 문제와 다음 작업

- 개(Ash Hound): 다리가 뻣뻣하고 자세가 하나뿐. 경고 자세(lunge 예고)가 필요.
- 걷기: 아래 방향만 있고 다리만 위아래로 움직임. 무릎·옷자락 흔들림이 없음.
- 붓결: 큰 면의 붓자국을 더 크고 방향성 있게 해야 A와 가까워짐.
- 캐릭터 대 소품 높이 비율 규칙을 정해야 함(현재 캐릭터 ≈0.6, 소품 0.5).
- 배경 한 장 렌더에 약 40~110초가 걸림. 많이 만들려면 판석 부분을 캐시해야 함.
