## 자체 검토 (read 도구로 직접 봄)

| 자산 | 1차에서 본 문제 | 고친 것 |
|---|---|---|
| 재 실타래 | 풀린 실(매듭 아이콘 조각)이 검은 덩어리처럼 떨어져 보임. 불씨가 물방울무늬처럼 보임 | 실을 가는 줄 네 개로 이어 실패 밑에서 나오게 함. 불씨를 실결 방향의 가는 줄로 바꿈 |
| 길 표지 | 바닥 분필이 검은 선으로 나옴(도구가 그림 전체에 바깥 윤곽선을 둘러서). 오염 얼룩이 안 보임(투명한 곳에 곱하기 합성) | 도구에 `decal` 기능 추가(아래). 분필·얼룩을 decal로 그림. 얼룩은 일반 합성의 반투명 색으로. 2차: 얼룩을 6px 올려 아래 여백 32px 확보 |
| 복귀 지점 | 발자국이 아이콘 모양 그대로 또렷해서 표시 기호처럼 보임 | 흐리게·거칠게·조금 돌려서 발로 닳은 자국처럼 |
| 농도 장치 | 가는 다리 두 개가 벌어져 벌레·로봇처럼 보임. 2차: 플레이어 옆에 두니 머리 높이까지 올라와 너무 큼 | 쇠 받침대와 바닥 고리로 바꿈. 몸통 1.0→0.86m, 굴뚝을 줄여 전체 약 1.4m(가슴 높이), 캔버스 192×336→192×320 |

크기 확인은 V1 플레이어(`h0-icon-mood-v02/output/player/idle_down.png`)를 같은 바닥선에 세운 임시 그림으로만 했다. 캐릭터와 합친 그림은 납품하지 않는다.

## 도구에 추가한 것

- `tool/iconkit/render.py`: 형태에 `"decal": true`를 주면 바닥 무늬(분필, 얼룩)를 따로 그려서 바깥 윤곽선을 받지 않고 오브젝트 전체 아래에 깐다. `decal`이 없는 레시피는 V1과 똑같이 나온다.
- `tool/review_sheet.py`: 긴 이름표가 옆 칸과 겹치지 않게 칸 너비를 이름표 길이에 맞춤(그림에는 영향 없음).
- `tool/iconkit/icons.py`: 아이콘 변환 병렬 개수 8→2.

## 아쉬운 점

- 길 표지는 게임 화면 크기(0.5배)에서 말뚝이 30px 정도라 작다. 분필 띠로 자리는 보이지만 말뚝 머리판의 분필은 거의 안 보인다.
- 복귀 지점의 판이 맨홀 뚜껑이나 시계판처럼 보일 수 있다. 가장자리 눈금을 줄이거나 모양을 바꾸는 것은 사용자 판단 뒤로 미룬다.
- 재 실타래는 옆에서 본 모습이라 60° 시점 느낌이 약하다(누운 실패는 이 카메라에서 옆모습으로 보이는 게 맞지만 입체감이 적다).
- 새 색 두 개(분필 `#9d97a2`, 마력 매체 `#5f8f8a`)는 팔레트 파일이 아니라 레시피에만 있다. 다른 세션이 같은 색을 쓰려면 이 값을 옮겨야 한다.
