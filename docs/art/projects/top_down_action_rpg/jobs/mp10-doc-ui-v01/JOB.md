## 스타일 대응 (작성자 설계)

- 문서 바탕, UI 타일, 띠 채움처럼 넓은 면은 palette_h0의 `environment` 스타일(배경과 같은 선 두께와 붓결 밀도)을 쓴다. 128·192·384 칸의 선택 표시는 `sprite` 스타일(캐릭터와 같은 선 두께)을 쓴다.
- 붓자국의 모양·길이·너비·밀도는 시험 작업 설정을 그대로 쓴다. 넓은 면은 `floor`·`worn` 재질 붓결(leaf, 길이 34~40, 너비 7~8)이고, 문서 가장자리는 `paper` 재질 붓결이다. 색과 진하기만 UI 색과 대비 기준에 맞춘다(`COMMON.md`: 붓 느낌은 나중에 한 번에 조정).

## 색 (`recipes/palette_mp10_ui.json` 계획, 작성자 설계)

위 표의 문서 색과 UI 붓결 색에 H0의 ink, shade_tint, paper를 더한다. 톤앤매너가 확정되면 다시 맞춘다. H0와 다른 점은 두 가지다. 문서 윤곽선에 더 짙은 자주 `#120a16`을 쓰고, UI 붓결은 H0 자주 계열이 아니라 게임 UI의 푸른 검정 계열을 쓴다(지금 게임 판 색에 맞추기 위해).

## 도구에 추가할 기능 (계획, 시작할 때 자기 복사본에만)

1. `iconkit/icons.py`: 아이콘 변환 병렬 개수를 2로 제한한다(`COMMON.md`).
2. 타일 wrap: 붓자국이 캔버스 가장자리를 넘으면 반대편에도 찍는 옵션. 이음매 없는 512 타일에 필요하다.
3. `compose_preview.py`: 바탕을 키우는 `background_scale`, 전체를 어둡게 하는 `dim`, 평면 판 `plates`, 검수용 흰 막대 `bars`, 항목별 `opacity`를 추가한다(mp10-vfx-v01과 같은 기능을 각 폴더에 따로 넣음).
4. `check_surface.py`(새 파일): 글자 영역 무늬 세기(표준편차), 게임 글자색 대비, 종이 밖 알파 0, 넘김 자리 비었는지를 자동으로 잰다.
5. `stretch_check.py`(새 파일): 3분할·9분할로 늘린 모습과 타일 2×2를 한 장에 모은다.
6. `pack_sheet.py`: mp10-vfx-v01과 같은 한 줄 시트 묶기(선택 표시 프레임용).
