## 실제 화면 확인 (§12)

- 1280x720 합성 미리보기: 확인함 (`preview/h0_screen_preview_1280x720.png`, 도트 1칸 = 2px).
- 1920x1080, 2560x1440: not_run. 1920x1080은 1280 기준 1.5배라 도트가 2px/3px로 고르지 않게 보일 수 있다.
- 게임(Godot) 안 표시: not_run (게임 연결 금지).

## 다듬기 기록

1. 1차: 바닥 점 얼룩과 무작위 어두운 돌을 줄이고 닳은 길을 돌 단위로 바꿈. 게이트 뒤 재 계단을 벽 밑 굴로 내려가게 다시 그림(창살 사이로 보이게). 사물 그림자를 조금 진하게.
2. 2차: 추 지도를 3도트 두께의 판에서 바닥에 박힌 판(두께 1도트)으로 바꿈(모듈 layer floor).
3. 팔레트 원본이 작업 중 바뀌어(inputs.json) 새 사본으로 전부 다시 그림. 모양은 그대로.
