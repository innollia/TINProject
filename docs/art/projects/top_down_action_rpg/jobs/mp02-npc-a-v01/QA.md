## 4. 남은 문제

- Orrin 머리는 2번 고친 뒤에도 매끈한 모자처럼 조금 보인다.
- Ilyra 깃이 두툼하게 부풀어 보인다.
- 얼굴을 한 가지 얼굴 도구로 만들어서 눈·코·입 구성이 서로 닮았다. 모양 값으로 차이를 줬지만 PERSONAL_STYLE_CORE §9(모든 얼굴에 같은 안면선 반복 금지)에 비추면 더 달라도 된다.
- 선 두께를 COMMON '크기 통일'대로 필드 그림과 같은 원본 픽셀 값으로 두어서, 88px로 줄이면 윤곽선이 가늘게 보인다. 대화창 초상화만 선을 굵힐지는 사용자가 정할 일이다.
- 세션 03 초상화와 선·얼굴 위치를 맞췄는지는 확인하지 못했다(다른 세션 폴더를 보지 않는 규칙).
