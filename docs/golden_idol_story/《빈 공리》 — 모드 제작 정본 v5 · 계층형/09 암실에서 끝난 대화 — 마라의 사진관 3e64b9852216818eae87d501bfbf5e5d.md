# 09. 암실에서 끝난 대화 — 마라의 사진관

# 스테이지 개요

**장소:** 마라 데인의 사진관 지하 암실 / 1996-06-10, 사건 8 이틀 뒤.  

**첫 화면의 국소 모순:** 안전등이 깨지고 마라의 손이 베였으며 줄리언은 사라졌다. 네 조각으로 끊긴 녹음은 서로 모순되는 듯하지만, 물리적 작업순서를 맞추면 두 사람 모두 거짓말하지 않았다는 것이 드러난다.  

**독립사건의 질문:** 녹음은 어떤 순서인가 / 누가 무엇을 어떤 뜻으로 들었나 / 폭행이 있었나 / 두 사람의 관계가 왜 끊어졌나.  

**장기 변화:** ‘설명을 들으면 가장 가까운 기존 개념으로 치환해 이해한다’는 전달실패를 행동으로 보여 준다. Ø의 이름이나 정의는 만들지 않는다.

# 시각추론 정본 v5.1 — 구현 시 이 절이 상위 설명보다 우선

## 핵심 변경

이 스테이지는 이미 시각통합 잠재력이 높으므로, 텍스트가 사진순서를 대신 말하는 부분만 제거한다.

목표는 **사진의 물리상태 → 작업순서 → 테이프 배경음 → 발화 지시어**의 4단 교차검증이다.

## VISUAL SYSTEM 1 — 사진현상 상태

B2의 각 사진에서 “19:12 / 19:18 / 19:24 / 19:31” 획득단어를 삭제한다.

사진에는 시간표기가 없다.

- A: 정상 농도, 물얼룩 없음.
- B: 확대기 셔터 이중작동 때문에 동일 윤곽이 2mm 겹침.
- C: 저수압 때 생긴 하단 유백 얼룩.
- D: 창밖 전차의 긴 수평광선.

이 네 특징을 장비상태·수도수리표·전차시간표에 적용해 순서를 얻는다.

## VISUAL SYSTEM 2 — 암실 작업동선

현상탱크 → 확대기 → 세척대 → 안전등은 U자 동선이다.

바닥의 현상액 발자국은 이 순서로 이어지다가 안전등 앞에서 갑자기 뒤틀린다.

사진순서가 맞으면 마라의 이동경로와 정확히 겹친다.

획득단어 없음.

## VISUAL SYSTEM 3 — 깨진 안전등과 손상

C3의 “우발사고” 자동판정 삭제.

유리파편 대부분은 벽에서 **마라 쪽 바닥**으로 떨어져 있고, 피가 묻은 파편은 손바닥 높이 아래에만 있다.

줄리언이 서 있던 위치에는 파편·혈흔이 없다.

마라 손의 절상방향을 안전등 테두리와 맞춰 직접 재구성한다.

## VISUAL SYSTEM 4 — 녹음조각 물리형태

테이프 네 조각의 절단면이 각각 다른 모양이라 실제 이어붙일 수 있는 쌍이 두 개 있다.

물리적으로 맞는 절단면은 시간순서를 완전히 정하지 못하고, 배경음·지시어와 결합해야 한다.

즉 텍스트 의미만 읽어서 αβγδ를 조립할 수 없게 한다.

## 기존 텍스트 단서 수정

- B3 각 조각의 “배경: 첫 현상타이머 / 확대기 셔터 / 낮은 수도압 / 19:30 전차종” 해석문은 플레이어 화면에서 삭제한다. 실제 음원으로만 들린다.
- B4 마라 메모의 번호 1~4 삭제. 네 장이 책상 여러 위치에 섞여 있다.
- B5 줄리언 X 메모도 번호가 없고, 각각 어느 발화 뒤에 작성됐는지 종이의 현상액 얼룩색으로 연결한다.
- C1/C2의 시간은 규칙자료로 남길 수 있으나 사진에 직접 시간을 지급하지 않는다.

## TEXT-ONLY FAIL

대화문만 읽으면 논리적 선후 일부는 추정할 수 있지만 **유일한 순서 / 어느 메모가 어느 발화 뒤인가 / 손상사고의 물리경위**가 닫히지 않는다.

## Word Pool 수정

설명했다 / 교정했다 / 해석했다 / 우발사고를 선제 정답어로 쓰지 않는다.

경쟁토큰: 물었다 / 비유했다 / 해석했다 / 반박했다 / 교정했다 / 오해했다 / 밀었다 / 부딪쳤다 / 깨뜨렸다 / 베였다.

의미대응판은 처음부터 열려 있다. 다만 녹음순서를 복원하지 않으면 지시어의 참조대상을 안정적으로 연결하기 어렵게 설계한다.

# v5.3 추론밀도 패치

## 힌지 단서 A — 사진 C의 저수압 얼룩

사진 C의 하단 얼룩은:

- 그 사진의 현상시간을 저수압 구간으로 좁힘.
- 같은 시간 테이프의 수도소리와 연결.
- 그 대화가 ‘앞의 두 개’ 뒤, 전차종 전이라는 순서조건을 만듦.

한 물리결함이 사진순서와 녹음순서를 동시에 움직인다.

## 힌지 단서 B — 사진 D의 전차광선 + 안전등 반사

사진 D에는 창밖 전차광선과 함께 깨지기 전 안전등의 붉은 반사가 구석에 찍혀 있다.

- D는 19:30 전후.
- 안전등 파손은 D 촬영 뒤.
- 마지막 녹음조각의 유리깨짐 소리는 D 이후.

를 동시에 준다.

전차시간표와 파손순서를 한 사진이 묶는다.

## 힌지 단서 C — 테이프 절단면의 현상액 얼룩

테이프 네 조각 중 두 조각의 절단면에 같은 현상액 방울이 반쪽씩 이어진다.

- 어느 두 조각이 물리적으로 이웃했는지.
- 그때 마라가 어느 작업대 근처였는지.
- 특정 대화가 사진 A/B/C/D 중 어느 작업과 겹쳤는지.

를 동시에 압축한다.

대화 의미만으로 순서를 맞추는 것을 막는다.

## 힌지 단서 D — 마라 메모와 줄리언 X 메모의 같은 종이

마라가 적은 ‘카메라 / 해리 / 무아 / 사적언어’ 옆에 줄리언이 각기 다른 모양의 X와 짧은 반례를 덧쓴 한 장의 종이.

- 마라가 실제로 네 해석을 제시했음.
- 줄리언이 네 번 모두 다른 이유로 부정했음.
- 둘이 같은 종이를 번갈아 사용했으므로 대화 중 실시간 교정이었다는 점.

을 함께 준다.

‘정직한 치환’이라는 해설문은 삭제 가능.

## 삭제/병합

- 사진마다 별도 시간토큰을 주지 않음.
- 수도표·셔터기록·전차표는 각기 하나의 규칙만 제공.
- 다음날 마라 메모는 감정/관계 후일담으로 축소하고 사건논리의 핵심증거에서 제외.

# 중간문제 v5.3 — 고밀도 선택형 넛지

1. **사진과 녹음 한 줄로 복원** — 사진의 현상결함, 테이프 절단면, 수도소리·셔터·전차종, ‘아까/앞의 두 개/세 번째’ 지시어를 하나의 작업시간축에 겹친다. **결과:** 사진순서와 대화순서가 동시에 좁혀지고, 네 해석이 순차적으로 제시됐다는 구조까지 보인다.
2. **마지막 30초** — 사진 D의 전차광선·깨지기 전 안전등 반사, 유리파편 분포, 마라 손 상처, 마지막 테이프의 깨지는 소리를 한 측면도에 놓는다. **결과:** 마지막 발화 뒤 안전등이 깨졌고, 줄리언 폭행설보다 마라가 장치에 부딪친 경위가 더 맞는다는 쪽으로 좁혀진다.

사진판/녹음판/해석판을 분리하지 않는다.

# 메인문제 v5.3

“[마라 데인]은 줄리언의 네 설명을 차례로 ‘시점 없는 카메라’, ‘해리’, ‘무아’, ‘사적 언어’라고 불렀고, [줄리언 룩]은 네 번 모두 다른 이유로 부정했다. 마지막 말다툼 직후 마라는 안전등에 부딪혀 손을 베었으며, 줄리언이 직접 다치게 했다는 물리증거는 없다.”

# 제작 잠금표 v5.5 — 플레이어 비노출

- **순서:** 전차시각·수도압·셔터 이중작동·사진 현상결함·테이프 절단면을 교차해 네 대화의 순서를 복원한다. 사진 조각에 정답시각을 1:1로 찍어 순서판을 없애지 않는다.
- **말의 뜻:** 마라가 제시한 네 기존개념과 줄리언의 각각 다른 거절 이유를 대응한다. 마라의 다음날 메모는 믿음과 혼란을 보여 주되 정답 순서를 요약하지 않는다.
