# 11. 검은 층 아래의 사람들 — 타르 해안동굴

# 스테이지 개요

**장소:** 타르 해안동굴 고고학 발굴현장 / 1995-09-15, 폭풍 뒤 부분붕괴 직후.  

**첫 화면의 국소 모순:** 폭풍 때문에 무너졌다고 보고됐지만 동쪽 벽에는 규칙적인 천공 4개와 전기뇌관 조각이 있다. 동시에 붕괴로 세 지층의 표본상자가 섞였다.  

**독립사건의 질문:** 누가 불법폭파를 지시·실행했나 / 에이라의 죽음은 의도적이었나 / 뒤섞인 표본은 어느 층에서 왔나.  

**장기 변화:** 지층을 올바르게 복원한 뒤에만 ‘같은 경계에서 생물학적 변화와 문화적 변화가 겹친다’는 지역적 상관자료를 얻는다. 원인은 확정하지 않는다.

# 등장인물

- **에이라 펜 / 수석고고학자·피해자** — 붉은 작업모, 층위기록 최종책임자.
- **노엘 사르 / 고유전체 연구자** — 흰 마스크, 뼈 표본튜브.
- **이보 렌 / 지구화학자** — 검은 안경, 층경계 샘플통.
- **카렐 모크 / 스폰서 회사대표** — 깨끗한 가죽장화, 동굴 아래 광물채굴권에 관심.
- **벤 아로 / 발파기술자** — 주황 작업복, 폭약창고 열쇠.
- **리아 노스 / 현지안내인** — 밧줄·등반장비, 지형기록 담당.

# 지역 E — 지구화학 장비차량 · 처음부터 접근 가능

**이미지 설명:** 처음부터 들어갈 수 있지만 붕괴 때문에 층 라벨이 떨어져 있어 AX-7·도상·샘플 데이터가 α/β/γ 코드로만 정리돼 있다. 지층복원 중간문제를 풀지 않아도 플레이어가 현장 단면과 원자료를 직접 비교하면 어느 층인지 해석할 수 있다.  

**지역 기능:** 사건 11의 범죄해결과 **인류사 해석자료를 분리**한다. 중간문제 완료는 접근조건이 아니며, 이 방의 정보도 범인을 찾는 데 필수는 아니다.

- 오브젝트 E1 — AX-7 층별 요약 · 문서
    
    적갈층: A형 우세
    
    검은층: A/B 혼재
    
    회백층: B형 우세
    
    현대 세포모델: A형은 연결변화가 크지만 강한 N-유사 자극에서 연쇄오류가 더 자주 남음. B형은 변화폭이 작고 오류도 적음.
    
    **얻는 단어:** A형 / B형 / 변화 / 오류
    
    **기능:** A형=Ø 같은 등식을 금지. 인지유연성과 특정 스트레스 취약성의 상관만.
    
- 오브젝트 E2 — 연안 경계 연대표 · 문서
    
    타르 / 네르 하구 / 오르스 섬에서 비슷한 연대구간에 고에너지 경계와 A→B 비율변화가 시간오차 범위 안에서 겹침.
    
    에이라 필기: “한 동굴의 우연이라고 부르기는 어려움. 전 지구 일반화 금지.”
    
    **얻는 단어:** 타르 / 네르 하구 / 오르스 섬 / 고에너지 / 시간상 상관
    
    **기능:** 복잡한 동위원소 그래프를 별도 퍼즐로 만들지 않고, 지역적 반복이라는 관찰만 제공.
    
- 오브젝트 E3 — 도상 보관판 · 이미지
    
    적갈층: 중앙을 의도적으로 비워 둔 도상 여러 점
    
    검은층: 소수
    
    회백층: 현재 발굴분 없음
    
    사건 7 석판과 재질·기법 일부 유사, 의미 동일성은 미확정.
    
    **얻는 단어:** 무조각 도상 / 감소
    
    **기능:** 문화적 변화의 상관. 개념소실 직접증거가 아님.
    
- 오브젝트 E4 — 이보 가설노트와 에이라 반론 · 문서
    
    이보: “고에너지 경계 → A형에서 연쇄오류 증가 → A형 비율 감소? B형 안정성이 생존차이를 만들었나?”
    
    에이라: “도상 감소가 곧 관념 감소라는 증거는 아니다. 다만 세 변화가 같은 경계에 몰린 이유는 설명이 필요.”
    
    **얻는 단어:** 가설 / 과잉해석 / 시간상 상관
    
    **기능:** 세계 안 인물의 가설과 확정사실을 분리.
    

# 시각추론 정본 v5.1 — 구현 시 이 절이 상위 설명보다 우선

## 0클릭 장면

동굴 첫 화면에서 동쪽 벽의 네 천공은 자연균열과 각도가 다르고, 에이라의 시신은 폭약구멍 정면이 아니라 옆쪽 상부 낙석 아래 있다.

“의도적으로 에이라를 폭파했다”와 “벽을 뚫다 예상 밖 붕괴가 났다”가 동시에 가능해야 한다.

## VISUAL SYSTEM 1 — 뇌관/도구 식별

B2의 “벤 회사규격과 일치” 자동설명 삭제.

전기뇌관 끝의 3핀 배열과 주황 절연띠를 벤 공구상자 속 정식 뇌관 샘플 그림과 직접 비교한다.

다른 작업자 장비에도 비슷한 2핀 부품을 둬서 단순 색상만으로 못 맞히게 한다.

## VISUAL SYSTEM 2 — 지시자 표식

카렐 광맥지도의 삼각표식과 벤 쪽지의 △가 “같다”고 텍스트로 말하지 않는다.

삼각형 내부에 작은 점 두 개가 찍힌 독특한 사내 표식을 IMAGE ↔ IMAGE로 비교한다.

카렐의 다른 회사서류에도 같은 표식이 있어 ‘벤 개인 기호’ 가설을 제거한다.

## VISUAL SYSTEM 3 — 살인계획이 아닌 과대붕괴

천공 4개는 광맥을 향해 수평으로 들어가고 폭약흔적도 안쪽으로 집중된다.

에이라 위치는 계획된 폭파직선 바깥이지만, 천장 균열이 오래된 빗물층을 따라 옆으로 뻗어 시신 위치까지 이어진다.

**천공방향 ↔ 낙석선 ↔ 시신위치**를 단면도 위에서 맞춰야 ‘광맥 확인용 미세폭파가 예상 밖 천장붕괴를 냈다’가 성립한다.

획득단어 없음.

## VISUAL SYSTEM 4 — 지층복원

D1의 “회백층=조개편·작은사슴뼈…” 정답표 문장을 삭제한다.

대신 현장 C지역 단면에 실제로 박혀 있는:

- 회백층의 흰 조개 단면 + 가는 회색점토 결.
- 검은층의 유리질 검은 알갱이 + 길고 뾰족한 바닷새뼈.
- 적갈층의 주황 철분띠 + 넓은 민물패각.

을 직접 관찰한다.

표본상자 αβγ에는 라벨 없이 같은 질감·형태 조각이 섞여 있다.

**현장 단면 IMAGE ↔ 표본 IMAGE**로만 복원한다.

## VISUAL SYSTEM 5 — 뼈 형태

작은사슴/바닷새/큰사슴 이름은 문서에서 바로 주지 않는다.

현장 생물도감에는 실루엣과 뼈모양만 있다. 표본의 골두·부리뼈·발굽뼈를 그림과 비교해 동물군을 구분한다.

획득단어 없음.

## VISUAL SYSTEM 6 — 도상 변화

E3에 “적갈 여러 점 / 검은 소수 / 회백 없음”이라는 문장표를 삭제한다.

복원된 각 층 서랍을 실제로 펼쳐 놓고 플레이어가 **중앙이 비어 있는 도상 조각을 직접 골라 층별 트레이에 분류**한다.

숫자를 자동 카운트하지 않는다. 최종 카드에는 분류결과만 요약.

## 기존 텍스트 단서 수정

- B1 ‘동일 직경·동일 간격’은 클릭 설명이 아니라 화면 격자자를 대어 비교.
- B5 시각표는 폭풍최고시각만 규칙으로 제공. 실제 붕괴시각은 깨진 현장시계·캠프 발전기 로그·리아 카메라 시각 세 개를 조합.
- D2~D4의 “α=적갈 / β=검은 / γ=회백” 설명 및 획득단어 삭제.
- D5 리아 단면스케치는 정답색 이름이 아니라 붕괴 전 질감 패턴만 보인다.
- E1 AX-7 자료는 지층복원 뒤 읽을 수 있으므로 텍스트 중심이어도 허용하되, 그 자체로 사건 범죄를 풀 수 없게 유지.

## TEXT-ONLY FAIL

문서만 읽으면 카렐-벤 사이 숨은 업무와 불법폭파 가능성은 알 수 있지만 **실제 벤 장비 사용 / 폭파방향 / 에이라가 직접표적이 아니었음 / αβγ 지층배치 / 도상 감소**는 확정되지 않는다.

# 중간문제 v5.3 — 고밀도 선택형 넛지

1. **동쪽 벽 사건복원** — 천공축, 회사 삼각표식, 뇌관조각, 광맥지도, 에이라 위치, 천장균열을 한 단면도에 놓는다. **결과:** 자연붕괴가 아니라 벽 뒤 광맥을 겨냥한 비공식 작업이 있었고, 피해자는 직접 표적이 아니었을 가능성이 동시에 강해진다. 지시자·실행자 이름은 남긴다.
2. **한 번의 지층복원, 세 종류의 변화** — αβγ 상자의 토양·동물뼈·패각·도상조각을 실제 트렌치 층과 맞춘 뒤 같은 αβγ 코드를 AX-7 자료에 재사용한다. **결과:** 상대층위 / 생태변화 / 생물학자료 / 도상분포가 한 번에 정렬된다. 그 변화들 사이의 인과는 답하지 않는다.

증거강도 사다리는 삭제한다. 인과가설에 필요한 연결고리가 비어 있다는 사실 자체를 남긴다.
