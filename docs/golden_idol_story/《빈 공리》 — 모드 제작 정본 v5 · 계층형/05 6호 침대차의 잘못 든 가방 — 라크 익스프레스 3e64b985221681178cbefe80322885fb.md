# 05. 6호 침대차의 잘못 든 가방 — 라크 익스프레스

# 스테이지 개요

**장소:** 북부행 야간열차 ‘라크 익스프레스’ 6호 침대차 / 1996-04-27, 사건 직후 산악역 정차.  

**첫 화면의 국소 모순:** 4번 침실 위침대에서 메렉 솔이 사망했는데, 승무원 원래 배정표상 그 자리는 세라 퀼의 자리다. 동시에 거의 같은 갈색 가방 세 개 중 하나에서 세라의 노트가 사라졌다.  

**독립사건의 질문:** 누가 실제로 어느 침대에서 잤나 / 세 가방 주인은 누구인가 / 누가 누구를 노렸나 / 왜 의뢰인이 죽었나.  

**장기 변화:** Ø에 대한 새 증거는 없다. 세라 퀼이 실제 인물로 등장하고, 사라진 III권과 해월사 약속만 남는다.

# 등장인물

- **세라 퀼 / 현지언어학자** — 짧은 은빛 머리, 청색 잉크, 손잡이에 파란 실을 묶은 갈색 가방.
- **메렉 솔 / 희귀문헌상·피해자** — 비싼 갈색 코트, 왼손 새끼손가락 금반지, 심장약 휴대.
- **베른 카스 / 철도우편 특송원** — 붉은 제복모, 붉은 밀랍봉인 가방.
- **유리 벤트 / 여행의사** — 둥근 안경, 응급약 상자.
- **니코 렌 / 차내승무원** — 검은 조끼, 객실배정표와 마스터키.
- **펠 도르 / 골동품중개인** — 회색 장갑, 세면가방, 메렉과 은밀한 거래.

# 시각추론 정본 v5.1 — 구현 시 이 절이 상위 설명보다 우선

## 0클릭 장면

4번 침실 첫 화면에서 시신은 위침대에 있고, 아래침대 이불은 몸집이 작은 사람이 잔 것처럼 좁게 눌려 있다. 바닥에는 서로 비슷한 갈색가방 두 개와 다른 방으로 이어지는 세 번째 가방이 보인다.

‘시신이 왜 원래 다른 사람 자리인가’는 문서 읽기 전부터 보이게 한다.

## VISUAL SYSTEM 1 — 실제 취침배치

B2의 “메렉 구두=4B / 세라 구두=4A” 해석문을 삭제한다.

위침대 사다리 아래에는 큰 남성구두 한 켤레와 금색 새끼발가락 반지 보관함, 아래침대 밑에는 낮은 여성구두와 청색잉크 얼룩 양말이 보인다.

세라·메렉의 현재 복장 이미지와 직접 비교해 실제 사용자를 정한다.

획득단어 없음.

## VISUAL SYSTEM 2 — 갈색가방 3개

가방 A/B/C라는 UI 라벨을 처음부터 표시하지 않는다.

- 가방 ①: 한쪽 금속모서리 찌그러짐 + 낡은 호텔 스티커 흔적.
- 가방 ②: 손잡이 파란실 + 안쪽 청색잉크 얼룩.
- 가방 ③: 바닥 붉은 밀랍 + 특송제복의 같은 봉인문양.

세라 산악사진 / 메렉 호텔 로비사진 / 베른 특송규정 그림과 각각 IMAGE ↔ IMAGE로 매칭한다.

수하물표에 소유자 이름을 직접 쓰지 않는다.

## VISUAL SYSTEM 3 — III권의 부재

B4 차례에 “III권 없음”이라고 쓰지 않는다.

세라 가방 안에는 같은 폭의 노트 두 권과 **세 번째 권이 있던 눌린 자국, 끊어진 청색 고정끈, 식물압착테이프 찌꺼기**가 남아 있다.

세라 사진 속 가방을 보면 세 권이 같은 고정끈에 묶여 있었다.

‘무언가 한 권이 빠졌다’는 사실은 시각으로만 얻는다.

## VISUAL SYSTEM 4 — 잘못된 표적

펠 쪽지에는 4B / 파란실만 남긴다.

원래 배정표는 규칙, 실제 침대사용은 VISUAL 1, 가방 소유는 VISUAL 2다.

세 줄기를 합치지 않으면 펠이 사람 얼굴이 아니라 **자리+가방표식**으로 표적을 잡았다는 결론이 나오지 않는다.

## 기존 텍스트 단서 수정

- A2 니코가 “자리를 바꿨다”고 말하지 않는다. “퀼 씨가 위칸을 힘들어했다. 그 뒤 확인은 못 했다.”까지만.
- D1 냅킨도 “바꾸고 싶어요”까지만 두고 실제 교환 성립은 시각으로 확인.
- C3 검안메모는 약물의 상호작용 규칙만 제공. ‘통상용량’인지 여부는 빈 앰플 눈금과 메렉 혈중검사 그래프를 비교해 판정.
- E1 청색 테이프는 “III권 전용”이라고 문장으로 말하지 않는다. 남은 I·II권의 표본부착 방식과 사건 전 사진 속 III권의 테이프를 비교한다.

## TEXT-ONLY FAIL

텍스트만으로는 원래 배정과 펠의 지시내용은 알 수 있지만 **실제 침대교환 / 가방 소유 3개 / 빠진 노트 한 권 / 실제 주사대상이 누구였는지**가 확정되지 않는다.

## Word Pool 수정

바꾸었다 / 잘못 보았다 / 가져갔다 / 사망했다를 초기 풀에서 제거하고 경쟁토큰을 둔다.

경쟁토큰: 누웠다 / 옮겼다 / 바꿨다 / 착각했다 / 노렸다 / 재웠다 / 훔쳤다 / 숨겼다 / 죽였다 / 죽었다.

이름 토큰은 소지품·명부에서 바로 얻는다. 가방 소유 판은 물건과 이름의 대응을 정리하는 선택형 문제이며 본문 슬롯을 잠그지 않는다.

- 취침 전 개인 약을 사용.
- 원래 배정표와 실제배치가 달라짐.

을 한 번에 준다.

신발위치와 복용기록을 따로 풀 필요가 줄어든다.

## 힌지 단서 B — 파란실 가방의 ‘세 번째 자리’

파란실 가방 안 I·II권 + 세 번째 권이 있던 눌린 자국 + 끊어진 고정끈 + 펠 장갑의 같은 청색 테이프.

- 세라 가방.
- 한 권이 실제 빠짐.
- 펠이 그 가방을 만짐.
- 목표품이 다른 가방이 아님.

을 한 번에 만든다.

## 힌지 단서 C — 펠의 4B / 파란실 / Q-3 쪽지

세 표기는 각각 자리 / 가방표식 / 목표품을 뜻하고 어느 것도 얼굴 이름이 아니다.

이 한 문서가:

- 펠이 사람 얼굴을 몰랐음.
- 원래 4B=세라라는 오래된 정보에 의존.
- 파란실 가방을 찾아야 했음.
- 자리교환이 오인의 핵심.

을 동시에 만든다.

메렉 거래장부는 Q-3 의뢰자=메렉만 추가.

## 힌지 단서 D — 주사 흔적과 개인약품

현장 주사흔적 + 남은 진정제 + 메렉의 개인약품 + 의사의 상호작용 규칙표를 결합하면:

- 의도적 과량투여 가설 약화.
- 잘못된 대상에게 사용되었을 가능성.
- 사망이 특정 조합에서 비롯됐다는 점.

이 같이 닫힌다.

# 중간문제 v5.3 — 고밀도 선택형 넛지

1. **4B 표적복원** — 실제 침대 사용흔적, 파란실 가방, 펠의 4B / 파란실 / Q-3 메모를 한 객실도에 배치한다. **결과:** 원래 표적은 세라 쪽 / 실제 4B 사용자는 메렉 / 펠은 얼굴이 아니라 자리+가방표식으로 찾았음이 동시에 좁혀진다. 의뢰자가 누구인지는 남긴다.
2. **빠진 한 권과 펠의 접촉** — 파란실 가방의 세 번째 눌림자리, 끊어진 고정끈, 펠 장갑 흔적을 맞춘다. **결과:** 무엇이 사라졌고 누가 그 가방을 만졌는지가 한꺼번에 압축된다.
3. **사망기전** — 현장 흔적, 남은 진정제, 메렉 개인약품, 의사 규칙표를 한 표에 놓는다. **결과:** 의도적 과량보다 잘못된 대상+불리한 조합 가설이 강해진다. 누가 주사했는지는 다른 판과 결합해야 한다.

가방소유판과 표적연결판을 분리하지 않는다.

# 제작 잠금표 v5.5 — 플레이어 비노출

- **배정과 실제:** 승차권 4A/4B와 침구·신발·사다리 아래 소지품을 대조한다. ‘바꾸고 싶다’는 냅킨은 의사표시일 뿐 교환완료 증거가 아니다.
- **표적과 실행:** 펠의 4B/파란실/Q-3 쪽지, 거래장부, 세 가방의 소유흔을 함께 써서 메렉이 세라를 겨냥했고 펠은 침대와 가방을 보고 오인했음을 밝힌다. 사람 이름 토큰은 명부에서 얻어도 된다.
