# 10. 편도표를 산 사람 — 포르테 국제여객선 터미널

# 스테이지 개요

**장소:** 포르테 국제여객선 터미널 / 1996-06-12, 새벽 첫 배 출항 직후.  

**첫 화면의 국소 모순:** 줄리언 룩은 사라졌고 편도 승선권은 찢겨 목적지가 보이지 않는다. 보관함에는 세 나라 화폐, 목적지가 다른 병원 안내서, 겨울코트, 3일치 짐, 미발송 편지가 뒤섞여 있다.  

**독립사건의 질문:** 어느 배를 탔나 / 어디로 갔나 / 도주·강제입원·휴식·치료 중 무엇이 목적이었나 / 본인의 선택이었나.  

**장기 변화:** 줄리언은 그 사고상태의 ‘내용’을 지운 것이 아니라, 반복해서 그 상태로 들어가게 하던 자기 훈련루틴의 자동접근성을 낮추는 치료를 스스로 선택했다.

# 등장인물

이 스테이지의 핵심 인물은 이미 확정된 **줄리언 룩**과 **마라 데인**뿐이다. 터미널 직원은 배경 인물이며 이름판을 만들지 않는다. 후반부 신원피로를 의도적으로 줄인다.

# 시각추론 정본 v5.1 — 재설계 우선

## 0클릭 장면

터미널 첫 화면에는 목적지 글자가 찢긴 승선권, 세 나라 화폐, 두 병원 안내서, 겨울코트, 아주 작은 여행가방이 한 보관함에 뒤섞여 있다.

문서를 읽기 전에도 “도주치고 짐이 너무 적다 / 북항이면 왜 겨울코트를 두고 갔지 / 병원이 둘인데 어느 쪽이지?”가 보이게 한다.

## VISUAL SYSTEM 1 — 승선권 ↔ 실제 배

A2 승선권에서 목적지와 부두번호만 훼손된다. 06:05는 보이고 낱말로 얻는다. 같은 시각 산텔행과 헤스카행이 전광판에 있으므로 숫자만으로 목적지가 정해지지 않는다.

남는 구별 표식은:

- 남색-금색 사선 테두리.
- 갈매기 세 마리 문장.
- 오른쪽 모서리의 세모형 절취홈.

전광판 옆에는 네 배의 **선사문장·표색·부두 게이트 절취형** 그림이 있다.

06:05 출항편 둘 중 산텔행만 승선권의 세 특징이 모두 일치한다.

목적지는 IMAGE ↔ IMAGE 비교로 먼저 알아낸다.

## VISUAL SYSTEM 2 — 부두 동선

Pier 1~4는 숫자 간판만 보이는 복도가 아니라 서로 다른 아치색·바닥문양을 가진다.

사진부스 연속필름에는 줄리언이 남색 타일 → 갈매기 문장 아치 → 세모 절취 게이트를 지나가는 모습이 3컷으로 잡힌다.

사진에 “Pier 2” 캡션 금지.

획득단어 없음.

## VISUAL SYSTEM 3 — 화폐

환전영수증에는 국가명이 없고 통화기호만 있다.

보관함의 세 나라 지폐는 실제 도안으로 보이며, 터미널 환율판의 도안샘플과 비교해야 어떤 화폐를 **방금 대량 환전했는지** 알 수 있다.

오래된 두 화폐는 접힌 모서리와 구형도안, 산텔 화폐만 새 지폐.

IMAGE ↔ IMAGE 필수.

## VISUAL SYSTEM 4 — 짐의 성격

B1은 “3일치”라고 글로 말하지 않는다.

가방을 열면 셔츠 3장 / 속옷 3벌 / 세면도구 소형 / 책 0권 / 직업서류 원본 없음이 보인다.

겨울코트는 락커 뒤에 그대로 걸려 있다.

장기망명·북항행 가설을 **물건의 양과 계절복장**으로 제거한다.

## VISUAL SYSTEM 5 — 성 아그네스 프로그램과 제출물

프로그램 안내는 텍스트 설명만 주지 않고 도식이 핵심이다:

반복카드 → 특정 호흡/시각순서 → 같은 사고상태 진입

치료도식:

같은 카드 → 경쟁과제 → 기존 화살표가 점점 얇아짐

줄리언 가방의 실제 질문카드·시각카드는 사건 8에서 사용한 것과 같은 그림이다.

**사건 8의 카드 이미지 ↔ 현재 제출물 ↔ 프로그램 도식**을 맞춰야 치료대상이 ‘기억 내용’이 아니라 자기 진입루틴임을 확정한다.

## VISUAL SYSTEM 6 — 자발성

예약팩스에서 “예약자 본인 / 자발적” 문구를 삭제한다.

대신:

- 매표소 감시사진: 줄리언 혼자 표를 사고 돈을 건넴.
- 선납영수증 서명과 사건 8·9의 왼손 필체를 비교.
- 게이트 사진: 제지·동행 없이 혼자 입장.

세 이미지로 자발성을 판정한다.

## 기존 텍스트 단서 수정

- C1 “산텔 화폐만 신규 환전” 자동해석 삭제.
- C2 “산텔 지역코드” 직접설명 삭제. 전화번호 지역코드는 터미널 공중전화 안내지도에서 도시별 색영역으로 비교.
- D1의 “Pier 2 방향” 캡션 삭제.
- D2 세관장부는 J. Rook 통과시각만 남기고 부두번호·동행자 여부는 이미지에서 확인.
- D3의 “예약자 본인 / 선납 / 보호자 공란” 중 선납 사실만 문자로 유지. 자발성은 VISUAL 6.
- D4 프로그램 텍스트는 “기억을 삭제하지 않는다” 규칙만 명시하고, 실제 치료과정은 그림도식으로 읽게 한다.

## TEXT-ONLY FAIL

텍스트만으로는 성 아그네스라는 기관과 줄리언이 무언가 치료를 고려했다는 정도까지만 알 수 있다.

**실제 탑승항로 / 산텔 선택 / 짧은 체류 / 혼자 자발적으로 출발 / 어떤 자기루틴을 치료대상으로 제출했는지**는 이미지 없이는 확정되지 않는다.

# v5.3 추론밀도 패치

## 힌지 단서 A — 락커 한 칸 전체

찢긴 승선권 / 새 산텔 지폐 / 남겨진 겨울코트 / 3일분 작은 짐이 같은 락커에 있다.

한 장면이:

- 어느 항로 후보가 강한지.
- 장기이주가 아닌 짧은 체류임.
- 추운 북항행과 충돌.
- 표 주인이 줄리언일 가능성.

을 동시에 움직인다.

각 물건을 별도 문서로 설명하지 않는다.

## 힌지 단서 B — 매표소→환전소→게이트 연속사진

서로 다른 세 카메라에서 같은 왼손 필체 가방끈/코트 없는 차림/작은 가방이 이어진다.

- 같은 사람이 전 과정을 스스로 진행.
- 동행자나 강제이동 흔적 없음.
- 환전과 승선이 한 여행행동으로 연결.
- 게이트 시각이 승선권 시간대와 맞음.

을 한꺼번에 준다.

세관장부의 ‘동행자 없음’ 문장은 삭제 가능.

- 목적지가 성 아그네스.

- 인간적 동기.

를 하나의 RETURN CLUE로 묶는다.

# 중간문제 v5.3 — 고밀도 선택형 넛지

1. **한 사람의 출항준비** — 락커의 찢긴 승선권·새 화폐·작은 짐·남겨진 겨울코트와, 매표소→환전소→게이트 연속사진을 한 여행보드에 놓는다. **결과:** 가능한 항로 / 짧은 체류 / 혼자 준비한 여행이라는 세 축이 동시에 좁혀진다. 목적기관은 아직 남긴다.
2. **성 아그네스 접수봉투** — 사건 8의 질문카드와 같은 제출물, 본인서명 영수증, 치료도식, 마라 편지의 ‘돌아가는 길을 덜 쉽게’ 문장을 대응한다. **결과:** 목적기관 / 자발성 / 치료대상이 기억전체가 아니라 반복 진입경로라는 점이 한꺼번에 가까워진다.

항로판·여행성격판·자발성판·치료목적판을 따로 두지 않는다.
