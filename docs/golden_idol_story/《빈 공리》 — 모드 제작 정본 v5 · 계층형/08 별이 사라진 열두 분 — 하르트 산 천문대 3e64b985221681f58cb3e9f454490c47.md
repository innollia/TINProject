# 08. 별이 사라진 열두 분 — 하르트 산 천문대

# 스테이지 개요

**장소:** 하르트 산 천문대 공개관측회 / 1996-06-08, 폭풍 접근 중인 밤.  

**첫 화면의 국소 모순:** 21:44~21:56 천문대가 정전됐는데, 보조발전기는 정상이고 연료도 충분했다. 같은 12분 동안 줄리언 룩은 돔 바닥에서 완전히 다른 종류의 변화를 겪었다.  

**독립사건의 질문:** 왜 정상 발전기가 있는데 정전됐나 / 누가 전력을 빼돌렸나 / 정전과 줄리언 사건은 같은 원인인가 / 줄리언은 무엇을 하고 있었나.  

**장기 변화:** 줄리언이 서로 무관한 자료에서 ‘공통된 실수 방식’을 보기 시작했다는 사실만 확정한다. 그가 정확히 무엇을 경험했는지는 정답으로 정의하지 않는다.

# 등장인물

- **줄리언 룩 / 인지철학 강사** — 32세, 검은 곱슬머리, 왼손잡이, 빈 원을 겹쳐 그리는 습관.
- **마라 데인 / 사진작가** — 31세, 짧은 갈색 머리, 카메라 2대, 줄리언과 14년 친구.
- **에반 트로 / 보조기사** — 기름 묻은 작업복, 햄라디오 동호회 배지.
- **베스 칼 / 전기담당** — 절연장갑, 발전기실 키.
- **올마 렌 / 천문대장** — 흰 셔츠, 청색 완장, 관측일지 서명.
- **다리오 벡 / 기업후원자** — 검은 턱시도, 관측시간 구매계약서.

# 지역 A — 공개관측 돔 · 쿼터뷰

**이미지 설명:** 정전 뒤 비상등이 돌아온 돔. 주망원경은 목표를 잃고 옆으로 틀어져 있다. 줄리언은 바닥에 앉아 있고 다리오는 올마에게 항의한다.  

**지역 기능:** sabotage / 폭풍 / 줄리언 / 장비고장 가설을 한 번에 연다.

- 오브젝트 A1 — 줄리언 룩 · 인물
    
    **대사:** “정전은 내가 한 게 아니야. 그런데… 끊긴 동안에야 뭘 잘못 보고 있었는지 알았어.”
    
    **얻는 단어:** 줄리언 룩 / 비교표
    
    **기능:** 인지사건과 전력사건을 같은 사건으로 섞지 않게 하는 첫 힌트.
    
- 오브젝트 A2 — 다리오의 계약서 · 문서
    
    정전으로 구매 관측시간이 취소되면 일부 보상금 지급.
    
    **얻는 단어:** 다리오 / 후원자 / 보상
    
    **기능:** 고의 sabotage 오도. 전력접근권한은 없음.
    
- 오브젝트 A3 — 수동 별지도 · 이미지/장치
    
    정전 전 별지도와 복구 뒤 접안부 기록의 기준별 위치가 다르다.
    
    **얻는 단어:** 12분 / 정전
    
    **기능:** 전산로그와 독립된 시간검증.

## 0클릭 장면

돔 첫 화면에서 망원경은 목표별이 있던 방향과 어긋나 있고, 벽을 타고 올라간 굵은 케이블 하나가 원래 배전배관과 다른 색으로 옥상 쪽으로 사라진다. 에반은 그 케이블 가까이에 기름 묻은 장갑을 두고 왔고, 줄리언은 전력설비와 먼 돔 중앙 바닥에 자료 몇 장을 흩어 놓고 앉아 있다.

정전범과 줄리언을 같은 사람으로 묶는 첫 가설이 자연스럽되, 화면 위치가 이미 둘을 분리할 가능성을 준다.

## VISUAL SYSTEM 1 — 별궤적과 망원경

A3의 “12분만큼 어긋남” 해석문을 삭제한다.

정전 직전 수동별지도에는 목표별과 기준별 2개의 상대위치가 있고, 복구 후 접안부 사진에는 같은 기준별만 남는다.

마라의 장노출 사진에는 돔 조명 공백 구간이 눈금 없는 필름으로 보인다.

플레이어가 **별지도 ↔ 접안부 ↔ 필름**을 맞춰 정전구간을 추정하고, 장치로그의 21:44/21:56로 교차검증한다.

## VISUAL SYSTEM 2 — 송신기 부하

옥상 송신기의 전력플러그는 보조발전기 규격과 맞는 특수 3핀이고, 발전기실 비상출력 소켓 하나에 같은 3핀의 긁힘자국이 있다.

문서에는 ‘송신기는 큰 전력을 쓴다’ 규칙만 있고, 실제 연결여부는 플러그·소켓 흔적으로 본다.

## VISUAL SYSTEM 3 — 에반 식별

햄라디오 동호회 단체사진 속 인물들은 모두 비슷한 작업복이다. 에반만 **왼쪽 장갑 손목의 삼각 패치와 무전기 안테나를 테이프로 감은 방식**이 현재 옥상 장비와 일치한다.

무선일지 서명만으로 에반을 확정하지 않는다.

## VISUAL SYSTEM 4 — 줄리언의 네 자료 연결

D2~D5의 색인카드 텍스트가 “소유감? / 문법? / 무아? / 상징?”을 직접 말하지 않게 한다.

각 자료에는 줄리언이 얹어 둔 반투명 트레이싱지 한 장이 있고, 현대 해석자가 덧붙인 요소에만 붉은 원이 그어져 있다.

- Case 44: 옷표에 그어진 소유자 구분선.
- 세라 유인물: 번역자가 삽입한 주어 자리.
- 지안 초안: 보충된 명사.
- 석판사진: 복원자가 중앙에 가상 인물상을 덧그린 스케치.

네 트레이싱지를 겹치면 붉은 원이 거의 같은 위치에 포개진다. **IMAGE ↔ IMAGE 비교를 해야 줄리언이 같은 종류의 ‘보충’을 보고 있었다는 사실이 생긴다.**

제어실 벽 / 발전기실 / 서비스사다리 / 옥상 송신기에 같은 황색테이프 두 바퀴와 긁힘이 이어진다.

한 케이블이:

- 정상 배전도에 없는 실제 전력경로.
- 발전기실과 옥상을 물리적으로 연결.
- 송신기 사용과 정전사건을 같은 인과축에 올림.
- 에반 장갑의 같은 검은 고무가루와 결합해 사용자 후보를 좁힘.

을 동시에 한다.

별도 ‘비인가 케이블’ 설명문은 필요 없다.

## 힌지 단서 B — 마라의 장노출 필름

한 장의 필름에:

- 돔 조명이 끊긴 구간.
- 줄리언이 외부 테라스가 아니라 돔 안에 있었음을 보여 주는 빈 삼각대.
- 폭풍번개는 계속 찍혀 있어 카메라 자체 정지설을 반박.

가 동시에 들어간다.

이 필름이 **정전 지속시간 / 마라 알리바이 / 카메라고장 반박**을 함께 담당한다.

## 힌지 단서 C — 에반의 송신기 플러그

특수 3핀 플러그의 긁힘이 발전기 비상소켓과 맞고, 같은 송신기 케이스에 에반 동호회 배지와 개인 호출기 번호가 붙어 있다.

- 실제 전원연결.
- 장비 소유자.
- 사적 사용.

세 명제를 한 번에 건드린다.

무선일지는 통화시간만 남긴다.

## 힌지 단서 D — 줄리언의 접힌 비교지

네 자료 자체를 모두 전시하지 않고:

- 두 자료는 현장 실물.
- 한 자료는 줄리언이 기억으로 다시 그린 도식.
- 한 자료는 플레이어 사건아카이브에서 직접 열어 비교.

접힌 비교지에는 네 경우의 ‘사람이 덧붙인 자리’만 같은 붉은 표시가 있다.

- 줄리언이 서로 다른 자료를 비교 중이었음.
- 특정 학설 하나를 답으로 고르지 않았음.
- 정전은 원인이 아니라 비교를 중단 없이 이어간 시간창이었음.

을 함께 드러낸다.

## 삭제/병합

- C1/C2/C3/C4가 전력원인을 네 번 반복하지 않게 한다.
- D2~D5 네 자료의 출처설명은 2개만 현장에 남기고 나머지는 아카이브/기억도식으로 전환.
- ‘공통점’이라는 직접 해석어를 원자료에서 제거.

# 중간문제 v5.3 — 고밀도 선택형 넛지

1. **정전의 실제 전력경로** — 황색테이프 케이블, 발전기 소켓, 송신기 플러그, 마라 필름의 정전공백, 송신시각을 한 배전도에 겹친다. **결과:** 정상 발전기가 있는데도 송신부하 때문에 보조계통이 무너졌다는 인과와 에반 장비 연결이 함께 좁혀진다. 줄리언 사건은 아직 별개.
2. **줄리언의 네 번의 같은 표시** — 현장자료 2개, 기억도식 1개, 플레이어 아카이브 1개에서 줄리언이 같은 종류의 ‘덧붙인 자리’를 표시한 흔적을 대응한다. **결과:** 줄리언이 특정 학설을 찾은 게 아니라 서로 다른 자료의 같은 오류패턴을 비교 중이었다는 쪽으로 좁혀진다. 그 경험의 이름은 끝까지 요구하지 않는다.

‘두 사건 분리’는 별도 판이 아니라 두 판이 서로 다른 증거망을 가진다는 사실 자체로 체감하게 한다.

# 메인문제 v5.3

“[에반 트로]는 개인 [라디오 송신기]를 보조전원에 연결했고, 폭풍 때 송신부하가 겹치며 천문대가 약 [12분] 정전됐다. 같은 시간 [줄리언 룩]은 서로 다른 네 자료를 비교하면서 후대 사람들이 각 자료의 빈 자리에 덧붙인 부분들을 같은 붉은 표시로 묶었다. 정전은 그 비교의 원인이 아니라 중단 없이 계속된 시간이었다.”

# 검증

정전의 실제 전력경로 / 줄리언의 네 번의 같은 표시는 선택 검증한다. 메인사건문은 별도 검증하며 줄리언의 경험 자체를 정의하는 빈칸은 만들지 않는다.

# 제작 잠금표 v5.5 — 플레이어 비노출

- **정전:** 황색테이프 케이블의 연속 경로·발전기 소켓·에반 송신기 플러그·송신시각·부하계를 결합한다. 정상연료와 보호작동은 연료부족 가설을 탈락시킨다.
- **동시 사건:** 마라의 필름과 별지도는 12분을 독립 확인한다. 줄리언의 네 자료는 정전 전부터 모은 것이며 송신기와 물리적으로 분리된다. 정전은 그의 비교를 일으킨 원인이 아니다.
- **자료 부담:** 현장에 실제 놓인 두 자료, 기억도식 하나, 이전 사건 아카이브 하나를 비교한다. 네 장의 긴 문서를 새로 읽히지 않는다. 답은 ‘빈자리에 덧붙인 해석을 표시했다’는 행동이다.
