# 13F. 핵심 비교단서 물성·상태 정본

# 단서 제작 규칙

핵심 단서는 **원거리 실루엣**, **근거리 표면특징**, **다른 자료와의 비교축**, **사건 전후 상태**를 가진다. 구체적 수치가 사건 정본에 없는 경우 임의 mm·kg·시각을 더하지 않는다. 같은 단서의 대응면에는 크기·방향을 비교할 기준이 있어야 하되 ‘일치’ 캡션은 금지한다. 자연스러운 오답 재료는 두되 정답의 고유 특징을 복제하지 않는다.

# Stage 1~3

- **1 / 과제보드:** 4×4 격자와 자석의 돌출 촉각윤곽은 원거리에도 배열이 보인다. 확대 시 색·위치 기준의 실패와 촉각윤곽 기준의 일치가 동시에 확인된다. 01:34 프레임에는 멀쩡한 두 눈과 같은 보드가 함께 든다. 이전 달 스케치와 사건 당일 스케치는 같은 방을 대상으로 하되 원근·색면 유무가 다르다.
- **2 / Guest 자리:** 의자 형태는 평범해도 수프 막·가득 찬 잔·빠진 의자 각도가 한 묶음이다. 다른 다섯 자리는 각기 다른 사용흔적이 있다. 금고 빈 폭과 요나 가방의 빈 보존커버는 동일한 서류철 폭을 가리키되 정답 라벨은 없다. V홈 구두·묘지자국·창문턱 회색점토는 같은 오염층으로 연결.
- **3 / 두 번째 인물:** 운동화 별마모는 **한 켤레의 같은 밑창 패턴**으로 잔해 덧신 안 한 짝·탈의실 다른 짝·자재문 필름 부분 밑창에 반복. 은반지는 잔해와 리사 사진에 같은 얇은 형태. 반투명 골격은 골반 호와 왼 대퇴골 머리 중첩이 읽히되 두 몸의 전체 윤곽을 처음부터 깔끔히 분리하지 않는다. K-2 열쇠날과 소켓은 날 끝의 비대칭 홈으로 비교한다.

# Stage 4~7

- **4 / 회선:** 검은 패치선에는 목적지 번호를 달지 않는다. 잭 프레임의 104 출발위치, 362 도착위치, 카운터의 같은 배열을 따로 본 뒤 결합한다. 난간의 파란도료 긁힘은 높이·사선방향이 오린 뒤꿈치 도료와 대응. 네라 오른소매의 사선직조 한 올만 난간 섬유와 맞는다.
- **5 / 가방 세 개:** 모두 갈색이지만 ① 찌그러진 금속모서리·호텔 스티커 흔적, ② 손잡이 파란실·내부 청색잉크, ③ 바닥 붉은 밀랍·특송문양은 서로 교환하지 않는다. III권은 직접 이름표 대신 세 번째 권의 눌린 자리·끊어진 청색끈·압착테이프 찌꺼기로 부재를 보인다. 펠 쪽지의 4B/파란실/Q-3는 소유자 이름을 대신하지 않는다.
- **6 / 제본과 낙상:** B113은 112 다음 114가 인쇄됐어도 실이 연속. C42는 41·43 사이 실이 끊기고 불규칙 종이섬유. 황갈 섬유 속 **붉은 한 올**은 타렌 오른소매의 빈 실밥과 대응. 문고리의 회색 실과 당김방향, 세 젖은 발자국, 장삼 위 자신의 신발무늬, 난간의 접촉 부재는 각각 다른 시점의 물리흔적.
- **7 / 질량이동:** 22kg 기계추는 사다리꼴 손잡이·둥근 돌기 둘. G02 트레이 빈 압흔과 E09 폼 새 압흔이 이 형태에 맞는다. 석판은 E09의 넓고 얇은 직사각형 먼지선·검은 돌가루로 부재를 보인다. K-71 진짜 밀랍 세 갈래 균열과 현재 봉인·카스 금형의 네 갈래 균열을 구분. V자 화점은 배선 합선흔이나 난로 오래된 원형 그을음과 다르다.

# Stage 8~11

- **8 / 케이블과 비교지:** 케이블 긁힘과 황색테이프 **두 바퀴**가 모든 지역에서 같은 위치. 송신기 3핀 플러그와 발전기 비상출력 소켓의 긁힘이 대응. 트레이싱지 네 장의 붉은 원은 Case 44 소유자선, 세라 번역주어, 지안 보충명사, 석판 복원 인물상을 각각 둘러싸며 겹치면 거의 같은 자리에 온다. 원은 해석문이 아니다.
- **9 / 사진·녹음:** A 정상농도, B 윤곽 2mm 중첩, C 하단 유백 저수압 얼룩, D 전차 긴 수평광선은 순서판정에 서로 다른 기능을 가진다. 테이프 절단면이 맞는 쌍은 두 개뿐이며 현상액 얼룩·배경음으로 순서를 더 좁힌다. 마라 쪽 유리파편과 손상방향은 접촉 사고를 뒷받침하되 누가 밀었다는 문장을 그리지 않는다.
- **10 / 항로·자발성:** 표의 남색·금색 사선, 갈매기 셋, 세모 절취홈은 세 특징이 **모두** 맞는 배와만 연결. 부두 연속사진은 남색 타일→갈매기 아치→세모 게이트 순서. 산텔 화폐는 새 도안, 나머지 두 통화는 오래된 접힘과 구형도안. 가방은 셔츠·속옷 각 3벌, 소형 세면도구, 책 0권, 직업서류 원본 없음. Stage 8 질문카드와 치료 제출카드는 같은 물건. 단독 매표·직접 서명·단독 게이트 입장을 서로 다른 자료로 확인한다.
- **11 / 폭파·층위:** 벤 장비와 현장 조각은 3핀·주황 절연띠로, 다른 작업자의 2핀 유사품은 오답으로 분리. 카렐 회사 표식은 삼각 안 점 둘이 세 문서·클립에서 같은 배치. 천공축은 광맥 쪽 수평, 에이라는 직선 바깥, 낙석선은 천장 측면으로 이어진다. 회백층 조개·회색점토, 검은층 유리알갱이·길고 뾰족한 새뼈, 적갈층 철분띠·넓은 민물패각은 표본상자와 직접 비교. 중앙 공백 도상은 층별 실제 조각으로 분류한다.

# 단서 품질 합격선

- 첫 관찰에서 정답을 말하지 않고 물리적 이상을 느낄 수 있다.
- 확대 없이 위치·개수를 대략 찾을 수 있고 확대하면 표면특징이 확인된다.
- 다른 자료와 나란히 두면 일치 또는 불일치가 판정된다.
- 비교 단서의 고유 특징을 조연·배경 장식에 무작위 복제하지 않는다.
- 정답을 가리는 흐림·어둠·손가림은 금지한다. 어려움은 발견이 아니라 해석에서 만든다.
