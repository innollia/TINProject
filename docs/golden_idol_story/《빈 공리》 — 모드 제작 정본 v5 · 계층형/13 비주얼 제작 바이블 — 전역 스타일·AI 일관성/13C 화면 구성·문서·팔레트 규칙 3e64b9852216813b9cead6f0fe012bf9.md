# 13C. 화면 구성·문서·팔레트 규칙

# 사용 순서

1. 장면의 [01. 눈을 고친 사람 — 세인트 오린 대학](../01%20%EB%88%88%EC%9D%84%20%EA%B3%A0%EC%B9%9C%20%EC%82%AC%EB%9E%8C%20%E2%80%94%20%EC%84%B8%EC%9D%B8%ED%8A%B8%20%EC%98%A4%EB%A6%B0%20%EB%8C%80%ED%95%99%203e64b985221681058dbfc67bb24c4c2e.md) 같은 **해당 Stage v5.3 정본**에서 시점·인물행동·오브젝트 상태를 확정한다.
2. 13A 인물 정본과 13B 공간 정본에서 화면에 실제 보이는 식별점만 가져온다.
3. 이 페이지와 전역 13의 화풍·재질 규칙을 적용한다.
4. 인물의 얼굴·체형·착장·손습관은 13A의 고정/변주 규칙으로 확인한다. 그림체 규칙은 별도 제작 규칙뭉치가 적용한다.
5. C형 화면에서는 Macro(구조·동선), Meso(인물·물건), Micro(고유마모)가 한 화면 또는 명확한 확대계층으로 이어지게 한다.

# 화면 구성 규칙

- **구조:** A 인물판 / B 상황컷 / C 조사화면을 구분하고 카메라 높이, 출입구, 시선경로, 여백을 먼저 고정한다.
- **인물:** 얼굴·머리·의상 실루엣과 해당 순간의 손동작을 유지한다. 다른 장면의 부상·감정을 끌어오지 않는다.
- **공간:** 고정 평면과 재질, 기관별 디자인 언어, 생활·직업 물건을 유지한다.
- **단서:** 위치·방향·형태·마모·부재를 그린다. 범인이나 사건 의미를 설명하는 캡션을 쓰지 않는다.
- **빛·색:** 주광원 하나, 저채도 넓은 면, 작은 식별 포인트를 기본으로 한다.
- **품질 판정:** 해부학·시대·인물동일성의 실제 오류를 결과 화면에서 확인한다.

# 문서·라벨 제품군
- **대학·학술:** 아이보리 두꺼운 종이, 올리브/남색 상단선, 작은 일련번호와 연구자 수기정정. 스케치·시험지는 기관양식과 개인필기를 구별.
- **N153:** 회청 금속판과 황색 안전표식, 각인 번호, 붉은 수정잉크. 인터록·키·봉투의 같은 번호문법. 지나치게 현대적 화면 UI 금지.
- **교환국:** 크림 기록카드, 촘촘한 번호격자, 먹갈 패치잭. 잭번호는 프레임에, 케이블 자체에는 목적지명 없음.
- **철도·항만·터미널:** 절취선, 펀칭, 선사·철도 문장, 바랜 인쇄색. 표와 짐표의 물리 규격은 같은 기관 안에서 반복.
- **사원:** 섬유와 실이 보이는 제본, 눌린 먹, 페이지 마모. B113 결번과 C42 찢김은 **다른 제본 단면**으로 구분.
- **천문·사진:** 눈금·필름·화학 얼룩이 정보다. 사진에 답인 시간을 인쇄하지 않고 실제 현상상태를 그린다.
- **발굴:** 물에 젖은 현장라벨, 흰 라벨끈, 표본번호 스티커. 표본상자에는 정답 지층명을 선제 표기하지 않는다.

# 관계형 팔레트

장면마다 바탕 2색, 보조 2색, 강조 1색을 기본으로 한다. 인물 대표색은 배경 같은 색군 안에서도 명도·채도·면적을 달리해 분리한다. 단서 강조색은 식별색과 경쟁하지 않게 작은 면적으로 둔다.

- 대학: 올리브·황토 / 아이보리·회청 / 은회 핀.
- 저택: 적갈·먹녹 / 포도주·황동 / 사용흔적의 회색 점토.
- N153: 냉회·탁청록 / 고무검정·황색 / 국소 붉은잉크.
- 교환국: 먹갈·크림 / 철회·황동 / 난간 파란도료.
- 열차: 회청·갈색 / 크림·황동 / 파란실.
- 사원: 젖은 목재·회석 / 황갈종이·먹색 / 붉은 실 한 올.
- 항만: 청회·적갈 / 검은 돌가루·황동 / 붉은 검사분필.
- 천문대: 남회·아이보리 / 검은 고무·붉은 야간등 / 황색 케이블테이프.
- 사진관: 크림·적갈 / 검보라·젖은 회금속 / 국소 안전등 적색.
- 터미널: 청회·적갈 / 크림·황동 / 남색·금색 승선권.
- 동굴: 적갈·회백 / 검은 유리질·젖은 캔버스 / 주황 안전장비.

# C형 조사화면의 정보 배치

- **원경:** 출입구·높이차·사람 위치와 이동 가능한 통로가 읽힌다.
- **중경:** 인물 복장, 가구, 상자, 가방, 작업도구의 소유·사용상태가 읽힌다.
- **근경:** 같은 물건의 고유 흠집, 봉인선, 접힘, 얼룩, 실밥을 다른 화면의 대응물과 비교할 수 있다.
- 비교 대상끼리 크기나 방향이 달라 헷갈릴 경우 같은 기준면을 하나 제공한다. 그 기준면이 정답표가 되면 안 된다.
- 첫 화면은 합리적 오답가설을 허용하고, 다른 지역을 본 뒤 같은 화면을 재해석할 수 있어야 한다.

# 생성 단위
- 캐릭터판은 13A의 식별 5점과 허용 변주 확인용이다.
- B형 상황컷은 인물 행동과 직업·관계 소품에 집중한다.
- C형 조사화면은 오브젝트 각각을 예쁘게 정렬하는 그림이 아니라 동선·부재·흔적의 관계가 읽히는 화면이다.
- 문서 클로즈업은 본문 텍스트만이 아니라 종이폭·접힘·제본·클립·인장의 물리상태까지 관리한다.
- 같은 컷을 다시 제작할 때도 오브젝트의 고유마모와 좌우방향을 고정하고 장면에서 달라진 상태만 바꾼다.
