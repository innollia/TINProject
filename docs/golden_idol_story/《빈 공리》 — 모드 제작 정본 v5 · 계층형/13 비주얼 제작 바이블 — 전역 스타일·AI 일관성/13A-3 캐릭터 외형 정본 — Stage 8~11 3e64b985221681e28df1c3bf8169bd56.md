# 13A-3. 캐릭터 외형 정본 — Stage 8~11

# Stage 8 — 하르트 산 천문대

## 줄리언 룩 / 인지철학 강사

**한 줄 인상:** 얌전한 학자 실루엣 안에, 무언가를 연결한 뒤부터 손과 시선의 속도만 비정상적으로 빨라지는 사람.

- **얼굴:** 긴 타원형, 높은 콧대, 얇은 입술. 오른쪽 눈 아래 피로선이 더 깊다. 웃을 때 입보다 눈이 먼저 움직이지 않는다.
- **머리:** 짙은 갈색, 약간 길어 귀를 덮는 직모. 오른쪽 가르마, 앞머리 한 가닥이 자주 눈 근처로 내려온다.
- **복장:** 회청색 셔츠, 짙은 갈색 조끼, 회갈 바지, 추울 때 어두운 울코트. 소매 끝에 붉은 표시펜 얼룩.
- **색:** 회청 #596874 / 갈색 #665248 / 포인트 붉은잉크 #8F3B3E.
- **대표 소품:** 붉은 표시펜, 접힌 비교지, 얇은 질문카드 묶음.
- **손 습관:** 생각이 깊어질수록 카드 모서리를 맞추지 않고 부채꼴로 펼침. 발견 직후에는 붉은 펜을 닫지 않은 채 손에 쥔다.
- **표정 범위:** 평소 침착 / 집중 시 눈꺼풀 올라감 / 발견 직후 눈이 커지기보다 동공이 고정되고 입꼬리가 올라감 / 전달 실패 후 턱 근육이 굳음.
- **식별 5점:** 긴 직모 / 높은 콧대 / 갈색 조끼 / 붉은 표시펜 / 질문카드.
- **절대 고정:** 오른쪽 가르마, 오른눈 아래 깊은 피로선, 붉은 펜.
- **장면 변주:** Stage 8은 비교자료에 몰입, Stage 9는 피로·초조, Stage 10은 단정한 여행복과 의도적으로 정리된 짐.
- **금지:** 광기 어린 과장표정, 천재 괴짜처럼 흐트러진 백발, 과도한 미소년화.

- **얼굴:** 부드러운 사각형, 코끝이 약간 넓고 눈썹은 곧음. 왼쪽 눈 아래 아주 옅은 주근깨 군집.
- **머리:** 짙은 흑갈색, 쇄골 길이의 거친 웨이브. 앞머리 없이 왼쪽 가르마.
- **복장:** 바랜 자주빛 셔츠, 암회 작업바지, 크림색 사진조끼. 암실에서는 소매를 걷음.
- **색:** 바랜 자주 #765866 / 암회 #4D5052 / 크림 #C8BDA7.
- **대표 소품:** 폴딩 카메라, 필름통, 사진집게, 검은 연필.
- **손 습관:** 듣는 동안 사진 모서리를 엄지로 톡톡 두드림. 반박할 때 턱을 조금 들고 눈을 바로 맞춤.
- **식별 5점:** 쇄골 웨이브 / 곧은 눈썹 / 사진조끼 / 폴딩 카메라 / 주근깨 군집.
- **절대 고정:** 왼쪽 가르마, 사진조끼의 큰 하단포켓, 카메라 스트랩 폭.
- **Stage 9 추가 상태:** 오른손 손바닥 절상 후 붕대. 상처는 국소적이고 과장 금지.

# Stage 9 — 마라의 사진관

**신규 인물 없음.** 줄리언과 마라의 외형은 Stage 8 정본을 그대로 유지한다.

## Stage 9 연속성 추가

- 줄리언: 머리는 더 흐트러지되 길이·가르마는 동일. 갈색 조끼는 그대로, 코트는 앞 스튜디오 의자에 걸려 있을 수 있음. 붉은 펜은 셔츠 포켓.
- 마라: 사진조끼 또는 암실 앞치마를 추가하되 기본 자주 셔츠는 유지. 마지막 구간 오른손에 붕대 전 단계의 피묻은 천 조각 가능.
- 두 사람 모두 장면 감정 때문에 얼굴형·눈 크기를 과장 변경하지 않는다.
- 안전등 붉은 조명은 피부색 전체를 적색으로 덮지 않고 그림자면과 금속·유리 가장자리에만 국소 반영.

# Stage 10 — 포르테 국제여객선 터미널

**신규 주요 인물 없음.** 줄리언 룩의 여행 상태를 별도 고정한다.

## 줄리언 / 여행 상태

- 기존 회청 셔츠와 갈색 조끼 유지.
- 어두운 울코트는 락커에 남겨져 있으므로 게이트 이후 장면에서 착용 금지.
- 작은 갈색 여행가방 1개만 소지.
- 머리와 얼굴은 Stage 8~9와 동일하되 수면부족으로 눈 아래 그림자만 조금 깊어짐.
- 질문카드는 정돈된 종이봉투에 넣음. 스테이지 8의 카드 형태·크기·인쇄방식 유지.
- “도주자처럼 초조한 자세”보다 의도적으로 움직이는 차분한 자세. 매표·환전·게이트 사진에서 스스로 행동을 시작하는 손 위치가 중요.

# 군중·단역 생성 규칙

- 동일 얼굴 복제 금지. 얼굴형을 원형/긴형/사각형/역삼각형으로 분산한다.
- 핵심 인물의 대표색과 동일한 고채도 포인트를 단역에게 주지 않는다.
- 단역은 핵심 인물보다 실루엣 세부를 20~30% 단순화한다.
- 제복 단역은 기관 공통복식을 따르되 신발 마모·소매 길이·머리 형태 정도로 생활차이를 둔다.
