# 13G. 기관 문서·기계 라벨 시각 규격

# 공통 인쇄문명

이 세계는 두꺼운 종이·금속·베이클라이트·천·가죽이 주재료다. 기관마다 다른 표색을 쓰지만 인쇄활자, 수기 정정, 판번호, 사용흔적의 문법은 같다. 현재 Stage 정본에 적힌 실제 코드·번호·시각을 우선하며, 이 페이지는 누락된 정답 정보를 새로 쓰지 않는다.

# 서식의 네 층

1. **기관 식별:** 상단 또는 좌상단의 기관명/문장. 한 기관 안에서 위치를 바꾸지 않는다.
2. **문서 유형:** 접수·검사·작업·개인메모·표/티켓을 테두리·행간·종이폭으로 구별한다.
3. **개별 식별:** 사건에 필요한 기존 번호, 도장, 펀칭, 절취형. 임의 새 코드가 추리의 답으로 작동하지 않게 한다.
4. **사용 이력:** 접힘·클립자국·잉크 눌림·얼룩·찢김·마름 정도. 사건 전후 컷에서 같은 손상을 유지한다.

# 기관별 고정 서식

- **세인트 오린 대학:** 먼지 낀 아이보리 종이와 가는 올리브 또는 남색 상단선. 실험지는 4×4 보드의 도형과 구별되는 인쇄 격자. 수기 연필기록은 연구자마다 필압과 여백 사용이 다르다. 이전달 스케치북은 연구실 도면지와 같은 방 구조.
- **모렌 저택·법률:** 저택 문장은 가족 자리 등받이와 공식 유언 관련 표지에만. 가족사진 뒷면의 사적 필기와 법률문서의 정렬을 구분한다. Case 44 병원기록은 오래된 두꺼운 철로, 현재 유언장과 종이폭·마모가 달라야 한다.
- **N153:** 번호 플레이트와 문서 우상단 태그가 같은 각인체계를 쓴다. 회청 바탕, 제한적 황색 안전띠, 붉은 수정잉크는 실제 수정에만 사용. K-2 키날의 실루엣은 대여판과 인터록에서 같게. 외부보고 초안과 봉투는 종이·도장·잉크 건조상태로 작성 순서를 비교할 수 있어야 한다.
- **벨마 교환국:** 번호는 잭 프레임과 기계식 카운터의 같은 열·행 배열로 표시. 케이블에는 목적지 번호를 직접 붙이지 않는다. 통화표는 요청값, 장치 카운터는 실제 사용값을 보여 주는 다른 매체. 카드·헤드셋·패치선의 수선흔은 현장 사용감을 준다.
- **라크 익스프레스:** 승차권·침대배정표는 철도 활자와 절취/펀칭으로 통일. 수하물표에는 소유자 정답을 직접 적지 않는다. 급송 가방의 밀랍은 일반 여행가방의 손잡이실·스티커 흔적과 다른 식별축이다.
- **해월사:** 경전 B권의 B113은 인쇄상 결번이나 제본실 연속, C권의 C42는 제본실 파열과 종이섬유가 있는 실제 결손. 번역초안 A/B의 보충명사는 먹색·여백·수정선이 같은 필자 작업에서 나온 것으로 유지. 문헌의 종교 문양은 사건 정답을 상징으로 설명하지 않는다.
- **카르민 세관:** 검사기록은 붉은 분필·저울 종이테이프·밀랍봉인이라는 서로 다른 매체로 남는다. K-71 진짜 봉인과 재압착 봉인은 균열 갈래 수로 구별. 수입허가서·인수목록·보험서류는 기관별 표제·인장 위치가 다르다.
- **하르트 천문대:** 계기판은 아이보리, 야간 표시등은 제한적 적색. 정상 배전도에는 비인가 케이블을 미리 그리지 않는다. 별지도·접안부·필름은 같은 하늘 방향을 공유. 줄리언 비교자료의 붉은 원은 기관공문이 아니라 개인 표시다.
- **마라 사진관:** 사진 A~D에는 사건 시간을 직접 인쇄하지 않는다. 필름 가장자리, 현상액 얼룩, 확대기 흔적, 전차광선이 시간자료로 작동한다. 카세트 조각의 절단면과 얼룩을 복제 가능하도록 관리. 메모의 수기번호를 정답순서로 붙이지 않는다.
- **포르테 터미널:** 승선권의 선사 색·갈매기 세 마리 문장·세모 절취홈은 전광판 옆 선박도해 및 게이트와 같은 체계. 환전영수증은 통화기호와 지폐 도안비교를 요구. 접수봉투와 치료 안내는 의료기관의 다른 서식이며 ‘자발적’ 정답 라벨을 도장처럼 찍지 않는다.
- **타르 발굴:** 표본라벨은 물기·진흙·흰 라벨끈이 있는 현장용, 회사 광맥지도는 점 두 개 든 삼각표식이 있는 상업용, 발파쪽지는 접힌 사적 작업메모. αβγ 상자에는 정답 지층명 라벨 금지. 도상 분류 트레이는 실제 조각의 수량을 숨기지 않되 자동 카운트 텍스트를 붙이지 않는다.

# 금지와 검산

- 기관 디자인이 비슷하다는 이유로 문장·번호체계를 서로 복사하지 않는다.
- 물리적으로 다른 시점의 문서는 잉크 마름·손때·찢김이 시간순서와 모순되면 안 된다.
- 한 장의 문서가 정답의 사람·행동·시각을 전부 말하게 하지 않는다.
- 문서 확대 컷에서도 종이 전체의 방향·모서리·봉인 위치가 원경과 일치한다.
- 모든 장식문양에 추리 기능을 부여하지 않는다. 직업과 생활의 반복이 먼저, 사건 의미는 소수의 물리적 차이에서 생긴다.
