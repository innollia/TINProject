# 01. 눈을 고친 사람 — 세인트 오린 대학

# 스테이지 개요

**장소:** 세인트 오린 대학 시지각 연구실 4층 / 1996-03-12 02:13  

**첫 화면의 국소 모순:** 눈 자체는 방금 전까지 정상인데, 미라는 이미 ‘보는 행동’을 전혀 수행하지 못했고 그 뒤 자기 눈을 손상시켰다.  

**독립사건의 질문:** 언제부터 이상했는가 / 누가 눈을 손상시켰는가 / 왜 그 행동이 본인에게 합리적이었는가.  

**장기 변화:** ‘기관은 정상이어도 특정 경험 전체가 사라질 수 있다’까지만 확정. 원인명은 주지 않는다.

# 등장인물

- **미라 벤, 26 / 시지각 연구원** — 짧은 흑갈색 머리, 왼쪽 귀 뒤 은색 핀 2개, 녹색 스웨터 위 흰 실험복. 동사를 네모로 둘러쓰는 필기습관.
- **토마스 그렐, 48 / 연구책임자** — 마른 체격, 남색 조끼, 금속테 안경, 가슴주머니에 펜 3자루.
- **에드 파로, 61 / 야간경비** — 회색 제복, 큰 열쇠고리. 연구동 사람 이름에는 서툼.
- **리나 오르, 22 / 학부조교** — 붉은 목도리, 실험참가자 명단을 들고 다님.

# 지역 A — 주실험실 · 쿼터뷰

**이미지 설명:** 중앙 실험대 아래 응급붕대를 감은 미라. 한 손에는 깨진 투명 렌즈 케이스. 왼쪽 벽에는 시각자극 모니터, 오른쪽에는 그렐이 피 묻은 손으로 응급도구를 정리한다. 문 쪽에는 에드가 서 있다.  

**지역 기능:** 첫인상에서 렌즈사고 / 폭행 / 약물 / 자해를 모두 살려 둔다.  

**상호작용 종류:** 인물, 물건, 장치, 혈흔.

- 오브젝트 A1 — 미라 벤 · 인물
    
    **이미지 설명:** 실험대 아래 반쯤 기대어 앉아 있고 양 눈은 붕대. 녹색 스웨터 소매에 소독약 자국.
    
    **대사:** “눈이 잘못된 것 같아서… 확인하려고 했어요. 그렐이 자꾸 손대지 말라고 해서.”
    
    **얻는 단어:** 미라 / 눈
    
    **기능:** 미라 자신이 ‘눈의 고장’으로 해석했다는 주장만 준다. 원인 진술로 취급하지 않는다.
    
- 오브젝트 A2 — 깨진 렌즈집 · 물건
    
    **이미지 설명:** 투명 원형 렌즈 두 장 중 하나가 깨져 있음. 케이스 측면에 EYE TRACK MARKER / 0.00 각인.
    
    **내용:** 도수 0.00. 시력교정렌즈가 아니라 안구추적용 표식 렌즈.
    
    **얻는 단어:** 렌즈 / 추적 / 0.00
    
    **기능:** ‘잘못된 도수 때문에 못 봄’ 가설을 죽인다.
    
- 오브젝트 A3 — 시각자극 장치 · 장치
    
    **이미지 설명:** 12칸 변화탐지 과제가 정지된 CRT. 옆 프린터에 두 장의 출력지.
    
    - 하위 A3-1 — 장비 교정 출력지 · 문서
        
        **내용:** 섬광자극 입력 파형은 기준범위.
        
        **얻는 단어:** 입력 / 정상이다
        
    - 하위 A3-2 — 행동응답 출력지 · 문서
        
        **내용:** 같은 시간 화면 변화 탐지 0 / 12.
        
        **얻는 단어:** 화면 / 응답
        
    
    **기능:** 장비 입력은 정상인데 행동응답은 0이라는 모순.
    
- 오브젝트 A4 — 그렐의 피 묻은 손 · 인물/흔적
    
    **대사:** “내가 발견했을 땐 이미 그랬어. 눌러서 지혈했을 뿐이야.”
    
    **얻는 단어:** 토마스 / 거즈
    
    **기능:** 폭행 오도를 만든다. D지역 소독도구와 함께 반증.

## 필수 비수집형 시각단서

### VISUAL 1 — 사건 전 카메라 프레임

01:34 프레임에서 미라의 양 눈이 멀쩡히 떠 있는 모습과 벽의 과제보드가 동시에 보인다.

획득단어 없음. Hotspot 없음. 플레이어가 B지역 CCTV 정지화면과 A지역 벽보드를 직접 비교해야 한다.

### VISUAL 2 — 시각과제 보드

4×4 색/도형 배열의 정답키와 미라가 꽂은 자석 배열이 한 화면에 있다. 문자는 없다.

미라의 배열은 색·위치 기준으로는 거의 전부 틀리지만, 돌출된 모양의 촉각윤곽이 같은 칸끼리는 맞는다.

획득단어 없음. ‘시각행동 실패 / 촉각식별 보존’은 이 그림을 보고만 얻을 수 있다.

### VISUAL 3 — 이전 달 스케치북 ↔ 사건 당일 스케치

이전 달: 연구실을 원근법으로 정확히 그린 연필스케치.

사건 당일: 같은 방을 그리라는 과제에 물건 이름을 적은 작은 표식과 손으로 더듬은 윤곽만 남고 원근·색면이 사라져 있다.

획득단어 없음. IMAGE ↔ IMAGE 비교 필수.

## 기존 텍스트 단서 수정

- B1 눈검사 카드는 동공·망막 검사 정상까지만 문자로 말한다. 문자판독 실패 / 촉각 9/10 문장은 삭제하고 실제 결과는 VISUAL 2로 이동.
- B3 실험기록의 문자판독 중단 / 촉각식별 9/10 수치도 삭제. 시간과 “입력선 재점검, 이상 없음”만 남긴다.
- C3 사물명명카드는 텍스트 정답표가 아니라 실제 그림카드 묶음으로 구현한다. 플레이어가 어떤 그림만 반복해서 설명하지 못했는지 직접 본다.
- D1은 “미라 지문만”이라고 자동해석하지 않는다. 손잡이에 남은 오른손 엄지의 피묻은 소용돌이 지문과 미라의 연구동 출입지문카드를 IMAGE ↔ IMAGE로 비교한다.

## TEXT-ONLY FAIL

문서·대사만 읽으면 시각처리 이상 / 약물 / 렌즈사고 / 자해 후 이상 중 적어도 둘이 남는다.

VISUAL 1 + VISUAL 2를 봐야 ‘눈을 다치기 전에 이미 시각행동이 무너졌다’가 확정된다.

## Word Pool 규칙

시각경험 / 부품고장 / 손상시켰다처럼 정답을 미리 말하는 해석토큰은 첫 수집 때 주지 않는다.

경쟁 표현을 함께 둔다: 고장났다 / 가려졌다 / 다쳤다 / 제거했다 / 확인했다 / 착각했다 / 망가뜨렸다.

메인판의 모든 문법슬롯은 처음부터 사용할 수 있다. 시각증거를 보지 않으면 ‘스스로’를 고를 근거가 부족할 뿐이며, 중간문제 완료 여부와는 무관하다.

## 힌지 단서 A — 01:34 CCTV 한 프레임

한 프레임 안에 **정상인 두 눈 / 실패한 시각과제보드 / 미라가 보드를 손으로 더듬은 자세**가 동시에 들어간다.

- 시간: 눈 손상 전.
- 상태: 눈 자체는 외견상 정상.
- 행동: 시각 대신 촉각전략 사용.
- 오답반박: 렌즈파손이 최초 원인이라는 가설 약화.

즉 B1 검사표·B3 실패기록·촉각성공 기록 세 개를 따로 두지 않고 이 프레임이 세 명제를 묶는다.

## 힌지 단서 B — 이전달 스케치 ↔ 당일 스케치

같은 장소를 그린 두 장이:

- 예전에는 원근/색/배치가 살아 있음.
- 당일에는 손으로 만진 윤곽과 사물명만 남음.

이 한 비교가 **후천적 변화 / 시각심상 손실 / 언어지식 보존**을 동시에 건드린다.

C3 명명카드는 보조단서로 약화한다.

## 힌지 단서 C — 소독도구의 지문 + 정비카드

도구 손잡이의 미라 지문만으로 자해를 확정하지 않는다.

같은 손의 기름때가 정비카드의 ‘입력부부터 분리’ 문장 옆에도 묻어 있어,

- 도구를 잡은 사람 = 미라.
- 사고 직전 장비수리 사고방식을 반복해 읽음.
- 그렐 폭행설 약화.

를 한 번에 만든다.

## 삭제/병합

- B1과 B3의 ‘행동실패’ 중복 수치 하나 삭제.
- C3 명명카드는 4장만 남겨 언어보존의 보조확인으로 축소.
- D2 복사기 로그는 리나 알리바이의 유일근거가 아니라 CCTV 배경시계와 겹쳐 보조근거로만 둔다.

# 중간문제 v5.3 — 고밀도 선택형 넛지

1. **01:34 상태복원** — CCTV 프레임 위에 과제보드 정답키와 미라의 자석배치를 겹친다. 한 판에서 눈 손상 전 / 시각과제 실패 / 촉각전략 사용 / 장비입력 정상 네 사실을 동시에 정리한다. **결과:** “눈을 다쳐서 못 봤다” 가설은 크게 약해지지만, 왜 그런 상태인지와 누가 눈을 다쳤는지는 남는다.
2. **정비식 사고 대응도** — 정비카드의 INPUT→PART→OUTPUT 도식에 미라가 실제로 점검한 물건과 소독도구 흔적을 놓는다. **결과:** 미라가 자기 상태를 장비고장처럼 다뤘을 가능성과 자가행동 가능성이 동시에 올라간다. 그렐 폭행설도 약해진다.

두 판 모두 생략 가능. 메인문제는 처음부터 입력 가능하며, 판이 새 증거를 주지 않는다.

# 메인문제 v5.3

“[미라 벤]은 눈이 멀쩡한 01:34에도 화면 과제를 거의 수행하지 못했지만 손으로 만진 도형은 구별했다. 그는 장비의 입력부를 분리해 고장을 찾던 자신의 정비방식대로 몸의 문제를 확인하려 했고, 이후 [스스로 눈을 손상시켰다].”

# 검증

01:34 상태복원 / 정비식 사고 대응도는 각각 선택 검증한다. 둘을 건너뛰어도 메인 사건문은 언제든 독립 검증 가능하다.

# 제작 잠금표 v5.5 — 플레이어 비노출

- **시간·상태:** 01:34의 CCTV와 과제보드를 먼저 맞춘다. 눈 손상은 그 뒤다. 정상 입력·촉각 성공·시각 실패가 함께 있어야 ‘손상 때문에 처음 못 봤다’와 ‘장비 입력 오류’가 탈락한다.
- **행위자·이유:** 손잡이 혈흔/지문·출입기록으로 미라의 자가행동을, 그렐의 위치와 토마스의 거즈로 폭행·응급처치 가설을 분리한다. 정비카드와 이전 스케치가 ‘왜 눈을 점검 대상으로 여겼나’를 설명한다.
- **정답 한계:** 의학적 원인명은 이 장의 답이 아니다. 플레이어용 클릭창은 관찰값과 원문만 보여 주고 ‘시각경험 결손’이라는 해설은 주지 않는다.
