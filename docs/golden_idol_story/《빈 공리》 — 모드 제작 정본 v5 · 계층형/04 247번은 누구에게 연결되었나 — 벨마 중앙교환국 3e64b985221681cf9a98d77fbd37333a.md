# 04. 247번은 누구에게 연결되었나 — 벨마 중앙교환국

# 스테이지 개요

**장소:** 벨마 중앙 수동전화교환국 / 1996-04-17 23:48  

**첫 화면의 국소 모순:** 학술원은 247로 전화를 걸어 본인에게 거절을 받았다고 기록했지만, 247의 집에서는 벨이 한 번도 울리지 않았다. 죽은 감독 오린의 메모에는 247 / 362가 함께 적혀 있다.  

**독립사건의 질문:** 요청번호와 실제 연결번호 / 전화를 받은 사람 / 조작자 / 오린이 발견한 것 / 실제 사망원인과 위장.  

**장기 변화:** 주 사건과 무관한 23:14 장거리통화에서만 세라 퀼과 이상한 번역문제가 스친다.

# 등장인물

- **오린 벨 / 야간감독, 피해자** — 57세, 짙은 회색 조끼, 은색 회중시계, 이상통화에 붉은 삼각형.
- **네라 홀트 / 제2교환석 교환원** — 30세, 검은 단발, 200번대 지역회선과 외부중계선 담당.
- **주나 렐 / 제1교환석 교환원** — 23세, 노란 리본, 긴급회선 담당.
- **브람 케스 / 선로정비기사** — 42세, 회색 작업복, 절연공구, 회선시험기.
- **토마 렌 / 야간전보원** — 19세, 청색 모자, 전보가방.
- **레다 홀트 / 예비합격자, 현장 밖** — 네라의 여동생. 폐업한 독서실의 옛 전화 362를 그날 밤 사용.

# 직책 규칙

- 전화교환원: 요청번호를 실제 목적지 잭에 연결.

- 전보원: 문서 운반, 교환패치 권한 없음.

# 시각추론 정본 v5.1 — 구현 시 이 절이 상위 설명보다 우선

## 0클릭 장면

교환홀 첫 화면에는 수십 개 패치선이 얽혀 있고, 제2석의 검은 선 하나만 정리걸이에 돌아가지 않은 채 아래쪽 잭으로 늘어져 있다. 오린의 시신 옆에는 고전압 점검표가 놓여 있지만 분전반 경고등은 정상색이다.

첫 화면만으로 배선 실수 / 고의 전환 / 감전사고 / 추락사고 가설이 경쟁한다.

## VISUAL SYSTEM 1 — 교환대 배선 추적

A2의 금속태그 362는 클릭하면 읽을 수 있다.

교환대에는 247·362를 포함한 여러 번호의 잭과 번호표가 있다. 숫자는 후보로 얻고, 검은 선이 실제로 꽂힌 잭은 경로를 따라 확인한다.

플레이어는 23:21 통화표의 출발선 104 위치를 확인한 뒤 **검은 패치선을 눈으로 따라가 실제 꽂힌 물리 잭 위치를 찾아야 한다.**

선은 다른 선 두 개 뒤로 지나가므로 Overview와 확대화면을 번갈아 봐야 한다.

획득단어: 362. 이 숫자가 요청번호인지 실제 연결번호인지는 아직 확정되지 않는다.

## VISUAL SYSTEM 2 — 잭 사용카운터

D1은 “247=0 / 362=1”을 문장으로 표시하지 않는다.

번호별 작은 기계식 카운터가 교환대와 같은 배열로 놓인다. 플레이어가 **교환대 잭배열 그림 ↔ 카운터 배열**을 비교하여 247 위치는 그대로, 362 위치만 한 칸 증가했음을 읽는다.

획득단어 없음.

## VISUAL SYSTEM 3 — 오린 사망경로

케이블 갤러리의 난간에는 파란 페인트가 긁힌 높이와 방향이 남고, 오린 신발 바깥쪽 뒤꿈치에 같은 파란 페인트가 사선으로 묻는다.

분전반 손잡이에는 그을음이 없고 장갑 손바닥에도 아크흔적이 없다.

‘추락’이라는 단어는 수집하지 않는다. **신발 ↔ 난간 높이·각도** 비교로 몸이 난간을 넘은 방향을 판정한다.

## VISUAL SYSTEM 4 — 네라 식별

난간 반대편에 남은 검은 섬유는 자동으로 ‘네라 제복’이라 설명하지 않는다.

교환홀 인물들의 제복 소매단을 확대 비교하면 네라 소매만 같은 사선직조 + 한 올이 뜯긴 상태다.

IMAGE ↔ IMAGE 비교 필수.

## 기존 텍스트 단서 수정

- B5 오린 메모는 “104 → 247 ? / 표는 맞는데 선이 다름 / 재시험”으로 둔다. 숫자 362는 A2와 다른 자료에서 직접 얻을 수 있지만, 메모 한 장에 요청·실연결·조작자가 모두 적히지는 않는다.
- D2 회선시험표의 362 숫자는 유지 가능하나 “네라가 362를 시험했다”는 해석은 쓰지 않는다. 어느 좌석에서 난 시험인지는 교환대 좌석배치와 시험기 케이블 방향으로 본다.
- E2 “감전이면 퓨즈가 끊어져야 함”은 안전규정 문서에서 규칙으로 제공하고, 실제 퓨즈상태는 이미지로만 본다.
- E3의 “감전화상 없음 / 파란 도료” 자동해석 문장 삭제.

## REGION GRAPH

## 힌지 단서 B — 22:53 시험흔적

362 카운터의 미세마모 + 시험기 케이블 위치 + 네라 교대시간이 한 장면에서:

을 동시에 만든다.

‘네라가 시험했다’는 문장 자체는 없다.

## 힌지 단서 C — 난간 파란도료

오린 뒤꿈치의 파란 사선도료 + 난간 긁힘 + 네라 소매 한 올이 같은 접촉지점에 모인다.

- 감전이 아니라 난간을 넘는 물리사고.
- 오린과 다른 사람이 근접접촉.
- 네라가 갤러리에 있었음.

세 명제를 동시에 움직인다.

고전압 점검표는 그래서 위장물로 의미가 뒤집힌다.

# 중간문제 v5.3 — 고밀도 선택형 넛지

1. **247 요청의 실제 경로** — 104 통화표, 검은 패치선, 362 사용흔적, 본인확인 규칙을 한 교환도에 겹친다. **결과:** 요청번호≠실제 연결번호 / 사칭 가능 / 제2석 관여가 동시에 좁혀진다. 수신자와 조작자는 아직 이름으로 확정하지 않는다.
2. **오린의 마지막 5분** — 재시험메모, 감독실→갤러리 동선, 난간도료·신발흔·소매섬유, 고전압 점검표를 한 현장도에 배치한다. **결과:** 감전설은 약해지고 “불일치 발견 후 누군가와 근접접촉하다 난간을 넘었다”는 사건형태가 생긴다. 위장행위자 확정은 남긴다.

조작자판·사망판·위장판을 따로 두지 않는다.

# 제작 잠금표 v5.5 — 플레이어 비노출

- **번호 대응:** 247과 362는 통화표·번호표·시험표에서 직접 얻는다. 요청번호, 실제 잭, 시험번호, 수신자 번호의 칸을 분리한다. A2의 362만으로 ‘247 요청이 362에 연결됐다’고 판정하지 않는다.
- **사칭·조작자:** 선의 물리 경로와 카운터가 실제 연결을, 통화시각/제2석 시험/좌석동선이 네라를, 레다의 위치·목소리·응시 이해관계가 수신자를 특정한다. 브람의 시험권한은 정비와 통화 목적지 조작을 구별하는 오답축이다.
- **사망:** 난간 도료·신발흔·소매섬유와 퓨즈상태를 비교해 추락과 감전위장을 분리한다. 클릭창은 번호·흔적만 보여 주며 ‘같은 섬유’ 판정문은 금지한다.
