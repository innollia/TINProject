# 02. 모렌가의 빈 의자 — 모렌 저택

# 스테이지 개요

**장소:** 오스왈드 모렌 개인저택 / 1996-04-05, 장례식 직후 저녁  

**첫 화면의 국소 모순:** 서재 금고는 열려 있는데 유언장은 남아 있고 오래된 병원기록만 사라졌다. 동시에 식탁의 Guest 의자 하나가 비어 있다.  

**독립사건의 질문:** 실라를 재운 사람 / 서재에 침입한 사람 / 두 사람의 목표 / 빈 의자의 주인.  

**장기 변화:** 사건 해결 후에만 1958년 Case 44가 남는다. 범행 해결에는 필요 없다.

# 등장인물

- **오스왈드 모렌 / 고인** — 은퇴한 정신과의. 1950~70년대 사설요양원 근무.
- **헬렌 모렌 / 장녀·의사** — 검은 상복, 목에 의사용 펜라이트를 습관처럼 걸고 있음.
- **루카 모렌 / 장남** — 짙은 갈색 상복, 오른손 소매에 약국 종이봉투.
- **에바 모렌 / 루카의 아내·재산관리** — 은색 장부클립, 열쇠모양 브로치.
- **실라 베크 / 법률대리인** — 회색 정장, 서류가방, 금고열쇠 목걸이.
- **요나 페일 / 전직 간호사·조문객** — 낡은 간호핀을 코트 안쪽에 달고 있음, 묘지흙 묻은 구두.
- **피터 론 / 집사** — 검은 조끼, 허리의 집사 열쇠판.

첫 화면만으로 “누군가 식사 도중 빠져나감 / 유언장이 목표였는데 실패 / 애초 다른 서류가 목표” 가설이 경쟁한다.

## 필수 비수집형 시각단서

### VISUAL 1 — 여섯 자리의 사용상태

이름표를 없앤다. 다섯 좌석은 사용흔적이 서로 다르고, 하나만 완전 미사용.

세 가족 좌석의 의자 등에는 모렌가 문장, 실라 자리에는 서류가방이 걸려 있고, 피터 자리에는 집사 앞치마 고리가 있다.

남는 평의자 하나가 Guest 자리임을 화면으로만 알아낸다. 획득단어 없음.

### VISUAL 2 — 가족사진 ↔ 식당 인물

가족사진의 얼굴·펜라이트·장부클립을 현재 식당의 헬렌·루카·에바와 대조한다.

신규인물 중 에바는 문서 이름이 아니라 사진 속 결혼식 신부 ↔ 현재 은색 장부클립으로 확정한다.

### VISUAL 3 — 흙·신발·경로

창문턱의 회색 묘지토는 텍스트로 ‘요나와 동일’이라 말하지 않는다.

현관의 여섯 신발 중 요나 구두 밑창에만 같은 회색 점토와 좁은 V자 홈, 묘지길 발자국에도 같은 V자 홈이 있다.

IMAGE ↔ IMAGE ↔ REGION GRAPH 비교로 요나의 외부동선을 확정. 획득단어 없음.

### VISUAL 4 — 사라진 서류의 두께

금고 안 서류철에는 먼지선과 눌린 끈자국이 남아 있다. 요나 가방의 빈 보존커버 두께가 그 빈 폭과 맞는다.

유언장이 ‘남았다’는 텍스트보다 비어 있는 폭과 커버 폭의 시각비교가 Case 44 절도의 필수근거다.

## TEXT-ONLY FAIL

문서만 읽으면 루카가 약을 넣은 정황과 요나의 Case 44 집착은 알 수 있지만, 빈 의자의 주인 / 요나의 실제 침입경로 / 무엇이 금고에서 실제로 빠졌는지를 확정할 수 없다.

# v5.3 추론밀도 패치

## 힌지 단서 A — 비어 있는 Guest 자리

한 자리의 **식지 않은 포도주 / 굳은 수프막 / 젖은 외투가 걸린 의자등 / V자 홈 신발흙**을 한 장면에 묶는다.

- 누군가 식사 시작 전후로 자리를 비움.
- 그 사람은 밖의 비를 맞고 돌아옴.
