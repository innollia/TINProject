# 07. 불탄 창고의 일곱 상자 — 카르민 항

# 스테이지 개요

**장소:** 카르민 항 12번 보세창고 / 1996-06-02, 새벽 화재 진압 직후.  

**첫 화면의 국소 모순:** 세관검사관 올렌은 E09를 검사하다 죽었고, E09는 한 번 22kg가량 무거워졌다가 다시 거의 원래 무게로 돌아왔다. 같은 사이 G02는 약 22kg 가벼워졌다.  

**독립사건의 질문:** 무엇이 두 상자 사이를 이동했나 / 누가 석판을 빼돌렸나 / 화재는 왜 났나 / 누가 억울하게 의심받나.  

**장기 변화:** 사건을 해결한 뒤 ‘중앙이 파손된 것이 아니라 처음부터 비어 있는 흑색석판’만 남긴다. 의미·연대는 미확정.

# 등장인물

- **올렌 피스크 / 세관검사관·피해자** — 회색 제복, 왼손잡이, 적색 검사분필.
- **베라 콜 / 창고감독** — 황색 조끼, 창고열쇠 보유, 세관봉인 개봉권한 없음.
- **나일 로우 / 하역반장** — 푸른 장갑, 지게차 운전.
- **카스 민 / 골동품수입업자** — 검은 코트. 수입허가서 Kass Min + 전보 K. Min으로 이름 확정.
- **제라 베일 / 보험조사원** — 초록 서류철, 화재 뒤 도착.
- **폴 에른 / 야간경비** — 등유난로 사용자.

# 설계 변경 — 일곱 상자를 조회문제로 만들지 않기

일곱 상자의 **번호·내용물·중량이 한 표에 동시에 나오지 않는다.**  

플레이어가 전부 1:1 대응시킬 필요도 없다. 정상 다섯 상자는 음성대조용 배경이고, 답안에 필요한 것은 E09와 G02뿐이다.

## 0클릭 장면

보세창고 Overview에서 E09는 검사대에 열려 있고 내부 포장틀 한 칸이 어색하게 비어 있으며, G02의 내부 트레이에도 같은 크기의 빈 자리가 있다. 바닥에는 서로 다른 방향의 지게차 자국과 소화수 흐름이 겹쳐 있다.

숫자를 읽기 전부터 “두 상자 사이에 무엇인가 이동했나?”라는 가설이 생겨야 한다.

## VISUAL SYSTEM 1 — 기계추의 형태

22kg 기계추는 사다리꼴 손잡이와 두 개의 둥근 돌기가 있다.

G02 내부 트레이에는 그 형태 그대로 눌린 빈 자리, E09 포장폼에는 같은 형태의 새 압흔이 있다.

C1의 숫자는 ‘약 22kg 이동’ 규칙만 주고, **무엇이 이동했는지**는 IMAGE ↔ IMAGE로만 확정한다.

획득단어 없음.

## VISUAL SYSTEM 2 — 석판 원래 자리

E09 포장틀에는 넓고 얇은 직사각형 먼지선과 검은 돌가루 테두리가 남는다.

올렌 주머니의 작은 조각과 창고바닥 조각을 맞추면 같은 흑색재질이며 포장틀 윤곽 일부가 맞는다.

‘석판을 빼냈다’는 텍스트 설명 없이 물체의 부재를 본다.

## VISUAL SYSTEM 3 — 봉인 위조

수입품 신고철은 봉인 **그림 규칙**만 제공한다.

진짜 K-71 검은 밀랍은 세 갈래 균열문양, E09 현재 봉인은 네 갈래로 어긋난 재압착 흔적이 있다.

카스 포장대 밀랍도 네 갈래 금형.

문자 “같은 밀랍” 자동해석 금지.

## VISUAL SYSTEM 4 — 화재 시작점

화점의 그을음은 바닥에서 위로 V자 확산되고, 전기배선은 그 V 바깥을 지난다.

폴 난로 주변 그을음은 오래된 원형이고, 사건 화점의 V자와 형태가 다르다.

가속제 검사표는 “가속제 성분 검출”만 제공하고 실제 시작점은 화면에서 결정한다.

## 기존 텍스트 단서 수정

- B2 내부 설명에서 “22kg 기계추”라는 이름은 클릭 즉시 뜨지 않는다. 무게각인만 보인다.
- C5 “빈 기계추 포대”라는 제목 대신 무표기 공업포대와 트레이 그림으로 구현.
- A3 “E09와 같은 돌가루” 자동해석 삭제.
- D2 “E09 새 실과 동일” 자동해석 삭제.
- D4 “화점 가속제와 동일”도 색/점도 반응카드를 직접 비교한다.

## TEXT-ONLY FAIL

숫자만 읽으면 E09와 G02 사이에 약 22kg 변화가 있다는 사실까지만 알 수 있다. **기계추가 실제 이동물 / 석판이 빠진 물건 / 봉인이 다시 만들어짐 / 실제 화점**은 그림 없이는 확정되지 않는다.

## Word Pool 수정

빼냈다 / 넣었다 / 불을 냈다 / 밀수했다는 초기 확정동사로 주지 않는다.

경쟁토큰: 옮겼다 / 바꿨다 / 채웠다 / 꺼냈다 / 숨겼다 / 봉인했다 / 다시 봉인했다 / 태웠다 / 합선됐다 / 불붙었다.

# v5.3 추론밀도 패치

## 힌지 단서 A — E09 포장틀

한 포장틀 안에 **넓은 석판 먼지선 / 사다리꼴 새 압흔 / 다시 묶인 봉인실**이 공존한다.

- 원래 넓은 얇은 물체가 있었음.
- 다른 형태의 무거운 물체가 잠시 들어옴.
- 상자가 한 번 개봉·재봉인됨.

세 명제를 한 번에 만든다.

숫자기록을 보기 전에도 바꿔치기 가설이 생긴다.

## 힌지 단서 B — G02 빈 트레이 + 자동저울

G02의 사다리꼴 빈 압흔과 E09의 새 압흔, 두 상자의 ±약 22kg 변화가:

- 같은 물체가 G02→E09로 이동했을 가능성.
- 두 상자의 이상이 하나의 행동으로 연결됨.
- 정상 적재오류보다 의도적 치환 가능성.

을 동시에 높인다.

## 힌지 단서 C — 봉인 균열문양

진짜 K-71 인장그림 / E09 현재 봉인 / 카스 포장대 금형의 균열패턴을 비교하면:

- 현재 봉인이 원래 봉인이 아님.
- 재봉인 도구와 카스 작업대 연결.
- 나일의 단순 이동만으로 설명되지 않음.

을 함께 준다.

## 힌지 단서 D — 올렌의 재검사 흔적

붉은 분필선이 E09에서 끊기고, 올렌 주머니에 석판조각, 자동저울 마지막 줄 옆 같은 붉은 분필이 남는다.

- 올렌이 E09에서 이상을 직접 봄.
- 재계량까지 진행.
- 화재가 그 직후 발생.

을 묶어 ‘왜 불이 났는가’의 동기축을 만든다.

# 중간문제 v5.3 — 고밀도 선택형 넛지

1. **두 상자, 한 물체** — E09 포장틀의 석판 먼지선·새 사다리꼴 압흔, G02의 빈 사다리꼴 자리, 두 상자의 무게변화, 봉인문양을 한 작업대에 놓는다. **결과:** 석판이 빠지고 다른 무거운 물체가 G02에서 E09로 이동했으며 재봉인까지 있었을 가능성이 한 번에 생긴다. 누가 했는지는 남긴다.
2. **올렌이 무엇을 발견했나** — 붉은 검사분필, 마지막 재계량, 주머니의 석판조각, 화점 위치를 시간순으로 놓는다. **결과:** 올렌이 상자 이상을 확인한 직후 화재가 시작됐다는 동기축이 생긴다. 방화범과 정상 작업자의 구분은 원자료와 결합해야 한다.

봉인판/질량판/형태판을 따로 두지 않는다.

# 완료 후 메타 카드

석판 조각을 복원하면 중앙의 매끈한 부분은 파손면이 아니라 제작 당시부터 비어 있었음을 확인. 무엇이 생략됐는지는 모른다.

# 검증

두 상자, 한 물체 / 올렌이 무엇을 발견했나는 선택 검증한다. 메인사건문은 독립 검증한다.

# 제작 잠금표 v5.5 — 플레이어 비노출

- **상자·질량:** E09 118.1→95.4, G02 96.8→119라는 측정값은 그대로 읽고 얻는다. 시간순·상자별 칸을 나누며 약 22kg의 이동만 수치로 추론한다. 물체 이름은 포장틀·빈 트레이·각인으로 확인한다.
- **행위자·방화:** 봉인 금형/절단실/카스 포장대와 재검사분필/화점을 연결한다. 나일의 지게차 이동은 허가된 작업이다. 난로·합선·보험금 목적의 오답은 화점·용제·손익자료로 각각 탈락한다.
- **장기 단서:** 석판 중앙의 공백은 제작 당시 상태까지가 확정이다. 상징의 뜻은 이 장에서 묻지 않는다.
