# 03. 루돌프의 마지막 견학 — N153 제2계측동

# 스테이지 개요

**장소:** N153 제2계측동 / 1996-05-02 — 제2계측실, 관찰통제실, 탈의실, 서비스통로, 안전봉인실. 이곳은 N153이 직접 등장하는 유일한 스테이지.  

**첫 화면의 국소 모순:** 공식 출입기록은 1명인데 탄 잔해에는 다리처럼 보이는 형체가 4개다. 머리는 1개만 식별되고 장비 프레임까지 얽혀 있어 첫 화면만으로 사람 수를 확정할 수 없다.  

**독립사건의 질문:** 몇 명이 있었나 / 두 번째 사람은 누구인가 / 왜 들어왔나 / 무엇이 사고를 냈나 / 누가 무엇을 오판했고 누가 무엇을 숨겼나.  

**장기 변화:** N153은 현상을 “측정하고 흔드는” 시설이었다는 사실까지만 남긴다.

# 등장인물

- **리안 소른 / 계측기사** — 탈색 짧은 머리, 회색 작업복, 코의 N-LUX 주입점, 사슴코 스티커.
- **리사 마렌 / 민간인·리안의 연인** — 베이지 코트, 흰 운동화, 얇은 은반지, 맞지 않는 직원용 덧신.
- **데럴 보스 / 보조연구원** — 초록 작업모, 귀 뒤 연필, 비상도끼.
- **이레나 베일 / 안전책임자** — 노란 보호안경, 방사선계측표 묶음.
- **하벨 도른 / 시설책임자** — 검은 정장 위 출입가운, 봉인도장, 통제실 마스터키.
- **오도 케스트 / 설비기술자** — 공구벨트, 검은 방수수첩 ‘상식노트’.

# 직책 규칙

- 계측기사: 서비스키 사용 가능.
- 보조연구원: 계측실 출입 가능, 인터록 관리자권한 없음.
- 안전책임자: 사고자료 봉인 및 법의학 스캔 요청 가능.
- 시설책임자: 외부보고 승인과 기록보존 지시 가능.
- 설비기술자: 서비스키 사용 가능하지만 사고 당시 개인 K-1을 몸에 지니고 있었음.

# 지역 A — 제2계측실 · 쿼터뷰

**이미지 설명:** 중앙 바닥에 탄 인체·장비 잔해가 뒤엉켜 있고 검은 안전화 한 쌍, 반쯤 보이는 흰 운동화 한 짝, N-LUX 흔적이 보인다. 문밖에서 데럴이 도끼로 문틀을 찍고 있음.  

**지역 기능:** 괴물설을 가장 강하게 만들되, 인원수는 여기만으로 확정하지 못하게 한다.

- 오브젝트 A1 — 탄 잔해 · 현장
    
    **이미지 설명:** 네 다리처럼 보이는 형체, 한 개의 식별 가능한 두개골, 회색 작업복 조각, 베이지 천조각, 장비 프레임이 서로 붙어 있음.
    
    **얻는 단어:** 네 / 하나 / 잔해
    
    **기능:** ‘한 사람의 변형’과 ‘두 사람의 중첩’ 가설을 동시에 살린다.
    
- 오브젝트 A2 — 신발 흔적 · 물건
    
    검은 안전화 한 쌍 + 흰 운동화 한 짝. 다른 흰 운동화는 D지역 덧신선반 밑에 있음.
    
    **얻는 단어:** 안전화 / 운동화
    
    **추천 중간문제:** 인원수 판
    
- 오브젝트 A3 — N-LUX 흔적 · 장치/물질
    
    **설명서 요약:** N-LUX 추적제는 코 → 목 → 손끝 순으로 발광.
    
    **얻는 단어:** N-LUX / 루돌프
    
    **기능:** 데럴의 ‘코부터 빛난 괴물’ 관찰이 거짓말이 아님을 보장.
    
- 오브젝트 A4 — 데럴 보스 · 인물/대화
    
    “로그에는 한 명이잖아요! 다리가 넷인데 리안 작업복이 붙어 있어! 문 열지 마. 밖으로 나오면 어떡해!”
    
    **얻는 단어:** 데럴 / 괴물

# 시각추론 정본 v5.1 — 구현 시 이 절이 상위 설명보다 우선

## 0클릭 장면

탄 잔해는 ‘두 명의 시체’처럼 그리면 안 된다. 회색 작업복 한 벌처럼 보이는 큰 덩어리에 베이지 천·장비프레임·네 개의 다리형 실루엣이 겹친다.

데럴의 괴물설이 첫눈에 우스워 보이면 실패다.

## REGION GRAPH

자재문 → 탈의실 → 서비스통로 → 제2계측실.

직원 정문 → 통제실 → 계측실.

리사는 정문기록을 남기지 않고 자재문에서 리안 바로 뒤에 붙어 들어와야 한다. 필름카메라는 자재문을 비스듬히 찍어 사람 전체가 아니라 하체 일부만 기록한다.

## VISUAL SYSTEM 1 — 신발/덧신/발자국

직원 안전화는 V자 깊은 바닥, 방문자 덧신은 매끈한 얇은 밑창, 리사 운동화는 별모양 마모가 있다.

- 잔해: 안전화 2짝 + 덧신 안쪽에서 나온 별모양 운동화 한 짝.
- 탈의실: 다른 별모양 운동화 한 짝.
- 자재문 필름: 리안 뒤 하단에 별모양 흰 밑창 일부.

이 세 장을 비교해야 두 번째 인물을 확정. 획득단어 없음.

## VISUAL SYSTEM 2 — 골격 중첩

응급 골격스캔은 텍스트 판독문을 삭제하고 반투명 영상 자체를 보여준다.

정상 참고 골격 그림과 비교하면 같은 방향의 왼쪽 대퇴골 머리가 두 개, 크기가 다른 골반 호가 겹쳐 있다.

COUNT: UNRESOLVED만 문자로 남긴다. ‘두 명’이라는 단어는 수집하지 않는다.

## VISUAL SYSTEM 3 — 반지 식별

잔해의 손에 붙은 얇은 은반지와 리안 사물함 즉석사진 속 리사의 반지를 직접 비교한다.

사진 캡션은 이름을 말하지 않는다. 리사 이름은 호출기 LISA와 사진 속 얼굴을 결합해 확정.

## VISUAL SYSTEM 4 — 키날/우회패널

서비스키 대여판에는 K-1/K-2 이름표가 아니라 서로 다른 열쇠날 실루엣이 걸려 있다.

인터록 패널 안쪽 소켓 모양과 K-2 열쇠날을 IMAGE ↔ IMAGE로 맞춰야 BYPASS 조작 가능성을 연다.

문서에는 “계측기사와 설비기술자는 서비스키를 사용할 수 있다”라는 규칙만 둔다.

## 기존 텍스트 단서 수정

- A1 두 명 획득단어 삭제.
- A2 두 명 획득단어 삭제.
- B2의 골격 구조 설명 문장 삭제. 영상+참고골격으로만 보임.
- B5 혈액 A/B는 ‘혈액형이 다름’이 아니라 라벨 없는 두 색반응 카드 이미지로 제시하고, 혈액형 판독표와 비교하게 한다.
- C1 즉석사진에서 연인 단어 지급 금지. 팔짱·얼굴거리·같은 은반지 세트 중 한쪽을 리안이 목걸이에 걸고 있는 시각정보로 관계를 추리.
- C2 민간인이라는 자동해석 삭제.
- D2 BYPASS / 우회했다를 Word Pool에 바로 넣지 않는다. 패널의 스위치 상태와 열쇠흠집을 본 뒤 선택.
- E1은 “전에 인수했다”라는 문장 대신 하벨 붉은 수정 잉크의 마름 정도 / 봉투 인수시각 도장 / 보고서 타자지 겹침을 비교해 순서를 판정한다.

## TEXT-ONLY FAIL

로그와 호출기만 읽으면 ‘비인가 방문 가능성’은 알 수 있으나 현장 인원수 2명 / 두 번째 피해자가 리사 / K-2로 인터록을 우회했다 / 하벨이 충돌물증을 본 뒤 보고서를 수정했다는 네 명제 중 어느 것도 완전히 확정되지 않는다.

## Word Pool 수정

삭제: 두 명 / 몰래 데려왔다 / 우회했다 / 오판했다 / 축소보고했다.

경쟁토큰 추가: 따라왔다 / 초대했다 / 숨겼다 / 들어왔다 / 잠갔다 / 풀었다 / 건드렸다 / 잘못 셌다 / 믿었다 / 고쳤다 / 지웠다 / 보고했다.

행동 후보어는 해당 물건이나 기록을 살피면 얻는다. 시각명제 판은 후보어의 뜻을 확인하는 선택형 문제이며 본문 슬롯을 잠그지 않는다.

# 중간문제 v5.3 — 고밀도 선택형 넛지

1. **두 번째 사람 복원** — 잔해의 골격호·별마모 운동화·은반지·자재문 필름을 하나의 인물실루엣에 연결한다. **결과:** 한 몸 변형설 약화 / 두 번째 사람 존재 / 비직원 경로 / 리사 신원 가능성이 한 판에서 동시에 좁혀진다. 리안이 데려왔는지는 아직 별도 추론.
2. **비인가 시연 경로** — K-2 열쇠날→인터록 소켓→LOW 시연시각→잔류전력 곡선을 한 기계흐름에 놓는다. **결과:** 어떻게 정상 방문기록 없이 들어가 위험한 시연이 가능했는지를 압축한다. 행위자와 책임은 남긴다.
3. **누가 무엇을 알았나** — REGISTERED / SCENE / REPORT 세 열에 데럴·이레나·하벨이 실제로 접한 자료만 배치한다. **결과:** 오판과 은폐를 성격판정이 아니라 정보접근 차이로 구분한다.

인원수판/관계판/사고원인판을 따로 쪼개지 않는다.

# 검증

두 번째 사람 복원 / 비인가 시연 경로 / 누가 무엇을 알았나는 각각 선택 검증한다. 메인 사건문은 독립 검증한다.

# 제작 잠금표 v5.5 — 플레이어 비노출

- **인원·신원:** 카드 1회 사용은 사람 1명이라는 뜻이 아니다. 중첩 골격·별마모 운동화·자재문 필름으로 두 번째 사람을 세우고, 은반지·호출기·사진 얼굴로 리사를 특정한다.
- **진입·사고:** K-2 열쇠날/대여판/우회소켓을 연결하고 LOW 시연시각과 잔류전력 곡선을 맞춘다. 괴물·우발 장비폭주·정상 견학은 각각 골격/우회/전력 자료에 의해 탈락한다.
- **오판과 은폐:** 데럴은 현장보다 등록기록을 믿었고, 하벨은 현장 충돌자료를 본 뒤 보고서를 바꿨다. 두 사람에게 같은 의도를 부여하지 않는다. 경쟁 행동어는 처음부터 선택 가능하며 선택형 판이 토큰을 잠그지 않는다.
