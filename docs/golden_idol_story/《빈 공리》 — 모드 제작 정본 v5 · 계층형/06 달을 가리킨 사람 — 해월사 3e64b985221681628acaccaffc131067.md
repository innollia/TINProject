# 06. 달을 가리킨 사람 — 해월사

# 스테이지 개요

**장소:** 산중 불교공동체 ‘해월사’ / 1996-05-22, 비 오는 오후, 번역회 직후.  

**첫 화면의 국소 모순:** 고문헌 한 장이 뜯겨 있고 번역승 지안이 난간 아래 쓰러져 있다. 절도자 타렌은 “제가 밀었습니다”라고 자백하지만, 난간에는 그의 접촉흔적이 없다.  

**독립사건의 질문:** 사라진 장은 어느 책인가 / 누가 훔쳤나 / 지안은 실제로 밀렸나 / 누가 무엇에 책임이 있나.  

**장기 변화:** 같은 고문을 ‘명사 보충’ 판본과 ‘무보충’ 판본 두 개로 남긴 번역문제가 존재한다는 사실만 확보.

# 등장인물

- **지안 / 번역승** — 63세, 왼쪽 눈썹 흉터, 회색 장삼.
- **렌포 / 주지** — 붉은 갈색 가사, 열쇠꾸러미.
- **소마 / 기록담당** — 안경, 손가락 청흑색 먹물.
- **타렌 / 행자** — 가장 젊음, 짧은 회색 옷, 오른쪽 소매 실밥.
- **알렉 룩 / 외부 철학교수** — 검은 우산, 번역회 초청자.
- **메이 아르 / 공양담당** — 앞치마, 부엌과 법당 사이 이동.

# 시각추론 정본 v5.1 — 구현 시 이 절이 상위 설명보다 우선

## 0클릭 장면

보관각 아래 장면에서 지안은 난간 바로 밑이 아니라 **문에서 몇 걸음 떨어진 위치**에 쓰러져 있고, 문고리 근처와 난간 근처의 젖은 흔적 사이에 빈 공간이 보인다.

타렌의 “제가 밀었습니다” 자백과 화면이 처음부터 미묘하게 충돌한다.

## VISUAL SYSTEM 1 — 결번과 실제 찢김

B113과 C42를 텍스트로 “인쇄오류 / 뜯김”이라고 판정하지 않는다.

- B권: 112 다음 종이가 바로 114로 인쇄되어 있고 제본실이 연속적.
- C권: 41과 43 사이 실이 끊어져 바깥으로 말리고, 종이섬유가 불규칙하게 남음.

책의 옆면·실밥을 직접 비교해야 한다. 획득단어 없음.

## VISUAL SYSTEM 2 — 종이섬유 ↔ 타렌 소매

C권 찢김면의 황갈색 섬유에는 붉은 실 한 올이 섞여 있다.

타렌 소매 안쪽에도 같은 황갈색 종이섬유가 붙고, 오른소매 붉은 실밥 하나가 비어 있다.

자동 “같은 섬유” 설명 금지. IMAGE ↔ IMAGE 비교 필수.

## VISUAL SYSTEM 3 — 문고리 접촉과 추락 분리

E1~E3의 결론문을 삭제하고 한 장면에서 다음을 직접 보여 준다.

- 문고리: 회색 장삼 실 + 타렌 소매의 반대방향 당김자국.
- 문→난간: 지안의 젖은 발자국 세 개.
- 난간 직전: 지안 장삼 끝 위에 지안 신발바닥 무늬.
- 난간: 타렌 손자국 없음.

플레이어가 방향과 거리로 “접촉 후 분리 → 지안이 홀로 추격 → 자기 옷 밟음”을 복원한다.

획득단어 없음.

## VISUAL SYSTEM 4 — 미끄럼천

우천 체크표는 “보관각 미설치”라고 쓰지 않는다. 각 회랑을 상징하는 작은 평면 아이콘이 있고, 현장 Overview에서 같은 아이콘 모양의 미끄럼천 패턴을 대조한다.

메이의 과실은 보이지만 지안의 신발자국이 **천이 없는 돌바닥을 지나도 미끄러진 흔적 없이 이어진다**는 점 때문에 직접원인에서 탈락한다.

## 기존 텍스트 단서 수정

- C2 점검표의 “B113 초판부터 결번 / C42 오전 존재”를 직접 문장으로 쓰지 않는다. 오전 점검표에는 페이지 수 총계와 책별 작은 제본도식만 남기고 현재 책과 비교하게 한다.
- C3 “C권과 동일” 자동해석 삭제.
- E2 ‘세 걸음’ 획득단어 삭제.
- E3 ‘밟았다 / 떨어졌다’ 획득단어 삭제.
- E4 자백은 유지한다. **거짓정보가 아니라 진실한 오판**이므로 강한 Red Herring으로 사용.

## TEXT-ONLY FAIL

문서만 읽으면 타렌의 절도동기와 자백은 알 수 있지만 **실제 결손책 / 타렌이 페이지를 만졌다는 물증 / 추락 순간 비접촉 / 장삼 밟힘**을 확정할 수 없다.

## Word Pool 수정

훔쳤다 / 밟았다 / 떨어졌다 / 밀었다를 모두 경쟁토큰으로 동시에 제공한다.

추가: 찢었다 / 숨겼다 / 놓쳤다 / 잡았다 / 밀었다 / 당겼다 / 미끄러졌다 / 밟았다 / 걸렸다 / 떨어졌다.

정답은 물리장면 없이는 조합해도 검증되지 않는다.

# v5.3 추론밀도 패치

## 힌지 단서 A — B113과 C42의 제본단면

두 책을 한 번에 비교하면:

- B113은 처음부터 인쇄되지 않은 결번.
- C42는 실제로 뜯긴 페이지.
- ‘페이지가 없다’는 표면사실이 서로 다른 원인을 가짐.
- 타렌 자백이 어느 결손을 가리키는지 다시 생각하게 됨.

을 동시에 만든다.

소마 점검표는 총 페이지수만 보조.

## 힌지 단서 B — C42 찢김면의 붉은 한 올

찢긴 종이섬유 속 붉은 실 한 올 + 타렌 소매의 빠진 실밥 + 소매 안쪽 종이섬유가:

- 타렌이 C42를 최근 만짐.
- 접촉 방향이 ‘책에서 소매 쪽’임.
- 단순 보관업무 접촉보다 급히 뜯은 상황과 맞음.

을 함께 준다.

가족편지는 동기 한 단계만 더함.

## 힌지 단서 C — 문고리→세 걸음→장삼 발자국

한 연속흔적 안에:

- 문 앞에서 실제 접촉이 있었음.
- 그 뒤 두 사람이 분리됨.
- 지안이 혼자 추격함.
- 마지막에 자기 장삼을 밟음.

이 들어 있다.

타렌 자백은 그래서 ‘접촉이 있었다’는 부분은 참이지만 ‘내가 추락시켰다’는 해석만 틀리게 된다.

## 힌지 단서 D — 미끄럼천 부재

메이의 누락은 진짜이지만 마지막 발자국이 천 없는 구간을 정상적으로 통과하고, 넘어짐은 장삼 자국 위치에서 시작한다.

- 메이의 실수는 사실.
- 직접원인은 아님.
- ‘여러 사람이 조금씩 잘못했지만 사건원인은 하나’라는 층위를 만든다.

## 삭제/병합

# 중간문제 v5.3 — 고밀도 선택형 넛지

1. **어떤 페이지가 실제로 뜯겼나** — B112-114 제본단면, C41-43 찢김면, 타렌 소매의 섬유를 한 복원대에 놓는다. **결과:** 원래 결번과 실제 절도를 구분하면서, 최근 C42를 만진 사람 후보까지 동시에 좁힌다. 동기와 추락은 남긴다.
2. **문에서 난간까지 4초** — 문고리 실밥, 지안 발자국 세 개, 장삼 끝 자국, 미끄럼천 부재, 난간을 한 실제비율 동선에 놓는다. **결과:** 접촉은 실제였지만 추락 순간에는 분리돼 있었고, 메이의 실수도 직접원인은 아니라는 두 오답을 동시에 정리한다.

타렌 자백은 별도 정답판이 아니라 이 두 물리복원과 충돌하는 진실한 자기해석으로 남긴다.

# 메인문제

“[타렌]은 약값 때문에 [C권 42]를 훔쳤다. 문에서 [지안]에게 붙잡히자 손을 [뿌리치고] 달아났고, 지안은 뒤쫓다 자기 [젖은 장삼] 끝을 [밟아] 난간 아래로 [떨어졌다]. 타렌은 자신이 밀었다고 믿지만 추락 순간 두 사람은 접촉하지 않았다.”

# 장기 연결

사건 해결 후 지안 번역 A/B를 카드화한다. ‘불교 = Ø’는 결론으로 만들지 않는다.

# 검증

어떤 페이지가 실제로 뜯겼나 / 문에서 난간까지 4초를 선택 검증한다. 메인사건문은 별도로 검증한다.

# 제작 잠금표 v5.5 — 플레이어 비노출

- **결손의 종류:** B113은 제본이 이어지고 C42는 찢김면이 남는다. 오전 총계·현재 책·타렌 소매 섬유를 맞춰 실제 절도 대상과 접촉자를 구별한다. 페이지 숫자는 직접 얻어도 된다.
- **추락의 4초:** 문고리 실밥은 접촉을 증명한다. 분리된 발자국 세 개·장삼 밟힘·낙하점은 추락 순간의 비접촉을 증명한다. ‘타렌이 밀었다’는 자백은 죄책감의 해석이지 물리적 확정이 아니다.
- **장기 단서:** 지안 A/B 번역은 해결 뒤 재해석 자료다. 종교용어를 결손의 이름으로 채점하지 않는다.
