## 읽는 방법

- **기능 결함:** 현재 코드의 실행 경로 또는 생성하지 않는 DryRun으로 구체적인 실패 원인을 확인했다. 실제 플레이로 재현했는지는 각 항목에 별도로 적었다.
- **계획의 빈틈:** 구현자가 같은 계약을 따라도 서로 다른 결과를 만들거나, 존재하지 않는 기능을 호출하게 되는 상태다.
- **작업 중 미구현:** 예정된 기능이 아직 골격·스텁·문서 상태다. 완료 선언 이후의 회귀라고 단정하지 않는다.
- **미검증:** 실행·플레이·시각·청취 증거가 없다는 뜻이다. 검증하지 않은 항목을 실패나 통과로 바꾸지 않는다.

각 항목에는 적용 요구, 근거 위치, 플레이 또는 구현에 미치는 영향, 보완 방법, 닫힘 조건을 기록한다. **P1은 먼저 해소할 기능·실행 계약, P2는 그다음 보완할 항목**을 뜻한다. 키트 수나 문서 길이를 성과로 삼지 않는다.
