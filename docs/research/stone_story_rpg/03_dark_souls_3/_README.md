# 03_dark_souls_3 — Sub Reference (확장점 한정)

**확장점이 확정되기 전에는 아무 내용도 적지 않는다.**

Dark Souls 3는 Primary Reference가 아니다. Stone Story RPG가 우선한다.
사용자가 명시한 **특정 시스템 확장점 하나에만** 쓴다. 다른 화면·시스템으로 넓히지 않는다.

선택 가능한 확장점 후보:

- 스태거·크리티컬 읽기
- 스탠스·포지션 게이지
- 보스 패턴 읽기와 페이즈 전환
- 체크포인트와 맵 재방문 상태 분기
- 루그·장비 빌드
- 재방문 맵의 변화량
- 아이템 서사(유물·효법 문구)
- 회복·재시작 흐름

확정되면:

1. `PROJECT_DECISIONS.md` §21에 확정 확장점을 기록한다.
2. `extensions/<topic>.md` 파일을 만들고 `01_stone_story_rpg/`와 **어떤 범위에서 다른지**를 명시한다.
3. 그 뒤에만 실제 화면 근거를 받는다.
