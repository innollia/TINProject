## 1. 가져올 구조 (This is the design, not the numbers)

### 1.1 스탯 9개 = 내구 4 + 공격 5

원작이 명확히 두 묶음으로 나눈다. **이 분할 자체가 설계다.**

| 묶음 | 원작 | TIN | 하는 일 |
|---|---|---|---|
| 내구 4 | 생명력(HP) / 집중력(FP+슬롯) / 지구력(스태미나) / 체력(중량+물리방어) | `체력` `정신` `지구력` `내구` | **살아남기 위한 최소치** |
| 공격 5 | 근력 / 기량 / 지성 / 신앙 / 운 | `위력` `민첩` `지혜` `신앙` `직감` | **무기와 능력을 쓰기 위한 값** |

원작 루트: "앞의 4스탯을 찍은 다음에 뒤의 5스탯을 찍는 것이 정석."

### 1.2 스탯이 무기를 *문 잠근다* (요구치)

원작 규칙:
- 무기마다 스탯별 **보정 단계**가 있다: S / A / B / C / D / E.
- 무기마다 스탯별 **최소 요구량**이 있다.
- 요구량 미달 시: 물리 공격력 대폭 감소, **전투기술 발동 안 됨**, 방어 시 튕김, 촉매는 마법 사용 불가.
- **근력만 예외**: 양손잡기 시 요구치 판정에 1.5배 적용.

→ 이게 이 설계에서 가장 중요한 규칙이다.
**"스탯을 못 찍으면 무기를 못 쓴다"** — 빌드가 스탯 배분에서 강제된다.

### 1.3 소프트캡 구조 (25 / 40 / 그 이후)

원작 관측:
- 효율 구간: 25, 40까지. 그 뒤엔 60, 99를 찍어야 차이가 날 정도로 효율이 떨어진다.
- 생명력만 99까지 꾸준히 오른다. 생명력도 40 이후엔 거의 안 오르고, 집중력은 40부터 10단위로 슬롯이 늘어난다.
- 지구력은 40 이후 6레벨당 1. 99를 찍어도 40과 10차이다.
- 집중력 기억 슬롯 임계점: 10/14/18/24/30/40/50/60/80/99.
- 출혈 축적치는 20~50에서 크게 오르고 이후 거의 안 오른다 (50 하드캡).

→ **곡선이 아니라 계단 함수다.** 부드러운 포화곡선이 아니라,
특정 구간에서 효율이 확 떨어지는 **구간별 계단**을 쓴다.

### 1.4 강화 수치(+N)가 근접과 원딜을 다르게 만든다

원작 관측:
- 근접 무기: 10강으로 공격력이 **2배 이상** 증가.
- 촉매(마법 지팡이): 10강 해도 위력치가 1.2배도 안 늘고, 사실상 스탯 순수 의존.
- 지성 16 → 60에서 촉매 위력 100 → 199/190.

→ **강화는 근접에만 유리하다.** 이 비대칭이 빌드를 나눈다.

### 1.5 변질(Affinity) — 스탯을 바꿔 쓰는 것

원작: 무기 변질을 통해 **선호하는 스탯의 보정을 바꿔 쓴다.** 무기 종류에 따라 변질이 다르다.

- 중후(Heavy) 변질: 근력 효율 ↑
- 예리(Keen) 변질: 기량 효율 ↑, 소형 무기에 유리
- 소형 무기 + 빠른 공속 → 출혈·독 보조효과
- 대형 무기 + 느린 공속 → 슈퍼아머로 한 방

→ **같은 무기 파이프라인에서 빌드를 바꾼다.** 이게 "전사계" 분기의 근거.

### 1.6 능력(버프)이 데미지를 곱연산으로 올린다

원작: 기적/마술/주술 위력 증가 반지가 **곱연산**으로 데미지를 올린다. 기본 스탯이 부족하면 곱연산으로도 정상 딜이 안 나온다.
기본 구성: 위력 증가 반지 + 속도 증가 반지 + 극딜/총애 반지.

→ 재사용진화 설계의 출발점. 단, 수치는 TIN이 정한다.

### 1.7 속성 = 데미지 타입 5 + 상태 3

원작이 실제로 쓰는 공격 속성:

```text
데미지 타입  물리 · 화염 · 번개 · 마력 · 어둠
상태 축적    출혈 · 독 · 서리
```

내성 축: 벼락/출혈 내성(지구력), 독 내성(체력), 화염 내성(근력), 마력 방어(지성), 어둠 방어(신앙), 속성 내성(운).

→ **이 구조로 TIN의 6속성(돌/독/생기/以太/화/氷)을 대체한다.**

### 1.8 스탯 재분배 (Rosaria's Finger)

- 회차당 5회.
- 재분배 스탯은 **기본 태생 + 레벨업 1 만큼만** 주어진다.
- 레벨을 더 낮출 수 없다.
- 1회차 중반에 태생 잘못 고른 것을 되돌릴 수 있는 안전장치.

→ **재분배 5회 제한**은 빌드 리롤을 "한 지역 안에서" 못 되게 만들어
스타 선택을 진짜 결정으로 만든다.

### 1.9 태생(클래스)이 시작 스탯과 난이도를 바꾼다

- 근력 계열 → 전사 / 기량 계열 → 용병이 시작 스탯 정렬에 유리
- 기사는 어느 쪽이든 무난
- 원작 권장: "처음이면 그냥 4스탯부터 찍자", "나중엔 거지로만 플레이한다"
- **초보는 모르면 못 이기는 게임.** 공략을 아는 사람이 극단적으로 유리.

→ 자동 전투 AI가 있는 TIN에서 이건 더 중요해진다.
AI가 스탯 빌드에 따라 다르게 짜여야 하는데, **빌드를 못 읽는 플레이어는 조작-timing으로도 못 이긴다.**

## 2. 안 가져오는 것 (금지)

- 원작 스탯 이름: 생명력/집중력/지구력/체력/근력/기량/지성/신앙/운
- 원작 수치: 27/39/50, 25/35/40, 10/14/18/24/30/40/50/60/80/99, 1.5배, 1000/1200/1300/1400, 2^N 강화표
- 원작 보정 단계 문자열 `S/A/B/C/D/E`
- 원작 무기·반지·주문·아이템·지역·보스명
- 원작 데미지 공식
- PvP 매칭 / 침입 / 잔불 / 사인 시스템

## 3. TIN이 새로 만드는 것 (수치·판정식 복제 금지)

| 항목 | TIN 설계 |
|---|---|
| 스탯 이름 | `체력` `정신` `지구력` `내구` / `위력` `민첩` `지혜` `신앙` `직감` |
| 보정 단계 | 열거형 대신 **0.00~1.00 실수 가중치** |
| 소프트캡 | TIN 자체 계단 곡선. 무릎 위치를 TIN 값으로 |
| 요구치 | TIN 요구치. 양손 보정 계수도 TIN 값 |
| 데미지 타입 | 물리 · 화염 · 번개 · 마력 · 어둠 |
| 상태 축적 | 출혈 · 독 · 서리 |
| 데미지 공식 | §04_COMBAT_STATS_DAMAGE.md에 TIN이 정의 |
| 어펙스 | **"그 무기를 강화했을 때 추가된 내용"** (사용자 확정) |

**모든 수치는 튜닝 파라미터로 분리한다.** 기본값을 코드에 박지 않고
콘텐츠 JSON의 `tuning` 블록에서 읽는다. → `04_COMBAT_STATS_DAMAGE.md` §7
