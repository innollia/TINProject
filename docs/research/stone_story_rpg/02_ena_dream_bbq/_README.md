# 02_ena_dream_bbq — 분위기·스토리·내용 source

**시스템 레퍼런스가 아니다.** 여기서 가져오는 것은 분위기·정서·스토리 기법·내용이다.
`01_stone_story_rpg/`의 시스템 문법과 섞지 않는다.

파일명: `<topic>_<subject>.md`
예: `tone_weight_of_absurdity.md`, `content_seed_ward_staff.md`

각 파일은 아래를 반드시 담는다.

1. 원본 위치 — `원본: 00_user_dumps/<파일명>`
2. 분위기/톤 — 무엇에 무게가 있는가
3. 가져올 스토리 기법 — 구조로 옮길 수 있는 형태
4. **이식 금지** — 고유 캐릭터, 세계관, 문구, 레벨 배치
5. 코드 전용 비주얼로 재현 가능한 장면인지 여부

사용자가 제공한 원문 한 문장도 authored content seed로 쓸 수 있다.
사용한 seed는 TIN rule·시스템 바인딩·cross-link·immediate/delayed consequence를 기록한다.
