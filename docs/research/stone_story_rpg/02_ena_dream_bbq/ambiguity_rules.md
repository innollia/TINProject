# 초현실 규칙 엔진

> **2026-09-26 전면 교체.**
> 앞판의 R1~R8(명사 퀘스트 · 해석 적층 · 부분 해소 …)은 **사용자가 폐기**했다:
> *"'플레이어가 대상을 몰라본다'를 뭔가 없애. 규칙을 뭐 이상하게 잡아놨어.
> 그냥 초현실주의잖아. 신경증 환자가 내뱉는 의미없는 말비빔 덩어리가 추상화를 거쳐서
> 하나의 형체를 가진 개체들이 되는거라고."*
>
> → 규칙은 **"말비빔 → 추상화 → 형체"** 다. 게임 디자인이 아니라 발생 규칙이다.
> 아래 R1~R12 가 그 규칙이고, 초현실은 여기서 **자동으로** 나온다.

---

## 0. 판정 기준 (이 문서의 존재 이유)

> **플레이어가 R1~R12 중 하나로 되짚을 수 없는 요소는 버그다.**

이것이 "어설프게 초현실주의를 하지 말라"의 operational한 해석이다.
장식은 넣지 않는다. 근거 없는 이상함은 넣지 않는다.

---

## 1. 발생 규칙 — 말비빔이 개체가 된다

### R1. 말비빔 (Raw Utterance)

- 모든 콘텐츠는 먼저 **형태 없는 말 덩어리**로 시작한다.
- 말비빔은 `raw` 배열이다. `raw: ["<무의미한 음절열>", ...]`
- **말비빔에는 규칙이 없다.** 그래서 개체가 될 수 있다.

### R2. 추상화 (Abstraction)

- 말비빔에서 **모양/수/크기/움직임** 4값만 뽑아낸다.
  (`form` `count` `size` `motion`)
- 이 4값이 개체의 정체를 **결정한다.** 나머지는 버린다.
- → 말비빔이 아무리 엉뚱해도 개체는 규칙적이라서 **형태를 얻는다.**

### R3. 형체 (Embodiment)

- `form` + 4속성으로 부품을 조립한다. (`critter.gd::_spec`)
- 부품: 몸통 · 머리 · 꼬리 · 다리(다리 수 = limbs)
- 부품은 면으로 그린다. (`view.gd::_draw_critter`)
- **눈이 반드시 있다.** 개수 = `floor(놀랍다/3)+1`

### R4. 같은 조립 규칙 (One Assembly Rule)

> 보이는 것은 **모두** 면과 관절로 구성된다.

- 개체도, 구조물도, 소품도 같은 규칙으로 조립된다.
- → "이것만 사실적이고 저것은화된" 인 공백이 없다.

### R5. 4속성은 개체의 성격이자 외형이다

| 속성 | 성격 | 외형 |
|---|---|---|
| 다리 | 1턴 행동 수 | 다리 개수 · 방사 각도 |
| 놀랍다 | 크리티컬 · AI 예측 실패 | 눈 개수 · 리듬 |
| 틀림 | 크리티컬 · 경직 무시 | 비대칭 · 축 이탈 |
| 동그라미 | 회피 확률 | 몸체 곡률 (1.0 = 원) |

→ **성격과 외형이 같은 수다.** 따로 만들지 않는다.

## 2. 세계 규칙 — 하나만 있다, 세 개만 깬다

> **기본 규칙:** 중력은 아래로, 같은 크기는 같은 자리를, 같은 것은 서로 다른 자리에.

### R6. 중력 규칙

- 기본: 아래로 내려앉는다.
- `float` 소품만 예외. 하늘에 뜬다.
- → 하늘에 뜬 기차, 공중 부유물

### R7. 크기 규칙

- 크기는 authored 값이다.
- **장면 안에서 규칙을 깨는 큰 것은 1개뿐.**
- → 돔 하나, 나머지는 규칙을 지킨다

### R8. 배치 규칙

- 같은 것은 같은 자리를 차지한다.
- **중복이 가능한 것은 1쌍뿐.**

### R9. 중요한 것은 혼자다

- 시각적으로 가장 큰 요소는 1개. 나머지는 그에 종다.
- → 시선이 갈 곳이 항상 정해진다

### R10. 색은 공간 구성용이다

- 공간당 4~6색.
- 색은 **구조**(하늘/바닥/큰 것)와 **소품**에만 쓴다.
- **상태 표식에 색을 쓰지 않는다** (`docs/UI_IMPLEMENTATION_RULES.md` R2).
- → 색이 많을수록 초현실이 안 된다

### R11. 유효한 밀도

- 근경(테두리) > 원경(안쪽). 항상.
- Ena 씬: 근경 개체가 크고, 원경 구조물이 안쪽에 있다.

### R12. 복제는 배치를 망가뜨리지 않는다

- 같은 것이 반복되면 **개수가 이상해진다** (R8 예외).
- 반복은 "많다"가 아니라 "왜 이렇게 많지"를 만든다.

---

## 3. R1~R12 가 만드는 것

| | |
|---|---|
| 개체 | R1 → R2 → R3 (속성 = R5) |
| 장면 | R4 + R11 (면 · 밀도) |
| 큰 것 | R7 + R9 |
| 소품 | R6 + R7 + R8 (한 개씩) |
| 색 | R10 |
| 이상함 | **위의 조합.** 그 외 없음 |

### 3.1 예시 (규칙에서 파생된 결과)

```json
// content/region/region_x.json
{
  "structure": "dome",                       // R7: 큰 것 1개
  "props": [
    { "id": "prop_train", "tag": "float" },  // R6: 중력 예외
    { "id": "prop_vat",  "tag": "twin"  }   // R8: 중복 1쌍
  ]
}
```

- `train` 은 하늘에 뜬다 (R6).
- `vat` 은 하나만 있다 (R8).
- 돔만 규칙을 깬다 (R7).
- **나머지 개체는 R1~R5 를 따른다.**
- → 이상해 보이지만 **되짚을 수 있다.**

---

## 4. 금지

- R1~R12 로 도출되지 않는 이상함
- 장식용 초현실 (깜빡임, 무의미한 왜곡)
- 색을 상태 표현에 사용
- 규칙을 깨는 요소가 2개 이상 (한 화면에)
- 크기가 없는 것
- 말비빔을 **화면에 그대로 찍는 것** (발생 규칙이지 표현이 아니다)

## 5. 구현 상태

| 규칙 | 구현 | 상태 |
|---|---|---|
| R2 추상화 | `content` 의 `attributes` + `shape` 블록 | **구현됨** |
| R3 형체 | `critter.gd::_spec` | **구현됨** (기하가 자rito) |
| R5 속성 | `systems/attributes.gd` | **구현됨** |
| R4 조립 규칙 | `critter.gd` 만 사용. 구조물·소품 미사용 | **부분** |
| R6 중력 | `prop.tag == "float"` | **미구현** |
| R7 크기 | `region.structure` | **구현 (형상 부적합)** |
| R8 배치 | `prop.tag == "twin"` | **미구현** |
| R9~R12 | `view.gd::_draw_space` | **부분** |

→ **소품(prop) 시스템이 통째로 없다.** R6/R8 을 쓸 자리가 없다.
→ `IMPLEMENTATION_STATUS.md` §3 참고.
