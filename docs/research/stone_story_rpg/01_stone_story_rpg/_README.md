# 01_stone_story_rpg — Primary Reference 실증

**Stone Story RPG 하나만** 다룬다. 다른 게임의 특징을 섞지 않는다.

파일명: `<topic>_<subject>_<state>.md`
예: `combat_shape_shifting_first_form.md`

`../README.md` §2의 S1~S14 상태를 **상태 하나당 파일 하나**로 만든다.
각 파일은 아래를 반드시 담는다.

1. Reference state — 원작의 어떤 화면/플레이 상태인가
2. Source — `00_user_dumps/` 원본 파일명 또는 사용자 캡처 파일명
3. 따라갈 것 — 카메라, 화면비, 셀/오브젝트 비율, 정보 밀도, 선택 위치, UI 노출 조건, 피드백 위치, 입력 흐름
4. 복제하지 않을 것 — 고유 자산, 문구, 캐릭터, 맵 배치
5. 첫 줄 `원본: 00_user_dumps/<파일명>`

근거 없는 항목은 `MISSING`으로 적는다. 추정으로 채우지 않는다.
