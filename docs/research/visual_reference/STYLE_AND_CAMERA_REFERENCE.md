현재 대화에 사용자가 직접 다시 첨부한 두 PNG를 **이번 calibration의 원본 기준**으로 삼는다.

## 눈으로 확인할 A의 특징

A에서 가져올 것은 "회화적"이라는 형용사가 아니다.

- 얼굴 중앙에 실제 구조 경계가 있고 그 경계를 따라 밝은 면과 그림자 면이 갈린다.
- 피부와 팔의 밝은 면은 매끈한 광택이 아니라 불규칙한 붓면으로 남는다.
- 머리카락은 수많은 가닥보다 큰 컬과 덩어리 안의 넓은 밝기 스트로크가 먼저 읽힌다.
- 의상도 평면색 뒤에 질감 필터를 얹은 모양이 아니라, 접힘 방향을 따라 서로 다른 값의 붓 덩어리가 겹친다.
- 배경의 단순 그래픽 모티프는 소재를 상속하지 않고, 화면 빈 공간의 리듬과 두 번째 평면 깊이층을 만드는 기능만 참고한다.

## 눈으로 확인할 B의 특징

B에서 가져올 것은 "선이 있다"는 수준이 아니다.

- 외곽과 내부 구조선의 굵기가 균일하지 않고, 겹침·얼굴·손·의상 구조에서 압력이 달라진다.
- 선 일부가 채색면에 먹히거나 끊겼다가 다시 나타나며, 모든 내부 면을 깨끗한 테두리로 둘러싸지 않는다.
- 옷의 복수 레이어와 주름이 장식의 나열이 아니라 선과 면의 방향으로 구조화된다.
- 배경은 단순 블러가 아니라 앞/중간/뒤의 평면 형태가 서로 다른 불투명도와 크기로 겹친다.
- 배경 밀도가 높아도 얼굴과 손 주변은 선·대비 계층이 분리돼 초점이 유지된다.

## 사용 금지 범위

A/B에서 다음은 상속하지 않는다.

- 얼굴형과 눈 형태
- 헤어스타일
- 의상 디자인
- 포즈
- 꽃, 잎, 하트, 별, 특수한 눈 등 구체 모티프
- 정확한 색 조합
- 서명

A·B는 Kit마다 다른 Primary Reference의 시스템·UI 계약을 없애지 않는다. 공통 세계 아트의 렌더 문법으로 보존한다.

A/B를 텍스트로 분해해 곧바로 production 자산에 평균내지 않는다. 전역 Style Master bootstrap과 Compact Visual Contract는 `docs/IMAGE_ASSET_WORKFLOW.md`, 관찰 가능한 공통 렌더 규칙은 `docs/art/PERSONAL_STYLE_CORE.md`가 소유한다.

## 사용자 확정 3D 시점

Rule Rewrite에서 `IS 3D`가 성립하면 **1인칭으로 시작**한다. 물리 키로 기존 3인칭 보드 조감 시점에 전환할 수 있고, 기존 3인칭 표현을 삭제하지 않는다. 두 시점은 같은 물리 보드·물건 ID·인벤토리 상태를 보여 준다. C는 첫 화면의 카메라/공간 읽기 기준이다. 시점 전환은 규칙을 만들거나 깨는 물리 턴이 아니며 Undo 한 단계를 만들지 않는다.

1인칭의 이동 방식과 실제 전환 키의 배치는 입력 충돌·Input Bubble을 고려해 Kit 계획에서 확정한다.

## 다른 Kit에도 쓸 아트 실험

과거 실험 이미지 파일은 `assets/shared_art_study/`에 원래 위치와 내용 그대로 보존한다. 실험 문서와 제작 도구는 `archive/icon_based_image_assets/`로 옮겼다. A·B에서 공통 스타일 방향만 참고하고, 캐릭터·구도·의상·표정·포즈는 복제하지 않는다.

기존 at-icons 실험 단계·후보 표기·조립법은 새 이미지 자산 기반으로 이어지지 않는다.

실제 자산의 스타일 적합성은 렌더 결과를 A/B 및 승인 Style Master와 나란히 보고 판정한다.
