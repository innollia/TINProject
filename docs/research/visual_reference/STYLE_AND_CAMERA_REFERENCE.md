## 사용자 확정 3D 시점

Rule Rewrite에서 `IS 3D`가 성립하면 **1인칭으로 시작**한다. 물리 키로 기존 3인칭 보드 조감 시점에 전환할 수 있고, 기존 3인칭 표현을 삭제하지 않는다. 두 시점은 같은 물리 보드·물건 ID·인벤토리 상태를 보여 준다. C는 첫 화면의 카메라/공간 읽기 기준이다. 시점 전환은 규칙을 만들거나 깨는 물리 턴이 아니며 Undo 한 단계를 만들지 않는다.

1인칭의 이동 방식과 실제 전환 키의 배치는 입력 충돌·Input Bubble을 고려해 Kit 계획에서 확정한다. 사용자의 추가 답변을 받기 전에는 자유 이동·마우스 시점 또는 기존 격자 이동 중 어느 쪽도 임의로 확정하지 않는다.

## 다른 Kit에도 쓸 아트 실험

작업 위치: `assets/shared_art_study/`. 담당 모델: GPT-6 Sol low 아트 전담. Rule Rewrite 보드의 즉시 플레이 자산과 구분한다.

제작 방식은 `res://addons/at-icons/` 원본 조각의 crop·회전·미러·비균일 배율·중첩·색 변형을 통한 재조합이다. 큰 나무·인물 파츠·폭탄·토끼와 크기별 비교 결과도 이 방식으로 만든다.

1. **큰 나무**: 전체 실루엣, 줄기·큰 가지·잎 덩어리의 분리, 멀리서도 읽히는 크기 시험.
2. **사람 기본형**: 정면 중립 포즈와 Spine식 팔·다리·몸통·목·머리의 독립 이미지. 얼굴, 머리카락, 옷을 교체 가능한 덩어리로 만들고 같은 기준 캔버스의 레이어 순서와 pivot을 기록한다. 완성된 Spine 리그나 애니메이션이라고 주장하기 전에 실제 장착·관절 회전 검수를 한다.
3. **폭탄·토끼**: 재질과 형태가 다른 소품/생물로서 스타일의 범용성을 확인한다.
4. **크기별 시험**: 동일 원본을 32·48·96·256·512px 등 실제 출력 크기로 렌더하고 형태, 얼굴, 붓질 질감이 어느 크기에서 살아남는지 나란히 비교한다. 작은 크기에서는 세부를 단순화한 별도 판본이 필요한지 기록한다. 단순한 확대/축소 한 장을 모든 크기의 합격 증거로 사용하지 않는다.

이 문서는 참고와 검수 기준이다. 실제 자산의 스타일 적합성은 렌더 결과를 사용자 이미지 A·B와 나란히 보고 판단한다.
