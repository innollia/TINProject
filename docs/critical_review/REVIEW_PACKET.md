# 비평 입력 패킷 양식

필요한 항목만 채운다. 긴 대화나 전체 문서 모음을 붙이지 않는다. 내용 없는 필드는 '미확정' 또는 '해당 없음'으로 남기고 발명하지 않는다.

```text
패킷 ID/버전:
검토 질문:
검토 역할 / 주 검토 방식:
실행 구분: SEPARATE_CONTEXT | SAME_CONTEXT
세션 식별자:
권한: 읽기와 비평만. 수정·전송·추가 세션 생성은 별도 권한을 따른다.

USER:
- ID / 사용자 원문 / 현재 적용 범위 / 결정 시점

SOURCE:
- ID / 관련 발췌 / 원문 위치 / 직접 관찰·사용자 설명·커뮤니티 기록 / 미확인 범위

TARGET (PROPOSAL):
- 검토 대상 버전·위치 / 이번 판단에 필요한 실제 본문

DIMENSIONS:
- 이번 판단에서 구별할 변수 / 관찰된 값 / 미확정 값 / 근거 없는 연결

UNKNOWN:
- 판단에 필요한데 없는 근거

OUTPUT:
- ID / 관점 / 대상 위치 / 근거 / 숨은 가정 / 영향 / 철회 조건 / 관련 축
- 근거 부족 항목
```

출력만 압축하고 근거 위치는 보존한다. SOURCE의 사건 몇 개로 작품 전체의 빈도·비율을 추정하지 않는다. 전문가 역할의 이력이나 말투는 추가하지 않는다. 실행문은 [공통 절차](../CRITICAL_REVIEW_WORKFLOW.md)의 §3을 사용한다.
