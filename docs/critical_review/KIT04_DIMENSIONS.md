# Kit04 비평용 구별 축

2026-09-27 사용자 교정과 승인된 비평 절차의 입력. 원작의 전체 분포를 실측한 문서가 아니다. [인터뷰 기록](../../plans/kits/04_TOP_DOWN_ACTION_RPG_KIT/docs/GRILLING_STATE.md)이 사용자 결정 이력을 소유한다.

## 사용자 조건

- 동화가 앞에 나오는 것은 괜찮다. 동화가 없는 곳이 없다는 편중이 문제다.
- 관계의 결말이 보이는 것은 괜찮다. 관계 자체의 진부함이 문제다.
- 역겨움의 다양성을 늘린다. 진부함을 강화·약화 문제로 바꾸지 않는다.
- 원문: '관계가 너무 많아. 스타듀벨리같아. npc중에 남자는 1/10 안쪽이어야 해'. 남성 비율 요구는 확정이다. 관계의 어느 축을 얼마만큼 바꿀지는 이 문장만으로 확정하지 않는다. '플레이어와 친밀해질 NPC를 일부로 줄인다'는 작업자 제안은 철회됐다.
- 남성 비율의 원문을 보존한다. 경계값 포함 여부와 NPC 집계 단위는 실제 명단 계산에 필요할 때만 확인한다. 비율을 충족시키려고 배경 인물을 늘리거나 역할을 임의 재분류하지 않는다.
- 사용자 검사 전에 세계관 내용과 제작 규칙의 변경을 실행하지 않는다. 승인된 비평 절차 설치와 이후 콘텐츠 재작성을 구분한다.

## 혼동하지 않을 축

| 구별할 변수 | 금지된 자동 추론 |
|---|---|
| 여성/남성 비율 · 성적 접근 가능성 · 캐릭터 매력 · 서약 · 호감도 시스템 | 여성 비율을 바꾸므로 연애나 호감도를 바꾼다 |
| 플레이어–NPC 관계 밀도 · NPC–NPC 관계망 밀도 · 관계 육성량 · 세계 사건과 관계의 결합도 | '관계가 많다'가 이 중 하나를 확정한다 |
| 동화의 사용 범위 · 동화의 노출 정도 · 원전 충실도 | 동화 편중을 해결하려면 원전을 숨긴다 |
| 관계 자체의 진부함 · 결말의 예측 가능성 · 정보 공개 시점 | 진부함은 반전이나 결말 은폐로 해결한다 |
| 역겨움의 다양성 · 강도 · 빈도 · 경험 방식 | 다양성 지적을 강도 변경이나 감각 소재 할당표로 대신한다 |
| 원작에 존재함 · 등장 빈도 · 전체에서 차지하는 비율 · 모든 콘텐츠의 의무 | 원작 사례 하나가 모든 NPC의 필수 조건이다 |

변수들은 관련될 수 있지만 같지 않다. 표는 새로운 세계 상태·런타임 수치·콘텐츠 할당량을 추가하는 명세가 아니다.

## 근거를 필요한 만큼 읽기

- 시스템·패턴: [통합 조사](../research/top_down_action_rpg/BLACK_SOULS_2_RESEARCH.md). 관찰과 TIN 추상화를 구분한다.
- 화면 기록: [A~H](../research/top_down_action_rpg/USER_PLAY_REFERENCE_2026-09-25.md). 원본 캡처를 지금 직접 본 것과 구분한다. UI 기록으로 원작 전체 서사·인구 분포를 판단하지 않는다.
- 구체 사건: [인터뷰의 레퍼런스 조사 2](../../plans/kits/04_TOP_DOWN_ACTION_RPG_KIT/docs/GRILLING_STATE.md). 커뮤니티 조사이며 버전·수치의 직접 플레이 검증은 아니다.

## 기존 규칙과 충돌하는 지점

[지도·집필 문서](../../plans/kits/04_TOP_DOWN_ACTION_RPG_KIT/world_new/00_MAP_AND_AUTHORING.md) §2의 '원전을 먼저 정한다', 도덕적 결론 예측을 탈락시키는 항목, §4–5의 전원 원전·호감·특정 신체 접촉 장면 의무는 사용자 교정과 대조해야 하는 작업자 규칙이다. 이를 사용자 승인값으로 입력 패킷에 넣거나 최신 교정보다 우선해 자동 탈락시키지 않는다.

이 문서는 기존 원전 배정·인물·사건을 새로 확정하거나 삭제하지 않는다. 해당 규칙의 구체 교체안은 사용자 검사 후 소유자가 반영한다. '모든 관계를 줄인다', '모든 동화를 없앤다', '역겨움을 약화한다'로 확장하지 않는다.
