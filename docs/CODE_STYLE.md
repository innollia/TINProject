# 코드 규칙

- 엔진은 Godot **4.7.2**로 고정한다. typed GDScript, 탭 들여쓰기, 명시적 매개변수·반환·변수 타입을 사용한다.
- 파일·함수·변수는 `snake_case`, 공유 계약·서비스의 `class_name`은 `PascalCase`다. 단일 용도 meta 스크립트는 전역 클래스를 추가하지 않는다.
- 요청 없이는 코드 주석을 추가하지 않는다. 의사결정은 짧은 문서로 남긴다.
- 노드 소유권을 명확히 하고 서비스는 `ModuleContext`로 주입한다. 모듈 간 참조, core의 구체 모듈 import, 광범위한 EventBus와 과도한 프레임워크를 금지한다.
- 명시적 승인 없이 autoload, 패키지, 플러그인을 추가하지 않는다. GUT 9.7.1은 addons/gut에 고정된 테스트 의존성이다. vendor 코드는 임의 수정하지 않는다.
- 비동기 전환의 `busy`와 앱 작업 잠금을 존중한다. 저장·설정 오류는 UI에서 알리고 첫 실행의 파일 부재는 정상 경로로 처리한다.
- 저장은 버전이 있는 JSON 호환 값만 사용한다. core는 모듈 상태를 불투명하게 취급한다. 딕셔너리 경계를 넘는 임시 스냅샷은 깊은 복사한다.
- 한 작업자는 한 담당 폴더/소유 범위만 수정한다. 다른 작업자의 파일이나 무관한 파일은 수정하지 않는다. API 변경은 먼저 조율한다.
- `.godot/`와 빌드 산출물은 제외하되 소스 `.uid`, `.tscn`, `.tres`는 추적한다. 비밀값과 사용자 저장 파일을 커밋하지 않는다.
- 검증 명령은 루트 `AGENTS.md`를 따른다. 실행하지 않은 테스트를 통과했다고 기록하지 않는다.
