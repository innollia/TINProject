# 10 — 화면 · 조작면

> **2026-09-26 전면 개정.** 1차 판은 12개 패널(월드 HUD · 인벤토리 · 상점 · 제작대 ·
> 전설 · 도감 …)과 전투 중 조작을 전제한 화면 목록이었다.
> 사용자가 폐기했다: *"플레이어의 캐릭터 조종은 없어. 로비에서 고르는 것뿐."*
> → 화면은 **2개**다. 로비와 탐험. 나머지는 복구한다.

---

## 0. 화면은 둘뿐이다

| 화면 | 언제 | 플레이어가 하는 일 |
|---|---|---|
| **로비** | 항상 기본 | 지역 / 별 / 장비 / 탐험을 고른다 |
| **탐험** | `[탐험을 보낸다]` 를 누른 동안 | **아무것도 하지 않는다** (cancel로 나가기만) |

`module.gd::mode` = `"lobby"` | `"expedition"`

### 0.1 왜 인벤토리/상점/제작대 화면이 없는가 (Phase 1 한정)

그 조작들도 **전부 로비 안으로 접었다.**
- 장비 목록 = 인벤토리 (켜고 끄기)
- `potion_at_hp` = 물약 UI
- `use_ability_below_hp` = 능력 UI

별도 화면은 Phase 2 에서 "로비가 너무 복잡해지면" 분리한다.
지금은 분리가 아니라 **한 화면에 다 보이는 게 맞는** 상태다 (사용자: "로비에서 고르는 것뿐").

## 1. 로비 — 유일한 조작면

`presentation/lobby.gd`

### 1.1 포커스 4칸 (R2)

| 순서 | 포커스 | 좌우 | Z |
|---|---|---|---|
| 0 | 지역 | 이전/다음 (열린 것만) | 확정 → 탐험 대상 지정 |
| 1 | 별 | −1 / +1 (1..20) | 확정 |
| 2 | 장비 | 다음 칸 (목록 끝이면 처음으로) | 켜고 끄기 |
| 3 | 탐험을 보낸다 | — | 탐험 시작 |

- 위/아래 = 포커스 순환 (`wrapi`)
- **닫으면 이전 포커스로 돌아온다** (`restore_focus`). 탐험에서 X로 나가면.
- **disabled 는 intent 를 내보내지 않는다.** (닫힌 지역)

### 1.2 select 와 focus 를 다른 표기로 (R2)

- **장착됨** = 왼쪽의 6×6 사각형이 **채워져** 있음
- **focus** = 해당 행의 **점선 테두리**
- 둘은 다른 형태. 색으로 구분하지 않는다.

### 1.3 좌표 (고정 격자)

내용이 바뀌어도 조작 위치가 밀리지 않는다 (R3). 전부 `const`.

```text
X_TITLE 24    Y_TITLE 44    FS_TITLE 26
X_BODY  44    Y_RULE  58
Y_REGION 100  행간격 ROW_H 30
Y_STAR 200    Y_STAR_MARKS 228  (20칸 눈금, pitch 22)
Y_GEAR 268    Y_GEAR0 300   (GEAR_ROWS 5, ROW_H 30)
Y_HINT  (300 + 5*30 + 12)
Y_GO 512      X_RIGHT 470  (정책·빌드·결과)
Y_KEYS 620
```

- 본문 16px 이상, 제목 20px 이상. (`test_v10` 이 강제)
- **도트 폰트·미니멀 텍스트 UI 금지.** 시스템 폰트 16/20/26/30.
- 긴 문자열은 고정 폭에서 자른다 (`_fit` + `…`). 최대 데이터에서 옆으로 밀리지 않는다.

### 1.4 상시 표시 (HUD 아님 — 로비 정보)

```
좌상  통화
중앙하  정책 2줄 : 스탠스 / 타깃 / 행동 / 상주가드 / 절대후퇴
        빌드 1줄 : 다리 놀랍다 틀림 동그라미 상성축
        결과 1~3줄 : 직전 탐험에서 뭐가 열렸고 얼마를 벌었나
좌하  우취얼 (20칸 눈금) + 숫자
```

이건 HUD가 아니라 **로비의 정보**다. 매 순간 필요한 판단의 재료.

### 1.5 공간도 칠한다 (V11)

로비 배경 = 하늘 그라데이션 8단 + 지평선(150) + 바닥 + 천장 레일.
**검정 배경 + 흰 글자 금지.** `test_v11` 이 정적 검사한다.

## 2. 탐험 — AI 화면

`presentation/view.gd`

플레이어가 하는 일 = 없다. 화면은 **AI가 뭘 하고 있는지 보여주는** 곳.

### 2.1 공간 계약 (V1)

```text
모든 조명된 장면 = 하늘/천장 + 지평선 + 바닥 + 구조물 1개 이상
```

- `HORIZON_Y = 243` (화면 높이의 38%). 고정.
- 하늘: 12단 그라데이션 면 (far→near)
- 구름/태양: 3원 합성 면
- 바닥: 6단 면 (근경으로 갈수록 밝음)
- 원경 구조물 1개 (높이 25%+) — **종류는 content `structure` 값**
- **빈 검정 화면 금지.** (V2)

### 2.2 면이 기본 (V3/V4)

- 기본 단위는 **채워진 면.** 선은 경계용.
- 헤어라인만으로 공간을 만들지 않는다.
- 1px 선은 액센트/경계/초점에만.

### 2.3 개체

`critter.gd` 가 4속성 → `ProceduralShape` 스펙을 만든다.
`_draw_critter` 가 파트별로 다르게 그린다:
몸통(면) · 머리(링) · 꼬리(선) · 다리(선+끝 면).

- **눈이 있다.** 개수 = `floor(놀랍다/3) + 1` (1~4). (V8)
- 예고: 공격 방향 1px 화살표, `awaken` 은 링, `staggered` 는 `*`

**알려진 결함**: 아직 "선 + 원"이다. 실루엣 3종을 authored 폴리곤으로
만들어야 한다. → `17_OPEN_QUESTIONS.md` A3

### 2.4 HUD (월드 위)

- 좌상 통화 · 중앙상 목표 · 우상 별 · 좌하 생명 · 우하 장비
- **5개 이하.**
- 월드 정보는 오브젝트 실루엣과 색면으로 전달. HUD는 최소.

## 4. 아직 없는 화면 (Phase 2)

아래는 **설계가 있고 구현이 없다.** 이번 Kit 에 넣지 않는다.

- NPC 대화 (선택지 · 스크롤)
- 제작대 (4동사 UI)
- 상점 (재고 · 가격 증가)
- 전설 (노드 그래프)
- 도감 (`observe` 돌)

모두 **로비 위에 겹는 패널**로 만든다. 별도 씬 아님.
