# 10 — 화면 · Presentation

모든 좌표는 **960×540 논리 픽셀** 기준. `01_RENDER_PIPELINE.md` 규칙을 따른다.

## 1. 화면 목록 12종

| # | 화면 | 여는 방법 | 닫는 방법 |
|---|---|---|---|
| 1 | `title` | 부팅 | `confirm` |
| 2 | `region_select` | `confirm` on title | `cancel` |
| 3 | `cutscene` | 사건 발생 | `confirm` (스킵 불가면 자동) |
| 4 | `field` | 지역 진입 완료 | 자동 전투 AI 진행 |
| 5 | `combat` | 적 조우 | 자동 / `나가기` |
| 6 | `beastiary` | `observe` 돌 보유 + `≡` | `cancel` |
| 7 | `chest` | 상자 접촉 | `confirm` / `cancel` |
| 8 | `inventory` | `아이템` 입력 | `cancel` |
| 9 | `workbench` | `작업실` 입력 | `cancel` |
| 10 | `shop` | 상점 지역 진입 | `cancel` |
| 11 | `legend` | `quest` 돌 보유 | `cancel` |
| 12 | `status` | `≡` 입력 (스탯 배분/도감) | `cancel` |

- `Esc` 는 전 화면에서 **강제 종료가 아니라 `cancel`** 이다.
- 전투 중 `나가기` 는 전투를 즉시 끝내지 않는다. 후퇴 후 지역 시작부.
  → `12` §3

## 2. 공통 레이아웃

```text
좌상 (12, 10)     통화
상단중앙 (480, 10) 목표/경고 (가운데 정렬)
우상 (948, 10)     보유 화폐 2~3 glyph (우정렬)
좌하 (12, 528)     생명 3~5 glyph
우하 (948, 528)    퀘스트 카운터 (우정렬)
중앙 (480, 300)    대사/팝업
```

- HUD 요소는 **최대 4개.** 1번 레이아웃을 그대로 쓴다.
- HUD에 박스·프레임·배경 없음.
- 패널은 모두 **우측 정렬 또는 중앙 정렬** 두 가지 중 하나.

## 3. HUD 규칙

| 요소 | 내용 | 갱신 | 조건부 |
|---|---|---|---|
| 좌상 | `currency` 2~3 glyph | 이벤트 | 항상 |
| 우상 | 진행도 2~3 glyph | 이벤트 | 항상 |
| 좌하 | 생명 | 틱마다 | 항상 |
| 우하 | `quest_counter` `12/40` | 이벤트 | `quest` 돌 보유 시에만 |

- **퀘스트 카운터는 돌을 얻기 전에는 없다.** = 스크린샷 근거
- 스탯/장비/인벤토리 정보는 **상시 표시하지 않는다.** → `status` 화면.
- HUD가 5개가 되면 하나를 지운다. 새로 넣지 않는다.

## 4. 상태 8종 (모든 interactive 화면)

| 상태 | 표현 | 금지 |
|---|---|---|
| `initial` | 첫 focus 위치 | 자동 focus 없음 |
| `normal` | focus 없음 | — |
| `focus` | **점선 테두리** | 색 변화 |
| `selected` | 흰 1×1 칩 + 선택 표시 | 색 변화 |
| `disabled` | 점선 대신 **짧은 실선** 1줄 | 회색 처리만 |
| `error` | 상단에 사유 1줄, 위치 고정 | 색으로만 알림 |
| `success` | 상단에 결과 1줄 | 색으로만 알림 |
| `closing` | 즉시 제거. 모션 없음 | 페이드 아웃 |

추가 (필요 화면):

| 상태 | 조건 | 표현 |
|---|---|---|
| `empty` | 재고 0 / 인벤토리 0 | 가운데 `─` 1줄 + 문구 1줄 |
| `maximum` | 인벤토리 만주 | **갱신 금지**(perf) |
| `long_text` | 최장 전설 문단 | 12px + 줄바꿈 + 아래로 스크롤 |
| `save_restored` | 세이브 로드 직후 | 아무 표시 없음 (조용히) |
| `reset` | 리셋 직후 | 아무 표시 없음 |

### 4.1 focus 규칙 (엄격)

1. 포커스 = **점선 테두리**. 색으로만 구분 금지.
2. `selected`(적용됨) ≠ `focus`(다음 대상).
   - 상점에서 `장착 중` 표시와 커서 위치를 **다른 위치**에 둔다.
3. 색상은 절대 focus 표현에 쓰지 않는다.
4. 패널을 열면 **명시된 초기 focus** 로 간다. 없으면 첫 항목.
5. 패널을 닫으면 **호출 직전 focus** 로 돌아간다.
6. 대상이 사라지거나 비활성화되면 → **다음 유효 항목**. 없으면 `빈 상태의 닫기 버튼`.
7. hover 전용 정보가 있으면 키보드로도 동일 접근 가능해야 한다.
8. 마우스 없이 전 기능 수행 가능.

## 5. 화면별 좌표

### 5.1 `title`

```text
(480, 300) 중앙 위: 게임 제목, 14px
(480, 340) 조작 안내 없음.에이서.
(480, 420) 아래: 계속 1줄, 12px, focus 시 점선 밑줄
```

- HUD 없음.
- 배경은 절차적 벽/바닥 텍스처만. `mood` 밀도.

### 5.2 `region_select`

```text
(48, 40)  좌측 섹션 라벨 "지역"  12px
(48, 70)  좌측 목록 (_region 이름들), 각 행 24px 간격
(520, 60) 우측 대형 패널 420 x 380
          ├ (540, 90)  지역 이름 14px
          ├ (540, 120) 리전 그래프 줄 형태의 선 (절차)
          ├ (540, 170) 적 구성 요약 1줄
          ├ (540, 200) miniboss / boss 유무 표시
          └ (540, 250) 별(★) 선택 줄 — stone_of_degree 보유 시에만
(48, 500) 좌하: `◀ ≡` 리턴 글리프 (호출 시에만)
```

- 좌측 목록 focus → 우측 패널 내용 갱신.
- 별 선택 줄은 돌이 없으면 **행 자체가 없다.** 빈 칸 남기지 않는다.

### 5.3 `cutscene`

```text
(480, 300) 텍스트 블록 중앙 정렬, 12px, 줄바꿈
(480, 480) `◀ 확인` 12px — 스킵 불가 컷신에는 표시하지 않음
```

- 스킵 불가: 입력을 무시한다. 강제 대기.
- 발견 컷신의 확인 모달: 중앙 `(360,240)-(600,300)` 1px 박스 + `계속하기`.

### 5.4 `field` / `combat`

```text
월드: (0,0)-(960,540) 전체를 월드 좌표로 매핑
월드 상단 대역 y=0..180: 벽 (원근 수직)
월드 중단 대역 y=180..470: 바닥
월드 하단 대역 y=470..540: 지면 텍스처 대역
HUD: §2 레이아웃
(400, 430)-(560, 470) 하단 중앙: `나가기` / `아이템` 2버튼 (전투 중)
```

- 카메라 고정. 스크롤 없음.
- **월드는 월드 좌표로 계산하고 그릴 때만 픽셀로.** → `01` §2
- 세 대역 높이는 지형 데이터가 준다 (레이아웃 상수가 아니다).

### 5.5 `beastiary`

```text
(48, 40)  좌측: 적 목록
(520, 60) 우측 패널: 스탯 테이블 (2열, 8~12행)
(520, 300) 상태 축적 3줄
(520, 380) 무법 목록
```

- 정보는 **숫자로** 보여준다. 말줄임 금지.
- 전투 중 열어도 시뮬레이션은 멈추지 않는다. (원작 AI가 계속 행동)
  → 화면은 `world_overlay` 로 그린다. 전투 상태를 읽기만 한다.

### 5.6 `chest`

```text
(280, 160)-(680, 380) 대형 박스
(480, 190) "보물 상자" 12px 중앙
(480, 270) 중앙: 상자 아이콘 (절차 드로잉, 개방 전/후 2형태)
(300, 270) 좌측 세로 tick 바 (개방 진행도)
(660, 270) 우측 세로 tick 바
(480, 420) 내용 목록 1줄씩
```

- 개방은 **1틱 1항목.** 전부 한 번에 보여주지 않는다.
- 개방 중 `cancel` → 중단. 이미 나온 항목은 유지.

### 5.7 `inventory`

```text
좌측 (48, 60)  섹션 3개: "지역" / "작업실" / "아이템"
                각 섹션 아래 획선 프레임 + 보유 표시
상단 (520, 40)  3슬롯: 주무기 / 주문매체 / 방패
중앙 (520, 160) 5열 그리드, 3행 = chest 슬롯
                각 칸: 등급 아이콘 + 내용물 수
하단 (520, 430) 필터 줄 (아이템 / 인챈트 / 재료)
좌하 (48, 500) `≡` 메뉴
```

- chest 슬롯 = `chest_cap`. 초과분은 **그리지 않는다.**
- 슬롯이 비면 칸 안에 `─` 1줄.
- `≡` 는 호출 시에만 나타난다.

### 5.8 `workbench`

```text
좌측 (48, 60)   "작업대" 섹션
중앙 (300, 120) 슬롯 좌 (40x40 1px 박스)
중앙 (620, 120) 슬롯 우 (40x40)
중앙 (480, 200) 결과 미리보기 (1줄)
하단 (300, 420) 버튼 4개: 업그레이드 / 제작 / 봉인 / 분해
                     (fissure/fuse 돌 보유 시에만)
상단중앙 (480, 10) 결과/사유 1줄
```

- 4개 버튼은 **항상 같은 위치**에 있다. 돌이 없으면 해당 버튼을 그리고 「─」로 대체.
  → 빈 칸을 남기지 않는다. 위치가 흔들리지 않는다.
- `boost` 는 `is_lost` 무기일 때만 활성. 그 외는 `disabled`.

### 5.9 `shop`

```text
좌측 (48, 60)  상점 이름 + 통화
우측 (440, 60) 행 x 열 그리드 (3x2 기본)
              각 칸: 절차 아이콘 + 가격 (우하단 정렬)
하단 (440, 420) Chest 판매 줄
좌하 (48, 500) `◀ 뒤로` 박스 버튼
```

- `no_funds` 시 가격 숫자 유지 + 아래 1줄 짧은 선.
- `sold_out` 시 가격 자리에 `─`.
- 계절 상점은 3열.

### 5.10 `legend`

```text
좌측 (48, 60)  전설 목록 15개, 각 행 20px, 현재 전설 점선 표시
우측 (440, 60) 본문 텍스트 블록 (12px, 줄바꿈, 세로 스크롤)
중앙 (480, 400) 선택지 2~3개, 각 1줄, focus 시 점선 밑줄
```

- 스크롤은 `▲`/`▼` 글리프로. 마우스 휠도 허용.
- 최장 텍스트: `15_MANUAL_PLAY.md` §3에서 실측.

### 5.11 `status`

```text
중앙 (240, 80)  3x3 스탯 그리드
                각 칸: 이름 + 현재값 + 다음값
중앙 (240, 380) stat_points 표시 + [분배] 버튼
우측 (600, 80)  장비 목록 (4칸)
좌하 (48, 500)  `◀ 뒤로`
```

- 스탯 변경은 **확정 버튼**을 눌러야 반영된다. 즉시 반영 금지.
- 최대 스탯(99) 셀은 `disabled`.
- 재배분 버튼은 `respec` 돌 보유 + 횟수 남음일 때만 존재.

## 6. 화면 전이

```text
title → region_select → cutscene → field ↔ combat
                                    ↓
                        chest / inventory / workbench / shop
                                    ↓
                              region_select (지역 완료)
```

- 전이 중 입력은 차단된다. `ModuleContext.input_enabled = false`.
- 전이 실패 시 **현재 화면에 머문다.** 빈 화면으로 가지 않는다.
- 모든 패널은 `ModuleHost` 위에 그리지 않는다. 이 모듈 안에서만.

## 7. 오닉스 프레임

원작 화면에 있는 각선 오닉스 프레임. **절제해서** 쓴다.

- 사용 위치: 3곳 이하 (좌측 섹션, 지리 그래프, 사망 화면).
- 각선 = 6px 단위 `hatch`. 채우는 금지.
- 3회 이상 나타나면 장식이 된다. → 최소로 줄인다.

## 8. 채굴

- `stone_of_ledger` 보유 + 지역에 채굴 지점이 있을 때.
- `field` 에 `상호작용` 지점으로 표시 (가장 가까운 지점에만 `◊`).
- 접촉 시 `chest` 화면과 같은 흐름으로 1틱 1항목 파낸다.
- 재료만 나온다. 아이템/인챈트는 나오지 않는다.

## 9. 금지

- 상시 HUD 5개 이상
- 색으로 focus/상태 표현
- 선택 항목의 말을 인박스/말줄임으로 숨기기
- 빈 칸을 남기고 그려두기
- 화면을 가로지르는 상시 패널
- 버튼 목록으로 월드 플레이 대체
- placeholder 사각형
- 패널 열림/닫힘 모션
