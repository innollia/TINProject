# 16 — 완료 기준

사용자 확정: **완료 기준은 사용자가 새로 말한 Stone Story 규모.**

### 1.2 절차 생성 범위

- 12개 지역 × 5개 밴드 전부에서 재생성 가능.
- `D1`~`D5` 결정론 테스트 통과.
- 생성기가 authored ID 를 하드코딩하지 않음 (정적 검사).

### 1.3 플레이타임

- 메인 8시간+. 실측 기록.
- "대기 / 이동 / 반복 노가다" 로 채우지 않는다.
- 10분은 15개 전설 중 최소 3개 완주 + 12개 지역 중 4개 클리어로 구성.

## 2. 품질 게이트

### 2.1 Primary Reference 일치

- [ ] 스크린샷 10장 대응 화면이 실제로 같은 화면 문법으로 나온다
- [ ] 순수 검정 / 1px 헤어라인 / 채움 없음 / 무채색 원칙 유지
- [ ] HUD 4모서리, 2~3 glyph, 박스 없음
- [ ] focus 가 점선 테두리이며 색이 아니다
- [ ] 대사가 중앙~하단 가로 박스 + `<)` 글리프
- [ ] 상점/보물창/작업대가 우측 정렬 대형 패널
- [ ] 레벨업 모달이 중앙 박스 + 단일 버튼

### 2.2 절차 비주얼

- [ ] 이미지 파일 0개 (`modules/stone_story_rpg/` 하위)
- [ ] ASCII 문자 렌더링 0개
- [ ] 정수 배 외 스케일 출력 0건
- [ ] 앵티에일리어싱 0건
- [ ] 1px 초과 선 굵기 0건
- [ ] 채움 면 0건
- [ ] 색으로 상태 표현 0건
- [ ] 상태가 모양으로 구분됨

### 2.3 시스템

- [ ] `04` §4 의 데미지 파이프라인 10단계가 순서대로 구현됨
- [ ] 요구치 미달 페널티가 **플레이에서 체감됨**
- [ ] 소프트캡이 두 무릎에서 체감됨
- [ ] 강화는 소프트캡을 우회하지 못함
- [ ] 5개 데미지 타입이 각각 다른 방어 경로로 동작
- [ ] 3개 상태 축적이 각각 다른 디버프로 동작
- [ ] 자동 전투가 무입력으로 완주됨
- [ ] 개입 창 3종이 각각 실제로 유효함
- [ ] AI 가 빌드를 읽어서 손패를 고름
- [ ] 스타 레벨이 콘텐츠를 실제로 바꿈
- [ ] 5개 동사 파이프라인이 전부 동작 (제작/인벤토리/상점/돌/전설)

### 2.4 검증

- [ ] 자동 테스트 `14` 전 항목 통과

- [ ] `15` 의 40개 수동 과제 전부 기록
- [ ] 1280×720 / 1920×1080 / 2560×1440 캡처 존재
- [ ] 미검수 항목 0개

- [ ] 색 focus 0건
