## 1. 인물의 몸과 생활 (지도 §5-1)

도엘은 성인, 외견 30대 중반. 전체 비율 약 7등신이나 오른 정강이 아래가 의족이라 서면 왼쪽으로 반 뼘 기운다. 어깨는 소하보다 곧고 목이 길다. 얼굴은 광대가 높고 뺨이 패였다. 눈은 깊고 아래 눈꺼풀이 검게 젖어 있다. 코는 콧대가 곧고 콧방울이 좁다. 입은 얇고 아래턱을 앞으로 문다. 머리는 검은색, 귀를 덮는 길이가 늘 젖어 이마와 목에 붙는다. 마른 곳에 있어도 물기가 가시지 않는다. 피부는 소금기로 튼 갈색이며 손등과 목에 흰 가루가 앉는다. 창백한 인형 피부로 만들지 않는다.

옷은 무릎까지 오는 두꺼운 뱃사람 상의, 앞섶을 왼쪽으로 여며 나무 단추 셋으로 잠근다. 아랫단과 오른 소매가 소금물에 굳어 뻣뻣하다. 허리에는 접은 밧줄 한 타래를 걸었다. 꽃무늬는 쓰지 않는다. 왼발에는 물에 부푼 가죽 신 한 짝, 오른쪽은 의족이다.

**의족**: 무연이 절단한 정강이 아래에 끼운 나무·금속 다리다. 종아리 대신 세로 나무 살 넷을 쇠테로 묶었고, 그 살 사이에 잘게 깨진 유리 조각을 박았다. 걸을 때 유리가 서로 스쳐 마른 방울 소리를 낸다. 발목에 해당하는 자리에는 접이식 칼날이 한 장 접혀 있다(제작자 S23 돈, World §5). 발바닥은 넓적한 나무판이라 젖은 바닥에 자국 대신 긁힌 선을 남긴다. 의족 안쪽에는 무연이 지은 매듭(두 가닥을 함께 꼰 봉합실과 같은 매듭)으로 종아리 살에 끈이 걸려 있다. 이 끈이 배수 추 걸쇠에 묶인 것이 감금 구조다(World D02).

**같은 균열의 통증**: 플레이어의 오른발과 도엘의 잘린 정강이는 소금 통에서 같이 절여진 뒤 나뉘었다. 무연이 붙일 때 “같은 균열”이라 부른 접합면을 공유한다(World §2.3 19일 전 행). 한쪽을 건드리면 다른 쪽이 저린다. 플레이어가 자기 발을 떼려 하면 도엘의 정강이 안쪽이 경련하고, 그 경련이 의족을 차올린다(World §4.1 도엘 행, §10 B01).

버릇: 말하기 전에 젖은 앞머리를 손등으로 한 번 쓸어 넘긴다. 물을 무서워하지 않지만 고인 물에 손을 담그지 않는다. 서면 오른 의족을 왼발 뒤에 반걸음 숨긴다. 무언가를 부탁할 때 순서를 먼저 못박는다: 끈, 그다음 발. 급하면 명사 대신 “끈. 먼저 끈.”만 남는다. 기호: 마른 밧줄, 바람이 통하는 곳. 혐오: 문틈, 뚜껑 닫힌 통, 발밑이 물러지는 바닥. 이 기호를 전부 숨은 역사 단서로 승격하지 않는다. 젖은 머리는 세계 원리의 표식이 아니라 구덩이 물에서 나온 몸의 상태다.

## 3. 외형 상태와 배치 요청 (지도 §5-6, H0 담당에게)

좌표는 H0 담당 소유다. 아래는 상대 앵커 요구이며, H0의 실제 bounds·통행폭·깊이·위험 경계와 충돌하면 이 표를 통합 수정한다. 도엘 본체와 끈·문·추가 같은 상호작용 반경에 겹치지 않게 한다(H0 §5 N12 행과 맞춤).

| 상태 | 배치 요청 / 행동 | 외형·소품 차분 |
|---|---|---|
| 발견 전 | H0-C 5호 구덩이 (H0 §5: 1600,220), 상체만 물 위로 노출. 문밖에는 두드림·물소리만 | 젖은 머리가 얼굴에 붙음. 의족은 물속. 문틈으로는 보이지 않고 소리만 |
| 문밑 끈 확인 | 5호 문밑 끈 C2 반응. 아직 상체 노출 상태 | 끈이 당겨질 때 물 밑에서 어깨가 한 번 들림 |
| 끈 해제 진행 | 5호 안 연결점 C3 작업 중. 도엘은 물속에서 상체를 세우려 함 | 의족이 물 위로 반쯤 올라옴. 유리 살에 물방울 |
| 구조 직후 | H0-D 운반판 옆 안전점 (H0 §5: 990,370) | 물이 빠진 머리, 의족 나무판에 낀 물때. 앉아서 정강이를 문지름 |
| 발 소유 다툼 | 플레이어 곁, 구조 직후 안전점 또는 이후 경로 | 왼발로 몸을 지탱하고 오른 의족을 앞으로 내밈. 손은 플레이어 발 쪽을 가리킴 |
| 발 되찾음 | R1 또는 바닷문 쪽 경로 | 오른발이 제자리, 의족은 손에 든 채. 걸음이 곧아짐 |
| 발 잃은 채 감 | 안전점에서 배 쪽으로 | 의족 그대로. 젖은 자국이 바닷문 방향으로 남음 |
| 사망 | 5호 구덩이 안, 물 밑 | 의족만 물 위로 뜸. 두드림 중단. 살아 있는 초상/대사 숨김 |

이 배치는 H0 §5·§6의 N12 훅(N12_ROPE_SEEN/FREED/FOOT_REQUEST)과 맞춘다. 도엘이 죽어도 배 자체는 남고, 배 수리는 다른 생존자와 가능하다(World §4.1). 도엘을 배경에 굽지 않는다.

## 4. 상태 판정과 우선순위

생존은 `alive / dead / departed / absent` 제작 별칭으로 구분한다. 관계와 독립이다.
- `alive`: 구조되어 해안에 있음(발 소유는 미정 또는 유지).
- `departed`: 발을 되찾아 출항했거나, 발을 잃은 채 배로 떠남. 이후 H0에 없음.
- `dead`: 발 먼저 분리로 익사, 또는 여관 굶주림 말기에 5호에서 굶어 죽음(지도 §3.1).
- `absent`: 아직 발견 전.

대사 우선순위: 사망 확정 → 익사 직전 → 구조 직후 → 발 다툼 → 발 되찾음/잃음 확정 → 문밖 두드림(발견 전) → 재방문. 상태 선택은 진입 시점 사실을 읽고, 대화 종료 직전 생존을 다시 확인한다. 같은 사건 결과를 대화 재개로 중복 적용하지 않는다.

관계 없이도 구조는 가능하다. 5호는 한 달 전부터 잠기지 않아 열쇠가 필요 없고, 도엘 구조는 소하 관계 단계에 잠기지 않는다(지도 §3.1). 도엘과의 관계는 다음 4개 이산 상태로 초안한다. 정식 `rel_*` 부여·06 바인딩은 미납품이다.

| 별칭 | 진입 행동 | 유지되는 실제 변화 / 다음 갈래 |
|---|---|---|
| P0 문 너머 소리 | 발견 전 | 두드림·물소리만. 대화 불가 |
| P1 끈 먼저 | C3에서 끈을 먼저 풀고 구조 | 발 소유 다툼으로 감. 배 동행/발 반환 갈래 열림 |
| P2 발 먼저 | 끈 해제 전 발 분리 실행 | 도엘 `dead`(익사). 재초기화 없음 |
| P3 방치 | 여관 굶주림 말기에 5호를 열지 않거나 운반 없음 | 도엘 `dead`(굶주림, 지도 §3.1). 두드림 중단 |

P2·P3는 비가역이며 원래 상태로 돌아가는 edge를 두지 않는다(지도 §3.2). 사망은 관계 상태가 아니고 전역 생존 입력이 모든 생전 전이를 막는다. 호감·서약·플레이어 성별은 판정 입력이 아니다.


## 5. 행동표 (지도 §5-4)

모든 선택은 hover/focus로 결과를 적용하지 않는다. 취소는 원래 대상 focus로 복귀하고 자원·시계·관계를 소비하지 않는다. 없는 물건은 비활성으로 남긴다. 끈 조작과 발 조작의 상호작용점은 H0가 소유하며(C2 문밑 끈, C3 의족 연결점, C4 배수 추 걸쇠), 이 표는 그 결과에 붙는 도엘의 행동만 정한다. 도엘은 다른 인물의 결과를 임의 소유하지 않는다.

| 행동 별칭 | 선행 / 입력 | 즉시 결과 | 지연 / 실패·거절 |
|---|---|---|---|
| DO-KNOCK | 발견 전, 5호 문 앞 접근 / 없음(수동 재생) | 문밖에 물 밑 두드림·긁힘. 규칙적이지 않음 | 굶주림 말기 도달 시 두드림 약해지고 멈춤(지도 §3.1). 대화 불가 |
| DO-ROPE-SEE | 5호 문밑 끈 C2 살피기 | 끈을 당기면 물 밑 어깨가 한 번 들리고 두드림이 잠깐 멈췄다 다시 남 | 문밑에서 당기기만 하면 해제 아님. 첫 확인은 사망 입력 아님(H0 C2) |
| DO-FREE | 5호 열고 C3에서 매듭 풀기 또는 칼로 끈 자르기 | 연결 해제. 도엘 상체가 물 위로 올라옴. `alive` 확정, P1 | 추만 받친 상태(C4)는 해제 아님. 발 처치 요청 DO-FOOT-ASK로 이어짐 |
| DO-DROWN | 끈 해제 전 발 분리 실행(H0 C3 경고 무시) | 같은 균열의 통증으로 도엘 정강이 경련→의족이 추 걸쇠를 차올림→추가 내려가 상체를 물속으로 끌어넣음. `dead`(익사), P2 | 살펴보기·대화 취소는 실행 입력이 아님. 확정 후 재초기화 없음. 두드림 실제 중단 |
| DO-STARVE | 여관 굶주림 말기+5호 미개방/미운반이 한 식사 시각 더 지남 | 5호 귀환자 셋과 함께 도엘 그 자리에서 죽음(지도 §3.1) | `dead`(굶주림). 열려 있던 5호였으면 셋은 복도로 나오고 도엘 시신은 구덩이에 남음 |
| DO-TOWEL | 구조 진행 중 소하가 수건을 놓음(N01 SH-DOEL) / 도엘에게 대기 | 구조 직후 도엘이 수건으로 얼굴·목의 물을 닦음. §6.3 반응 | 수건이 없으면 소매로 닦음. 소하 부재·사망이면 수건 없이 진행 |
| DO-FOOT-ASK | P1 구조 직후 / 발을 봄 | 도엘이 플레이어 오른발을 가리키며 자기 것이라 함. 발 다툼 시작 | 무연 생존 시 “소금 통. 그 사람.”, 사망 시 “그럼 잘라.” |
| DO-FOOT-REFUSE | 발 다툼 중 / 반환 거절(발 유지) | 도엘은 물러서지 않고 다시 요구. 관계 P1 유지, 배 동행 갈래 닫히지 않음 | 반복 거절 시 도엘은 배 쪽으로 먼저 감(§6.4). 발 잃은 채 `departed` 가능 |
| DO-FOOT-GIVE | 발 다툼 중+무연 도구 또는 학교 절단법 확보 / 발 반환 실행 | 발을 떼어 도엘에게 줌. 도엘 오른발 복구. 플레이어는 지팡이 이동(결말 B와 연결) | 절단 도구·안정 조건 없이 실행하면 실패 연출, 발 붙은 채 유지. 무연 사망 시 학교(R8) 경로 |
| DO-LIE-SEEN | 소하의 “빈 방이야”가 자기를 5호로 보냈음을 도엘이 알게 되는 입력(§6.5) / 없음(자동) | 도엘이 소하 쪽을 한 번 보고 말이 끊김. 이후 소하에게 순서 명령을 쓰지 않음 | 동기 해설 없음. 소하를 공격하는 별도 입력은 만들지 않음(연결 요청 §11-3) |
| DO-FOOT-FOUND | 소하가 맡긴 발의 행방을 도엘이 확인하는 입력(§6.5) / 없음(자동) | 도엘이 자기 발이 플레이어에게 갔음을 앎. 발 다툼의 대상이 소하가 아니라 플레이어임을 재확인 | 동기 해설 없음. 소하 반환·사과 장면으로 대체하지 않음 |
| DO-BOARD | P1+발 상태 확정(유지 또는 반환)+배 접근(결말 A/B 조건) / 배에 오름 | 도엘이 배 한 자리에 앉음. 다른 사람 몫이 없음을 이 시점에 드러냄(§6.6) | 결말 발동은 이 파일이 하지 않음. World §11 A/B 조건을 따름 |
| DO-SEAT-DENY | DO-BOARD 시 플레이어/동행이 함께 타려 함 / 자리 요구 | 도엘이 자리 하나뿐임을 말함. 함께 타는 선택은 배가 가라앉거나 한 사람만 남는 결과로 감(World §11, R1 담당 확정 요청) | 강제 동승 자동 성공 없음. 자리 다툼을 전투로 만들지 않음 |

도엘은 독립 보스 변신을 하지 않는다. 익사·굶주림 외 도엘발 사망은 없다. 구조를 위해 K12와 싸우는 것과 도엘 구조는 다른 사건이다.


## 6. 대화 작성·표현 계약 (지도 §5-3, 5-7)

각 인용은 실제 발화 한 페이지다. `/`는 다음 페이지이며 한 페이지 최대 3줄. 아래 대사는 한 줄 또는 명시된 2줄이다. 괄호 안 행동은 제작 지시이고 게임 자막으로 낭독하지 않는다. 선택은 최대 6개, 이전 페이지의 복귀 focus가 없으면 첫 행. 위험한 모든 선택을 빨갛게 칠하지 않는다. `extreme`는 발 먼저 분리 실행에만 지정한다. 비활성 행도 focus 가능하며 확정해도 결과 없음. 도엘은 동기 해설을 하지 않고, 소하의 동기를 대신 말하지 않는다.

### 6.1 문 너머 P0 — DO-KNOCK

(5호 문 앞. 대사 없음. 물 밑에서 뭉개진 두드림과 긁힘. 규칙적이지 않다.)

문에 대고 부르면 두드림이 잠깐 커졌다 멈춘다. 말은 돌아오지 않는다.

### 6.2 문밑 끈 P0 — DO-ROPE-SEE

문밑 끈을 살핀 뒤 당기면, 물 밑에서 한 마디만 뭉개져 올라온다.

“끈.”

선택: `당긴다` / `문을 연다` / `물러난다`.

- 당긴다: “먼저.” (어깨가 한 번 들렸다 다시 물속.)
- 문을 연다: 대사 없음. 5호 안으로 진입, §6.3로.
- 물러난다: 두드림이 다시 시작된다.

### 6.3 구조 P1 — DO-FREE·DO-TOWEL

(5호 안. 도엘의 상체가 물 위, 의족은 물속. 끈이 배수 추 걸쇠에 걸려 있다.)

“끈. 먼저 끈.”

선택: `끈을 푼다` / `발부터 뗀다`(extreme) / `추를 받친다` / `물러난다`.

- 끈을 푼다: (매듭 풀림 또는 칼로 자름. 상체가 올라온다.) “올라간다.” → §6.3 이후로.
- 발부터 뗀다: §6.7로. 확정 전 이 선택은 결과 없음.
- 추를 받친다: “그거 말고. 끈.” (추만 받친 상태는 해제가 아님. H0 C4.)
- 물러난다: “가지 마.” 두드림으로 돌아감.

끈이 풀린 직후:

“나왔다.”

(수건이 놓여 있으면 DO-TOWEL) 수건을 집어 얼굴과 목을 닦는다. “젖었어. 계속.” (소하가 준 수건이라는 설명은 하지 않는다. 물을 닦는 행동만.)
(수건이 없으면) 소매로 얼굴을 훔친다. “됐어.”

구조 직후 처음 서려다 왼쪽으로 기운다: “다리.” (의족 나무판이 물때로 미끄러짐. 앉아서 정강이를 문지른다.)

### 6.4 발 다툼 P1 — DO-FOOT-ASK·REFUSE·GIVE

(도엘이 플레이어의 오른발을 본다.)

“그거 내 거야.”

선택: `내 발이야` / `누구 발인데` / `가져가` / `나중에`.

- 내 발이야: “발목 아래. 오른쪽.” (자기 정강이 끝을 가리킨다. 같은 균열을 안다는 사실만.)
- 누구 발인데: “소금 통에 뒀어. 그 여자한테.” (소하를 이름으로 부르지 않고 “그 여자”. 왜 붙였는지는 모른다.)
- 가져가: DO-FOOT-GIVE 입력. 절단 도구·안정 조건 확인.
- 나중에: “나중에 언제.” (물러서지 않는다. 발 다툼 유지.)

발 반환을 거절(발 유지)하면: “그럼 네가 신어.” (의족 앞으로 몸을 지탱하고 배 쪽을 본다. 반복 거절 시 §6.6로 먼저 감.)

무연 생존 확인 뒤 발 처치: “소금 통. 그 사람이 해.”
무연 사망 확인 뒤: “그럼 잘라. 위에서 배운 놈.” (R8 절단법. 도엘 의족 안 칼날 제작자가 학교 학생이다.)

발을 떼어 주는 데 성공: “……가벼워.” (오른발을 제자리에 맞추고 의족을 손에 든다. 걸음이 곧아진다. 플레이어는 지팡이로 이동.)
발을 떼려다 조건 미달로 실패: “아직. 붙어 있어.” (경련만 오고 분리 안 됨. 발 유지.)

### 6.5 소하의 거짓말과 발의 행방 — DO-LIE-SEEN·DO-FOOT-FOUND

이 두 절은 동기 해설을 쓰지 않는다. 도엘이 사실을 아는 순간의 행동만 쓴다.

**거짓말을 알게 됨(DO-LIE-SEEN)**: 전날 소하가 복도로 가는 자기에게 “빈 방이야”라고 한 것이, 발을 거기 숨겼다고 믿고 5호를 열게 한 말이었음을 도엘이 알게 되는 입력. (예: 플레이어가 소하의 그 말을 도엘 앞에서 전하거나, 5호 안에서 소하의 목소리를 다시 들음. 실제 입력점은 H0/N01 담당과 맞춘다 — §11-3.)

“빈 방이라며.”

(소하 쪽을 한 번 본다. 말이 끊긴다. 이후 도엘은 소하에게 순서 명령 “끈. 먼저”를 쓰지 않고 말수가 준다.) 그 뒤 소하에게 처음 말하면: “……물.” (소하가 물을 틀던 것을 안다는 한 마디. 추궁하지 않는다.)

**맡긴 발의 행방을 앎(DO-FOOT-FOUND)**: 소하가 자기 발을 플레이어에게 붙였음을 도엘이 확인하는 입력(봉합실의 같은 매듭, 젖는 구두, 또는 발 다툼 중 확인).

“그 발이 너한테 갔구나.”

(플레이어 오른발을 다시 본다. 다툼의 상대가 소하가 아니라 플레이어임을 안다.) 이후 발 반환 요구는 플레이어에게만 향한다. 소하에게 발을 내놓으라 하지 않는다. 소하의 반환·사과 장면으로 대체하지 않는다.

### 6.6 출항 P1 → departed — DO-BOARD·DO-SEAT-DENY

(바닷문 밖 배. 발 상태가 확정된 뒤. 배는 한 사람이 앉으면 차는 크기다.)

“고치면 나가.”

선택: `같이 가자` / `자리는` / `너 혼자 가` / `안 보낸다`.

- 같이 가자: “자리 하나야.” (처음으로 밝힌다. 노를 자기 쪽으로 당긴다.)
- 자리는: “여기 하나. 다른 몫 없어.”
- 너 혼자 가: “……그래.” (발 유지 상태면 “발은 신고 가.”)
- 안 보낸다: “막을 거야?” (배를 밀지 않고 기다린다. 강제 출항 없음.)

함께 타려 하면(DO-SEAT-DENY): “가라앉아.” (자리 다툼의 물리 결과는 R1/결말 담당이 확정 — §11-4. 전투로 만들지 않는다.)

발을 잃은 채 배로 가면: “한 짝은 두고.” (의족으로 배에 오른다. 젖은 자국이 바닷문 쪽으로 남는다.)
발을 되찾아 출항하면: (돌아보지 않는다. 발끝이 바다 쪽으로 꺾인 채. World 결말 A 장면과 연결.)

### 6.7 익사 P2 — DO-DROWN

끈 해제 전 발 분리를 실행하면:

“끈부터랬잖—”

(말이 끝나기 전에 정강이가 경련하고 의족이 추 걸쇠를 찬다. 추가 내려가 상체가 물속으로 넘어간다. 두드림이 물 밑에서 한 번, 그다음 없다.)

도덕 판결창 없음. 이후 5호 재방문 시 물 위에 뜬 의족만. 발화 없음. 살아 있는 초상/두드림 재생 금지.

### 6.8 사망 후·굶주림 P3 — DO-STARVE

여관 굶주림 말기에 5호를 열지 않거나 운반이 없어 한 식사 시각 더 지나면, 5호 귀환자 셋과 함께 도엘이 그 자리에서 죽는다(지도 §3.1). 두드림이 약해지다 멈춘다. 발화 없음.

5호가 열린 상태로 말기를 지나면 셋은 복도로 나오고(K01), 도엘 시신은 구덩이에 남는다. 시간 경과만으로 시신이 사라지지 않는다.

### 6.9 재방문·상태별

- 구조 후 재방문(alive, 아직 해안): “아직 여기야.” (배를 손보는 중이면 밧줄을 감는다.)
- 출항 후(departed): H0에 없음. 안전점에 젖은 의족 자국 또는 곧은 발자국만(발 상태에 따라). 살아 있는 초상 재생 없음.
- 익사/굶주림 후(dead): 5호에 의족 또는 시신. 발화 없음.
반복 말걸기는 새 사실 없으면 한 번만. 추모 메뉴를 만들지 않는다.

## 8. 직업과 비밀을 지워도 남는 개인 장면 둘 (지도 §5-8)

뱃사람이라는 직업과 “배에 한 자리뿐”이라는 비밀을 지워도 남는 도엘만의 장면 둘. 하나 이상은 관계 단계나 사건 조건을 실제로 바꾼다. 무작위 기벽으로 채우지 않는다.

**DO-D07 마른 자리 찾기** (관계·조건을 바꾸지 않는 개인 장면)

도엘은 앉을 때 반드시 바닥이 마른 쪽을 손등으로 먼저 쓸어 본다. 젖은 자리에는 남이 권해도 앉지 않고, 마른 자리가 없으면 선 채로 있는다. 구조 직후 안전점에서도 물때가 마르지 않은 나무판 위에는 의족을 올리지 않고 옆으로 뺀다.

“여기 말고.” (마른 쪽으로 반걸음.) / 마른 자리가 없으면: “서 있을게.”

이 장면은 관계 단계나 생존을 바꾸지 않는다. 물을 무서워하는 이유(구덩이 익사 직전)를 해설하지 않는다.

**DO-D08 밧줄 다시 감기** (관계·조건을 실제로 바꾸는 개인 장면)

도엘은 대화 중에도 허리의 밧줄 타래를 풀었다 다시 감는다. 감는 방향이 늘 같고, 남이 반대로 감아 주면 다시 푼다. 플레이어가 도엘의 밧줄을 한 번이라도 대신 감아 주면(같은 방향으로), 도엘은 그것을 받아들이고 이후 배 매는 매듭을 플레이어에게 맡긴다.

선택: `같은 방향으로 감아 준다` / `반대로 감는다` / `둔다`.

- 같은 방향으로 감아 준다: “……맞게 감네.” (P1 유지, 이후 DO-BOARD에서 배를 먼저 묶게 함 = 출항 준비 한 단계 단축.)
- 반대로 감는다: “아니.” (다시 푼다. 관계 변화 없음.)
- 둔다: 스스로 감는다.

이 장면은 **관계나 사건을 실제로 움직인다**(지도 §5-8 요구): 밧줄을 같은 방향으로 감아 준 플레이어는 출항 준비를 한 단계 빨리 마쳐, 굶주림·관문 시각에 쫓기는 플레이에서 배 확보 여유가 달라진다. 밧줄이 폐/발의 비밀을 푸는 열쇠가 되지는 않는다.

이 두 장면은 선물 반복으로 해금되지 않는다. 물에서 나온 몸의 상태(젖은 머리·미끄러운 의족)는 개인 장면에서 깨끗해지지 않는다. explicit sexual content 없음. 로맨스·신체 공포는 허용되나 이 두 장면은 어느 쪽도 강제하지 않는다.


## 9. 반복 서비스가 도엘을 소모시키는가 (지도 §5-9)

도엘은 플레이어에게 반복 서비스를 제공하는 인물이 아니다(항해·수리는 자기 탈출을 위한 것이고 상점 기능이 아니다). 따라서 “도움을 반복해서 받아 그 인물이 소모되는” 구조는 **없음**이다.

단, 도엘 쪽으로 향하는 반복 입력 하나는 그를 소모시킨다: **5호 문밖 두드림에 응답하지 않고 지나가는 것**. 이것은 서비스가 아니라 방치다.
- 몇 번째: 굶주림 단계가 `문틈 손 → 말기`로 오른 뒤, 말기에서 식사 시각이 한 번 더 지나면 도엘이 죽는다(지도 §3.1). 별도 횟수 카운터를 도엘 파일에서 만들지 않는다.
- 어떤 공통 순서에서: 여관 밖 관문(G1–G8)·보스 조우(K13–K25) 결과가 확정될 때마다 식사 시각이 한 번 지난다. 도엘의 죽음은 그 공통 시각에 걸린다.
- 화면 밖에서 일어나는가: 그렇다. 플레이어가 H0 밖에 있을 때 식사 시각이 지나 도엘이 죽을 수 있다(지도 §3.1 결과 3과 같은 화면 밖 진행). 재방문 시 두드림이 멈춰 있는 것으로 결과를 안다.

## 10. 이미지·레이어·소리 납품 명세 (지도 §5-1 외형 자산)

현재는 자산 목록이며 생성 요청/완료 자산이 아니다. 이미지 생성은 하지 않는다. 생성 입력은 최신 A 원본 또는 A 캐릭터 배경 분리본만(AGENTS 2026-09-26). B 원본·크롭 사용 금지. A의 인물 정체성·의상·모티프·정확한 팔레트는 복제하지 않는다. 04는 코드 그림(아이콘 조합·도트·SVG/Pillow)도 최종 그림으로 허용한다. 인물은 어떤 배경 base에도 굽지 않는다. 지면 하향 60도 시점.

소리: 의족 유리 살이 스치는 마른 방울 소리(걸음), 물 밑에서 뭉개진 두드림(발견 전), 끈이 걸쇠에서 풀리며 나는 금속 긁힘, 추가 내려가는 무거운 물소리(익사). 도엘 목소리는 마르고 잠긴 저음, 문장 끝을 빨리 닫는다. 음성 합성·작곡 미착수. 기획만으로 음성이 만들어졌다고 집계하지 않는다.

### 10.1 역겨움 장면별 접촉 방식 (지도 §4-11 준용)

도엘 쪽 불쾌함이 한 방식에 몰렸는지 스스로 보인다. 비율을 맞추라는 뜻은 아니다.

| 장면 | 접촉 방식 |
|---|---|
| 물 밑 두드림·뭉개진 목소리 | 보기·듣기 |
| 구조 직후 젖은 머리·미끄러운 의족 | 보기 |
| 같은 균열의 통증(발 분리 시 경련) | 만지기(플레이어 자기 발 조작) |
| 의족 안 유리·발목 칼날 | 보기·만지기 |
| 익사(추가 상체를 물속으로) | 보기 |

도엘 쪽은 먹기 장면이 없다(World 검수에서 지적한 “먹기 편중”에 기여하지 않음). 접촉이 보기·듣기·만지기에 있고, 물이라는 매질에 몰려 있다.

## 11. 연결 요청·플레이 과제·미작성

### 11.1 플레이 과제 원고 (지도 §5, 수동 과제)

1. 발견: 5호 문 앞에서 물 밑 두드림·문밑 끈을 확인한다. 문밖 당기기만으로는 해제가 아님을 확인한다.
2. 끈 먼저 구조: 5호를 열고 C3에서 끈을 먼저 푼다. 도엘 `alive`. 수건이 있으면 닦는 반응, 없으면 소매. 구조 직후 위치와 첫 말을 확인한다.
3. 발 다툼: 구조 후 발 소유 요구를 받는다. 반환 거절(발 유지)과 반환(발 절단·지팡이 이동)을 각각 확인한다. 무연 생존/사망에 따라 처치 안내가 달라진다.
4. 실패 분기: 같은 시작에서 끈 해제 전 발 분리를 실행한다. 같은 균열 통증→의족이 추를 참→익사, 두드림 중단을 확인한다. 살펴보기·취소만으로는 죽지 않아야 한다.
5. 소하의 거짓말·발 행방: “빈 방이야”가 자기를 5호로 보낸 말이었음을 아는 입력과, 맡긴 발이 플레이어에게 갔음을 아는 입력에서 도엘의 행동 변화를 확인한다. 동기 해설이 없어야 한다.
6. 출항: 발 상태 확정 후 배에 오른다. 자리 하나뿐임이 이 시점에 드러난다. 함께 타려는 선택의 결과(가라앉음/한 사람만)를 확인한다. 발 되찾음(결말 A)과 발 잃은 채 감(결말 B의 다른 출항)을 구분한다.
7. 방치: 여관 밖에서 관문/보스 결과가 지나 굶주림 말기가 한 번 더 지날 때 도엘이 화면 밖에서 죽는지, 재방문 시 두드림 멈춤으로 확인한다.

### 11.2 완료 경계

작성됨: 도엘의 외형·의족 구조·같은 균열 통증, 욕구/지식 경계, 배치 앵커 요청, 관계 4상태, 행동표(끈/발/거짓말/출항/익사/굶주림), 전 장면 실제 대사, 전형성 검토, 개인 장면 둘, 반복-소모 판정, 이미지/소리 자산 목록, 접촉 방식 표.

미작성: 정식 `rel_*`/대화 stable ID와 06 스키마 바인딩, 자리 다툼(DO-SEAT-DENY)의 물리 결과 수치, 결말 A/B 접근의 정확한 상태 조합(World §11 소유), 실제 collider·이동 검증, 이미지 brief 승인·생성·음향 제작·콘텐츠 JSON. 이 문서 하나로 인물 구현 명세 완성이나 이미지 생성 준비 완료로 보지 않는다.

### 11.3 연결 요청 (H0·N01·R1 담당과 사용자에게)

이 파일은 소유 경로 밖을 고치지 않는다. 아래는 다른 담당 파일에 필요한 변경이며, 확정은 통합 담당/사용자 몫이다.

- **H0-1 (H0 담당)**: H0 §5 N12 행의 발견 앵커(1600,220)·구조 후 안전점(990,370)·끈/추 상호작용점(C2 1550,397 / C3 1600,230 / C4 1710,180)을 이 파일 §3·§5의 도엘 행동과 최종 대조. 도엘 본체와 끈·문·추가 같은 반경에 겹치지 않게 확정.
- **H0-2 (H0 담당)**: DO-STARVE(굶주림 사망)를 H0 §3 시체 규칙·§6.1과 맞춤. 5호 열린 상태 말기 통과 시 셋은 복도(K01), 도엘 시신은 구덩이 잔류로 재방문 차분에 넣기.
- **N01-1 (N01 담당)**: SH-DOEL 수건 요청과 이 파일 DO-TOWEL 연결 확정. 소하 §6.4의 도엘 사망/구조 반응은 소하 소유이며 이 파일과 중복 발화하지 않음(현재 맞춤됨).
- **입력점 (H0/N01 담당)**: DO-LIE-SEEN·DO-FOOT-FOUND의 실제 게임 입력점(플레이어가 소하의 “빈 방이야”를 도엘 앞에서 전하는지, 5호 안에서 소하 목소리를 다시 듣는지, 봉합실 매듭 제시인지)을 정해야 한다. 후보만 적었고 확정은 통합 담당.
- **R1-1 (R1 담당)**: 결말 A/B의 배(바닷문 밖)·자리 하나뿐(DO-SEAT-DENY)·함께 타면 가라앉음의 물리 결과를 R1 바닷문 G1·E01·E07·플레이어 원래 발(D12)과 맞춰 확정. 도엘이 발을 잃은 채 떠나는 “다른 출항”(World 결말 B)이 R1 배 수리와 어떻게 이어지는지 R1 소유.
- **root**: 관계 4상태의 06 바인딩, DO-SEAT-DENY 수치, 결말 A/B 상태 조합.

### 11.4 사용자 결정이 필요한 항목 (대화 본문에 번호로 물음)

아래 두 가지는 판단이 갈릴 수 있어 사용자 결정을 요청한다. 본문에서 번호로 묻는다.

1. **발을 잃은 채 도엘이 떠나는 “다른 출항”(World 결말 B)에서, 플레이어와 도엘이 한 배에 함께 타려 하면 결과를 어떻게 할지** — (가) 배가 가라앉아 둘 다 못 감, (나) 한 사람만 남고 다른 하나가 물에 빠짐, (다) 애초에 함께 타는 선택을 막음. 나는 (다)를 기본값으로 두되 R1 담당과 맞추자고 제안한다.
2. **DO-LIE-SEEN/DO-FOOT-FOUND의 입력점** — 소하의 거짓말과 발 행방을 도엘이 아는 계기를 (가) 플레이어가 소하의 말을 도엘 앞에서 전할 때, (나) 봉합실의 같은 매듭을 도엘에게 보일 때, (다) 둘 다 중 어느 것으로 할지. 나는 (다) 둘 다 허용을 제안한다.
