# N01 소하 — 만조 여관 인물 상세 v0.2

상태: 독립 집필 초안, 사용자 내용 검토 전. 작성자는 이 파일만 소유한다. [World](../../15_NEW_WORLD.md)와 [지도·교차 사건](../00_MAP_AND_AUTHORING.md)의 C0/C1/C2, 도엘 감금, 플레이어 발 이식 인과를 유지한다. 좌표·공통 시계·다른 인물의 말과 생사 판정은 해당 담당이 소유한다. 아래 `SH-*`는 제작 별칭이며 기존 NPC/저장 ID를 덮어쓰지 않는다. JSON·이미지·실행물은 납품하지 않았다.

v0.2 입력: [상세 인덱스](../01_CONTENT_INDEX.md)의 통합 검수 N01-1~9, [지도 §3.1](../00_MAP_AND_AUTHORING.md)(C0 원자 경계·식사 시각·열쇠 고리·5호 무잠금·소하 공격 결과 1–3), [지도 §3.2](../00_MAP_AND_AUTHORING.md)(관계 전이 해석), [지도 §5](../00_MAP_AND_AUTHORING.md)(인물 담당 납품 8·9항), [World §12 D01·D02·D10](../../15_NEW_WORLD.md), [World §17 D01](../../15_NEW_WORLD.md). D01의 제작 원인은 World §12가 정본이며, 그 사실을 대사로 설명하지 않는다(never_explains 유지). H0는 아직 v0.1이라 식당 위험 앵커 좌표(H0-6)가 미확정이므로 SH-LURE 좌표는 연결 요청으로 남긴다.

## 1. 인물의 몸과 생활

소하는 성인 여성, 외견 40대 초반. 전체 비율은 약 6.5등신, 넓은 골반보다 앞으로 굽은 어깨와 굵은 팔뚝이 먼저 읽힌다. 얼굴은 볼살이 아래로 내려오고 턱끝은 짧다. 눈 사이가 조금 넓고 윗눈꺼풀은 무겁다. 오른쪽 콧방울에서 볼 안쪽까지 작은 화상 자국이 있다. 머리는 검갈색, 귀 아래 길이의 머리칼을 뒤통수 낮게 틀어 꽂았으나 왼쪽 귀 앞만 젖어 붙는다. 피부는 갈색 바탕에 콧등과 손등의 붉은 면; 창백한 인형 피부로 만들지 않는다.

단추 네 개의 목 닫힌 작업 원피스, 허리선 아래 넓은 주름 두 개, 정강이 중간 길이. 물이 드는 아래 옷단만 더 짙다. 앞치마는 가슴까지 덮으며 오른쪽 옆에 접시 받치는 두꺼운 천을 꿰매 두었다. 왼쪽 소매 끝은 씹혀 둥글게 비었고, 말문이 막히면 그 부분을 입술 안에 넣는다. 꽃무늬는 여관 벽지에만 남기고 옷에도 반복하지 않는다. 두꺼운 천 실내화는 서로 다른 회색이다. 열쇠는 허리에 전시하지 않고 앞치마 안주머니에 넣는다. 손등의 오래된 화상, 물에 불은 손가락, 검지 끝 손톱 밑에 끼는 기름이 근접 그림의 식별점이다.

서 있을 때 오른팔로 빈 접시를 몸에 끼운다. 남에게 접시를 건넬 때는 바닥을 손으로 쓸어 찌꺼기를 떼고, 그 손으로 상대의 손목을 돌려 접시를 올린다. 식당에 사람이 있어도 빈 복도 쪽으로 먼저 밥을 가져간다. 친절한 미소·낮고 다정한 목소리를 기본 포즈로 사용하지 않는다. 목소리는 마르고 조금 잠기며 문장 끝을 빨리 닫는다. 불쾌한 질문을 받으면 목소리를 낮추는 대신 하는 일을 크게 한다. 접시를 겹치거나 물을 틀어 대답을 끊는다.

먹기: 손님 상을 치운 뒤 자기 몫을 같은 접시에 넣는다. 남은 밥을 비밀 독극물로 만들지 않는다. 식사 중 손님이 오면 숟가락은 입 안에 둔 채 눈으로 앉을 곳을 가리킨다. 자기 그릇은 남에게 못 씻게 한다. 잠: 주인 침실 대신 식당 쪽 세탁실 문턱 옆 칸막이 뒤 접이 의자에서 잔다(H0-14와 같은 위치). 누구를 영원히 기다리는 낭만적 자세가 아니라 젖은 손을 겨드랑이에 넣고 코를 골다가 그릇 소리에 일어난다. 기호: 국물에 젖지 않은 눌은 밥 가장자리, 너무 무거운 담요. 혐오: 접시 아래에 젖은 수건을 깔아 놓는 것, 자는 척하며 밥을 남기는 것. 이 기호를 전부 숨겨진 역사 단서로 승격하지 않는다.

## 2. 욕구·능력·지식의 경계

| 필드 | 내용 |
|---|---|
| public_role | 여관 주인. 잠자리, 남은 식사, 객실 열쇠를 다룬다. 안내소·퀘스트 접수원이 아니다. |
| private_role | 같은 기억을 지닌 여러 귀환자를 숨기고 먹인다. 도엘을 풀어주고 싶지만 귀환자들이 자기를 버릴까 두려워 문을 열지 못한다(World §2.3 '전날'). |
| desire / fear | 돌아온 사람이 다시 이 집에 머물기를 원한다 / 아무도 식사를 요구하지 않는 저녁을 두려워한다. |
| contradiction | 손님을 붙잡으면서도, 실제로 손님이 방에서 나오면 식당을 차지했다고 짜증 낸다. 필요한 존재이고 싶지만 남이 자기 일을 바꾸는 것은 못 견딘다. |
| capability / ports | 침상 안내, 보유 식사 제공, 객실 잠금 해제, 젖은 옷 보관. 급식은 복도 급식자리까지만 나르고 문틈에는 넣지 못한다(한 달 전 5호에 손목을 잡힌 뒤 문 앞 팔 길이 안에 들어가지 못함, World §12 D01). 발 이식을 한 적이 있으나 반복 치료/수술 상점이 아니다. |
| resource_access | 실제 남은 식량, 접시, 수건, 앞치마 안주머니의 객실 열쇠 고리(1–4호만 연다). 분실된 열쇠나 이미 소비한 식량을 대화로 재생성하지 않는다. |
| knows | 자신이 플레이어에게 도엘의 발을 붙였음(오른발, 발목 아래, 두 사람 머리카락을 한 가닥씩 꼬아 꿰맴), 그 이유가 문틈에 접시를 넣을 손이 필요해서였음, 그 발이 집에 있던 유일한 성한 발이었음, 도엘에게는 알리지 않았음. 전날 발을 찾으러 온 도엘에게 늘 하던 대로 “빈 방이야”라고 했고 도엘이 5호를 열었음, 도엘이 어느 객실에 붙잡혔는지, 5호는 한 달 전부터 잠기지 않음, 방별 식사 순서, 귀환자의 여러 몸, 현재 보관한 식량. |
| does_not_know | 학교 접기의 기원, 왕관의 성질, 플레이어 과거, 도엘 의족 안 줄의 정확한 기계 구조, 배수 추 걸쇠의 작동, 마로가 숨긴 모든 재료 출처. |
| never_explains | 이식을 해야 했던 이유 전체(D01: 손을 잃은 채 접시 넣을 손이 필요했다는 사정을 말로 풀지 않음), 전날 “빈 방이야”가 도엘을 5호로 보낸 일(D02), 반복 귀환의 완전한 기원, 각 지역을 하나로 묶는 세계 원리. 다른 NPC가 대신 정답을 말하게 하지 않는다. |
| speech_pressure | 방 문이 흔들릴 때 명사 대신 짧은 동사만 남는다. '놔.' '뒤로.' 질문이 반복되면 같은 답을 길게 풀지 않고 작업을 계속한다. |
| silence_lie_pattern | '빈 방이야'는 사람 없다는 거짓말. '안 열려'는 자기 손으로 열기 싫다는 회피. 증거를 보이면 처음 말을 재해석하는 긴 변명 대신 열쇠를 꺼내거나 문을 등진다. |
| faction_links | 여관 생활집단, 공동부엌과 식사 공급 관계. 옛 세계의 기관 token을 새 고유 조직 이름으로 복제하지 않는다. |
| clock_links | resource_collapse_clock: 실제 배급 소비; personal_collapse_clock: 귀환자 굶주림·소하 부상 입력. 대화 반복/실시간 대기만으로 증가하지 않는다. 공통 수치 배정은 통합 담당 소유. |
| cross_links | N02 무연/C1 봉합, N03 오트/C2 식사, N07 테사/운반, N12 도엘/C0, N13 마로/공급. |

seed 계획 연결: core S008/S011/S015/S033/S036/S085를 C0의 실제 행동으로 구체화한다. magic 별도 배정 없음. 원장의 ONEOFF 분류를 확인하지 않은 기호 대사를 seed 사용 수로 더하지 않는다. 기존 World에 배정된 seed의 상세화이며 추가 사용 실적으로 중복 집계하지 않는다.

## 3. 외형 상태와 배치 요청

| 상태 | 배치 요청 / 행동 | 외형·소품 차분 |
|---|---|---|
| 첫 도착 | 세탁실, 플레이어 침상과 통로를 막지 않는 물통 옆 | 오른팔 빈 접시, 왼손 젖은 붕대. 플레이어가 일어나면 붕대만 바닥에 놓음 |
| 평상 | 식당 설거지대; 배급 사건에만 복도 급식자리 왕복(문틈까지는 가지 않음) | 접시 들기/내려놓기 분리. 배경과 손에 동시에 접시 금지 |
| 도엘 구조 진행 | 복도 바깥 끝, 구조 구멍·문·끈의 상호작용 반경 밖 | 수건 한 장을 끝까지 쥐고 있음. 줄을 대신 푸는 자동 해결 없음 |
| 귀환자 노출 | 식당 안쪽에서 식탁을 당겨 사람들과 거리를 둠 | 빈 접시를 내려놓지 못함. '놀란 표정'만으로 완료하지 않음 |
| 공격 직전 | H0 담당이 지정할 식당 위험 앵커(H0-6 미확정, 연결 요청 §10) | 소매를 무는 귀환자와 팔을 빼는 소하를 분리. 접시 낙하 |
| 부상 생존 | 마당 퇴로 또는 식당 의자 | 왼팔 찢긴 소매, 상처 감싼 작업천. 한 손 서비스 연출 |
| 자발적 외출 | C0 해결 뒤 플레이어와 마당까지만 이동 | 앞치마는 벗지 않음. 전투 파티 영입으로 해석하지 않음 |
| 사망 | 공격 결과가 확정된 식당 위치 | 뜯긴 소매와 시체, 떨어진 열쇠. 살아 있는 초상/대사 숨김 |

이 배치는 상대 앵커 요구다. H0 담당의 실제 bounds·통행폭·깊이·위험 경계와 충돌하면 이 표를 통합 수정한다. 소하가 죽어도 침상과 H0 외부 다섯 통로는 사라지지 않는다. 소하를 벽 뒤에 굽거나 시체를 자동 음식 아이콘으로 변환하지 않는다.

## 4. 상태 판정과 우선순위

생존은 `alive / wounded / dead / absent` 제작 별칭으로 구분한다. 관계와 독립이다. 대사 우선순위: 사망 → 진행 중 공격 → 도엘 사망 직후 → 부상 → 도엘 구조 직후 → 최초 만남 → 개인 장면 → 평상 재방문. 상태 선택은 한번 진입 시점의 사실을 읽고, 대화 종료 직전 대상 생존을 다시 확인한다. 같은 사건 결과를 대화 재개로 중복 적용하지 않는다.

관계는 다음 8개 이산 상태로 초안 작성한다. 정식 `rel_*`/`rs_*` 부여 및 06 바인딩은 미납품이다. 이것을 기존 옛 인물 상태 이름으로 임의 등록하지 않는다.

| 별칭 | 진입 행동 | 유지되는 실제 변화 / 다음 갈래 |
|---|---|---|
| Q0 낯선 손님 | 첫 대면 | 개인 물건 접근 거부. 침상은 이용 가능 |
| Q1 일을 맡김 | 첫 배급 운반을 실제 완료 | 보유 일반 객실 열쇠를 맡김. 강제 호감 아님 |
| Q2 함께 남음 | 배급 후 다른 손님 접시까지 씻고 자기 방으로 돌아옴 | 소하가 이후 옆자리에서 자기 식사. 정해진 일회 장면 하나 |
| Q3 사적 가까움 | Q2 이후 마당 동행 제안을 양쪽이 수락 | 성인 간 비성적 애정 장면 허용. 도엘 관련 비밀/거짓말 유지 |
| Q4 갈라짐 | 사적 물건을 가져감, 도엘 생사를 거짓 보고하고 실물이 드러남 | 식사 전달 거부, 침상 유지. 보관물 반환+직접 돌려놓기 후 Q1 가능 |
| Q5 거절을 받아들임 | Q2/Q3에서 개인 접촉을 거절 | Q2와 같은 서비스 유지. 반복 구애 선택 숨김; 화해 선물로 자동 복구 안 함 |
| Q6 함께 살림 | 결말 E 조건 충족 후 객실 인수를 선택 | 개인 여행 종료의 실제 식사 행동. 소하 생존 여부는 별도 분기 |
| Q7 적대 | 소하 직접 공격 확정 | 개인 서비스 종료. 다시 말걸어 초기화하지 않음 |

Q4→Q1은 물건 반환이라는 새 행동이 필요한 가역 전이다([지도 §3.2](../00_MAP_AND_AUTHORING.md): `is_irreversible: false`는 서로 되돌아가는 쌍을 가질 수 있고, 되돌아가려면 새 행동이 필요하다). Q7 적대는 `is_irreversible: true`이며 Q7에서 다른 관계 상태로 돌아가는 edge를 두지 않는다(다시 말 걸어 초기화하지 않음). 비가역 전이만 모은 그래프에는 순환이 없다. 사망은 관계 상태가 아니고 전역 생존 입력이 모든 생전 전이를 막는다. 04의 DAG/불가역 역방향 의무 간 모순은 지도 §3.2가 상위 해석이며 이 파일은 그것을 따른다. Q6(함께 살림)과 Q7(적대)이 둘 다 끝 상태이므로, 06 바인딩 때 `exclusions.max_final_state`를 확인해 값이 1이면 하나를 끝 상태에서 뺀다(연결 요청 §10). 보조 trust/fear/debt/recognition/attachment와 agency는 연출 해석만 가지며 호감 수치 임계로 생존/연애/열쇠를 자동 해제하지 않는다.

## 5. 행동표

모든 선택은 hover/focus로 결과를 적용하지 않는다. 취소는 원래 대상 focus로 복귀하고 자원·시계·관계를 소비하지 않는다. 없는 물건은 비활성 상태로 남긴다. 아래 반복 가능 행동도 매번 실제 자원·장소·생존을 검사한다.

| 행동 별칭 | 선행 / 입력 | 즉시 결과 | 지연 / 실패·거절 |
|---|---|---|---|
| SH-REST | 침상 접근 / 눕기 | 기존 회복 계약에 따라 침상 사용 | 소하 부재·적대여도 침상 유지. 소하 죽음을 복구로 되돌리지 않음 |
| SH-MEAL | 소하 생존+실제 식사 있음 / 식사 받기 | 보유량에서 한 몫 소비, 접시 위치 이동 | 다음 C0 배급이 같은 몫을 다시 소비하지 않음. 없음: 빈 솥을 기울임 |
| SH-CARRY | 운반할 두 접시 있음 / 두 접시 들기 | 운반 물건 소유 이전 | 올바른 급식자리에서 놓을 때만 C0 배급; 소하와 대화만 해서는 완료 안 됨. 소하가 문 앞 팔 길이 안에 못 들어가 문틈 운반이 플레이어에게 넘어오는 것이 이 행동의 이유(§2 capability) |
| SH-REFUSE | 운반 제안 중 / 거절 | 접시 원위치, 거절 대사 | 즉시 굶주림 사망 금지. 다음 식사 시각까지의 미운반이 [지도 §3.1](../00_MAP_AND_AUTHORING.md) 굶주림 한 단계 상승의 입력이 됨 |
| SH-WASH | 배급 완료+씻을 접시 / 다른 접시도 씻기 | 얼룩 접시를 실제 깨끗한 접시로 바꿈 | 첫 성립 시 Q2. 반복하여 호감 농사 없음 |
| SH-KEY | 앞치마 안주머니의 열쇠 고리+Q1 이상 또는 도엘 끈 제시 / 열쇠 받기 | 소하 앞치마 안주머니→플레이어. 이 고리는 1–4호만 연다([지도 §3.1](../00_MAP_AND_AUTHORING.md)) | 문을 여는 행동은 별도. 5호는 한 달 전부터 잠기지 않아 열쇠가 필요 없다(도엘 구조는 관계 단계에 잠기지 않음). 이미 없는 열쇠: 빈 주머니를 뒤집음 |
| SH-EXPOSE | 문 안 사람 목격 / 소하에게 보이기 | '빈 방' 대사 종료, 1–4호 열쇠 접근 | 귀환자를 자동 해산·살해하지 않음. 듣고 취소해도 목격은 사라지지 않음 |
| SH-DOEL | 구조 시작 입력 수신 / 수건 요청 | 소하 수건을 마당/복도에 놓음 | 도엘 생사는 N12 사건 소유. 소하가 줄 조작 순서를 보증하지 않음 |
| SH-FOOT | 이식 흔적 제시 / 발을 보여줌 | 붕대 걷기 연출, N02 장소를 손짓으로 가리킴 | 소하에게 반복 이식/절단 기능 열리지 않음 |
| SH-LURE | H0에서 안전한 급식 유인점이 승인됨(H0-6 좌표, 식당 밖)+식사 있음 / 그곳에 식사 놓기 | 귀환자 대상 위치 변경 요청 | [지도 §3.1](../00_MAP_AND_AUTHORING.md) 결과 2: 소하 `alive`, 귀환자가 유인점으로 가고 굶주림 한 단계 하강, 공격 진행 해제. H0-6 좌표 미승인 상태에서는 제작 연결 요청(§10)으로 남김 |

| SH-TOUCH | Q2/Q3+개인 장면 / 손 내밀기 | 소하 수락 시 젖은 손을 얹음 | 거절 시 접촉 없음, 관계 처벌 없음. 접촉 중에도 방 씹는 소리 지속 |
| SH-LIE | 도엘 상태 미확인 / '떠났어' | 소하는 빈 구두를 세탁실에 놓음 | 나중 시체/도엘 귀환 확인 시 Q4. 대사만으로 도엘 이동 처리 금지 |
| SH-RETURN | Q4+가져간 물건 보유 / 돌려놓기 | 실제 물건 반환 | 대화 사과만으론 반환 안 됨. 해당 물건 이미 소모: Q4 유지 |
| SH-STRIKE | 소하 생존 / 공격 선택 extreme | 기존 전투 전환 요청 | encounter 구체 수치 미납품. 확정 전 cancel 무효과; 결과 생존/사망에 따라 Q7/시체 |
| SH-INHERIT | C0 결과 확정+결말 E 접근 / 객실 맡기 | 인수 장면 시작 | '소하와 연애'를 선행으로 요구하지 않음. 사망 시 빈 여관 변형 |

소하는 독립 보스 변신을 하지 않는다. 직접 공격의 비전투 결과나 encounter 수치는 기존 전투 담당의 자료와 바인딩하기 전 확정하지 않는다. 소하 구조를 위해 K12와 싸우는 것과 소하를 공격하는 것을 같은 전투 ID로 처리하지 않는다.

## 6. 대화 작성·표현 계약

각 인용은 실제 발화 한 페이지다. `/`는 다음 페이지이며 한 페이지 최대 3줄. 모든 아래 대사는 한 줄 또는 명시된 2줄이다. 괄호 안 행동은 제작 지시이고 게임 자막으로 낭독하지 않는다. 선택은 아래 순서로 최대 6개, 이전 페이지의 복귀 focus가 없으면 첫 행. 위험한 모든 선택을 빨갛게 칠하지 않는다. `extreme`는 아래 공격/강제행위에만 지정한다. 비활성 행도 focus 가능하며 확정해도 결과 없음. 문서는 최대 9줄이지만 새 설명 문서를 추가하지 않는다.

### 6.1 첫 대면 SH-D01

(침상에서 일어남. 소하는 붕대를 물통 가장자리에 건다.)

“일어났네.”

선택: `내 발` / `여긴 어디야` / `물` / `나간다`.

- 내 발: “바꿔 달았어.” / 추가 `누구 발이야`: “구두는 밑에.” (침대 아래를 발로 밀어 구두를 드러냄. 주인 질문에 답하지 않았다는 사실이 남음.)
- 여긴 어디야: “여관.” / 추가 `이름은`: “문 밖에.” (간판을 읽지 못해도 길 진행 가능. 간판 복원 퀘스트 없음.)
- 물: “그 통 말고.” (빨랫물 통을 자기 쪽으로 당기고 마실 컵을 놓음. 컵 받기만 물건 이전.)
- 나간다: “구두 신고.” (이동을 잠그지 않음. 맨발로 나가면 “아, 바닥.” 한 번만.)

발을 다시 질문하면: “만지지 마. 아직 젖었어.” 치료 이유를 늘어놓는 선택지 가지는 없다.

### 6.2 배급 SH-D02

(식당. 한 접시에 다른 접시가 얹혀 있어 처음엔 한 몫처럼 보인다. 들면 두 장이 분리됨.)

“두 개 놓고 와.”

선택: `어디에` / `접시를 든다` / `내가 먹는다` / `안 해`.

- 어디에: “복도 끝. 바닥에.”
- 접시를 든다: “기울이지 말고.”
- 내가 먹는다: “네 건 저기.” 실제 플레이어 몫이 있으면 가리킨다. 없으면 “아까 먹었잖아.”를 쓰지 않고 “남은 건 없어.”
- 안 해: “그럼 거기 놔.” 접시를 던지거나 플레이어를 악인이라 부르지 않음.

한 장만 운반: “밑에 하나 더.”
빈 접시 회수: “안쪽 보지 말고.”
회수 접시에 치아가 붙어 있음: “뒤집어 줘.” (직접 손톱으로 떼어 자기 앞치마 안주머니에 넣음. 치아 주인을 해설하지 않음.)
음식을 바닥에 쏟음: “접시는?”
깨진 접시 조각 반환: “큰 것부터.”
두 장 모두 놓고 돌아옴: “손 씻어.”
귀환자가 아직 먹는 중인데 회수함: “아직 잡고 있잖아.” 플레이어 운반 포즈에 문 안 손이 붙은 상태는 H0 물건 연출 요청.

### 6.3 거짓말이 드러나는 순간 SH-D03

처음 문을 묻기: “빈 방이야.”
문 너머 씹는 소리를 들은 뒤: “쥐.”
같은 사람 얼굴 둘을 실제 목격한 뒤: “문 닫아.”

선택: `열쇠를 달라` / `누가 안에 있어` / `문을 닫는다` / `자리를 떠난다`.

- 열쇠를 달라: (안주머니에서 꺼냄) “이건 안쪽 거야.” 이 고리는 1–4호만 연다(5호는 잠기지 않음). 열쇠 일치 여부는 [지도 §3.1](../00_MAP_AND_AUTHORING.md)·H0 담당 계약. 모든 문 만능열쇠로 만들지 않음.
- 누가 안에 있어: “손님.” / 재질문 “알아. 봤잖아.”
- 문을 닫는다: “손 빼고.” 관계 보상 자동 없음.
- 자리를 떠난다: “접시는 두고.”

문 안에도 같은 열쇠가 걸려 있을 때 보여주면: “또 가져갔네.” (자기 것을 회수하려다 안쪽을 보고 손을 뺌.) 이것을 복제 원리 설명으로 이어가지 않는다.

### 6.4 도엘 SH-D04

두드림 처음 제시: “들었어.”
문 밑 끈 보여줌: “당기지 마.” (소하는 결과 구조를 모르지만 도엘이 안쪽에서 버티는 것을 본 적 있음.)
도엘 이름을 확인해 말함: “목소리 나?”
구조용 수건 요청: “이걸 물려.” 도엘에게 실제 적용 여부/효과는 N12 담당이 결정. 대사를 들었다고 구조 진행값 증가 금지.
끈을 먼저 푼 결과 수신: “됐어?”
살아서 문을 나옴: “그 사람 방은 없어.” (자기 침상 옆 의자를 끌어 놓음.)
발을 먼저 떼다 죽음: “그쪽을 왜 당겼어.” / 한 번 뒤 “들어 줘. 머리 쪽.” 도덕 판결창 없음.
플레이어가 구조 전에 죽인 사실 확인: “만지지 마.” (수건을 플레이어 손에서 빼고 도엘 쪽에 둠.)
이미 죽은 뒤 처음 발견: “소리 났었는데.”
시체를 두고 돌아옴: “아직 거기야?”
시체를 옮긴 뒤: “수건도.”
도엘이 떠났다고 거짓 보고: “구두는 안 가져가고?”
거짓말 이후 도엘이 실제 돌아옴: “밖에 있다며.” (Q4로 가되 도엘 위치는 외부 사실을 읽음.)
거짓말 이후 시체를 직접 확인: “살아 있다고는 안 했지.” (변명 대신 플레이어가 한 말을 좁게 되풀이함. 이후 장문의 추궁 없음.)

도엘 자신의 마지막 말·행동·보복·출항 판단은 여기서 쓰지 않는다. 소하 애정 장면 진행 여부는 위 모든 사망 반응을 바꾸지 않는다.

### 6.5 발 SH-D05

봉합을 보여줌: “실 들지 마.”
발 주인을 도엘이라고 확인한 뒤: “응.”
왜 붙였는지 재차 물음: (소매를 입에 넣는다. 잠시 뒤) “물 식었어.”
통증 호소: “소금 묻은 사람. 염전.” (N02 생존을 모르면 살아 있다고 단정하지 않음.)
무연 사망을 확인한 뒤 치료 부탁: “내 손 봐.” (손을 펴면 미세하게 떨림. 수술 선택 unavailable.)
발을 반환하고 돌아옴: “한 짝이면 돼?” (실내화를 한 짝 내놓음.)
발을 유지하기로 한 뒤: “밑창 닳았네.”
도엘 사망 후 발이 계속 젖음: “닦아도 나와?”
발이 가려는 곳을 묻기: “내가 어떻게 알아.”

### 6.6 재방문·서비스 SH-D06

첫 외출 후: “문은 닫았어?”
젖은 옷: “벗어 놓고 가.” 의복 선택을 강제하거나 성적 장면으로 이어가지 않음. 겉옷 보관만.
겉옷 찾기: “아직 축축해.” 상태가 마르면 “의자.”
음식 없음: “긁어 줄까.” (빈 솥 바닥을 보여줌. 음식 획득을 가짜로 약속하지 않음.)
도엘 구조 후 재방문: “오늘은 조용해.” 해당 조용함이 실제 현장 소리와 맞을 때만.
귀환자 이주 후: “한 장만 가져가.”
귀환자 전원 사망 후: “그쪽은 안 닦아도 돼.”
소하 부상 후: “왼쪽에 놔.”
식량을 실제 가져옴: “젖은 건 따로.”
반복 말걸기: “왜.” 최초 한 번 이후 추가 페이지 없이 물 흐르는 행동 유지. 새로운 퀘스트 힌트 생성 없음.
사적 접근 거절 상태: “밥은 먹어.” 개인 접촉 거절과 생활 서비스 보복을 연결하지 않음.

### 6.7 사적인 장면 SH-D07~09

SH-D07: 다른 손님 접시까지 씻은 뒤 소하가 자기 그릇을 들고 옆에 앉는다.

“그건 놔. 내 거야.”

선택: `손을 뗀다` / `옆에 앉는다` / `돌아간다`.

- 손을 뗀다: “밑에 눌었어.” 자기 그릇 바닥을 긁어 먹음.
- 옆에 앉는다: “의자 젖었는데.” 플레이어가 계속 앉으면 소하가 자기 옷자락을 접어 둘 사이 바닥에 놓는다. 상태 Q2, 그릇을 나눠 먹는 연출은 자동 아님.
- 돌아간다: “불은 내가.” 불 끄는 실제 행동 뒤 다음 사건. 영원히 기다린다는 고백 없음.

SH-D08: Q2, 급박한 위험 없음. 마당 동행 한 번.

“여기까지?”

선택: `잠깐 앉는다` / `손을 내민다` / `먼저 들어가`.

- 잠깐 앉는다: “여긴 덜 젖어.” 자신이 앉던 돌의 좁은 쪽으로 몸을 옮김.
- 손을 내민다: 먼저 소하가 손을 뒤집어 손바닥 물을 바지에 닦음. “차가워.” 수락 사실이 확인된 경우만 손을 얹고 Q3. 관계 Q4/전투위험이면 “지금?” 후 접촉 취소.
- 먼저 들어가: “문 열어 둬.” Q5로 강제 전이하지 않고 단순 장면 종료.

SH-D09: Q3, 식당에서 어깨를 기대려는 짧은 개인 장면. 선택 `그대로 있는다` / `떨어진다`.

- 그대로 있는다: “잠깐만.” (소하가 눈을 감음. 복도 안 씹는 소리는 끊지 않음.)
- 떨어진다: “응.” (의자를 반 뼘 옮김. Q5, 서비스 손실 없음.)

이 세 장면은 선물 반복으로 해금되지 않는다. 몸의 역겨움이 친밀 장면에서 깨끗해지지 않는다. 플레이어의 성별을 지정하지 않으며 두 인물 모두 성인. explicit sexual content 없음. 관계 맺은 뒤 소하가 위험해지면 다음 절의 같은 조건을 적용한다.

### 6.8 적대·위기·죽음 SH-D10

소하 공격 선택 직전: “그거 내려.” `내린다` neutral / `공격한다` extreme. 전자가 기본 focus. 확정 전 결과 없음.
상처를 입히고 멈춘 뒤: “다가오지 마.” Q7. 칼을 든 채 대화하면 용서 장면 열리지 않음.
굶주림 말기, 전체 문 개방: “다 나왔네.” (접시를 내려놓으려는데 팔이 잡힘.)
위험 중 식사 유인이 실제 성공: “놔. 놓으라고.”
공격에서 살아남음: “소매 잘라.” (소매와 살이 함께 붙은 자리를 내보임. 치료 결과는 별도 행동.)
구조 실패 후 사망 직전: “손.” 한 페이지 뒤 더 말하지 않음. 실제 사망 결과가 확정되기 전 임의 임종 연출 금지.
플레이어가 떠나 사망한 뒤 재방문: 발화 없음. 살아 있는 초상을 띄우며 유언 재생 금지.

### 6.9 다른 핵심 인물 소식

다른 NPC의 생존/부재는 확인된 사실만 반응한다. 소하가 모든 죽음을 원격 감지하지 않는다. 물건 제시·직접 동행·목격 전달의 입력을 각각 둔다.

| 대상 / 확인 입력 | 소하의 실제 말 | 행동 / 범위 |
|---|---|---|
| 무연 / 도구 제시 | “그 사람 손에 있던 건데.” | 도구를 받지 않음. 죽음 확인 후 빈 치료 선택 제거 |
| 오트 / 다른 두 몸이 함께 방문 | “그 옷 벗겨. 밥 묻어.” | 외투 하나와 두 몸을 따로 보며 의자 두 개. 오트 전원의 의사를 대신 말하지 않음 |
| 벤 / 미끼 냄새 묻은 도구 | “그건 밖에.” | 마당 보관 지점 가리킴. 개를 자동 소환하지 않음 |
| 니르 / 실제 동행 | “먹을 땐 풀어.” | 귀의 천을 가리키지만 직접 풀지 않음 |
| 살무 / 예복 착용 | “앉을 수는 있어?” | 의자 한 개를 뒤로 뺌. 변신을 해설하지 않음 |

| 옴 / 공연 초대 제시 | “끝나면 밥은?” | 초대장을 돌려줌. 공연 강행 선택 자동 입력 없음 |
| 지르 / 식사 운반 요청 전달 | “여긴 남은 게 없어.” | 실제 여관 재고 있을 때는 “이것만.” 후 제시량을 선택하게 함 |
| 안느 / 실제 동행 | “그 옷, 문에 걸려.” | 출입을 위한 옷단 손짓. 신분 찬양 없음 |
| 페른 / 학생 작품 제시 | “말리는 중이야?” | 젖은 천으로 오해. 미확인 교사 악행을 소하가 폭로하지 않음 |

| 차라 / 송풍 정지 확인 | “또 냄새 올라와.” | 식당 창의 끈을 풀려다 멈춤. 환기 결과는 H0/C4 담당 |

소식 반복은 새 물건이나 사실 변화 없으면 한 번만. 전원이 죽었을 때 순서대로 추모 메뉴를 만들지 않는다.

## 7. 생존·사망·부재의 후속

### 7.1 귀환자 공격

필수 원인은 `귀환자 굶주림 말기`와 `1–4호 전체 문 개방`, 그리고 `소하가 식당에 실제 있음`의 결합이다([지도 §3.1](../00_MAP_AND_AUTHORING.md) 공격 진행 조건). 친밀도, 서약, 플레이어 성별은 판정 입력이 아니다. 문을 열 때 식당이 차고, 빈 접시를 향하던 손이 소하 팔로 옮겨가는 전조가 먼저 보인다. H0 담당은 이를 임의 실시간 QTE로 만들지 않는다. 판정은 지도 §3.1의 결과 1(K12 승리→`wounded`), 결과 2(SH-LURE 유인점 성공→`alive`), 결과 3(플레이어가 H0를 벗어남·밖에서 재개·밖에 있을 때 진행이 참→`dead`, 원인: 귀환자), '결과 없음'(K12 패배·플레이어 사망→조우 상태만 되돌리고 소하 상태를 쓰지 않음)을 그대로 따른다.

| 결과 | 소하 | 남는 생활 기능 | 영구 상실 |
|---|---|---|---|
| 공격 전 분리·이주 | alive | 식사·열쇠·침상 | 사건 선택에 따라 방의 손님만 바뀜 |
| 결과 2 유인점 성공 | alive | 식사·열쇠·침상 | 없음. 귀환자 굶주림 한 단계 하강, 공격 진행 해제 |
| 결과 1 K12 승리 후 구조 | wounded | 침상, 보유 열쇠; 식사는 다른 손으로 천천히 | 정상 양손 포즈, 사적인 마당 장면은 회복 사건 전 닫힘 |
| 결과 3 H0 이탈·방치 | dead | 침상, 떨어진 물리 열쇠, 남은 물건 조사 | 소하 식사 서비스·개인 대사·연애 장면 |
| 소하 직접 살해(SH-STRIKE) | dead | 위와 동일 | 별도 사망 원인 기록. 귀환자가 죽인 것으로 위조하지 않음 |
| 결과 없음(K12 패배·플레이어 사망) | (미확정) | — | 공격 진행은 남고 소하 상태를 쓰지 않음([08](../../08_SAVE_DEATH_AND_RECOVERY.md) §5.1대로 조우 상태만 복귀) |

시체 조사 문구는 “앞치마 안쪽에 열쇠가 걸렸다.” 한 페이지. `열쇠를 뺀다 / 그대로 둔다`. 살점 해설문 대신 열쇠를 빼면 소매가 함께 들렸다가 떨어지는 물리 연출. 보유 열쇠가 이미 플레이어에게 있으면 빈 주머니와 찢긴 안감만. 같은 열쇠 무한 획득 금지.

사망 후 1차 재방문: 씻지 않은 접시가 남고 물이 흐른다. 물 잠그기 가능. 2차는 정해진 배급 사건을 한 번 더 통과한 뒤: 귀환자 생존이면 빈 접시가 복도 밖으로 밀려나옴, 모두 부재면 마지막 놓은 위치 유지. 시간 경과만으로 시체가 사라지거나 서비스 NPC가 대체 등장하지 않는다. 시체 이동은 H0 담당의 이동 가능 범위에서만. 유품을 주워 소하가 귀신으로 정답을 말하는 경로 없음.

### 7.2 부재와 인수

단순 마당 동행은 조건부 부재: 소하 앵커만 이동, 서비스 호출은 그 위치에서 가능 여부를 읽는다. 영구 가출은 v0.1에 없으므로 임의 추가하지 않는다. 여관 인수 결말은 소하 생존이면 소하가 접시 두 장을 내려놓고 “밑에 하나 더.”, 사망이면 플레이어가 스스로 두 장을 포개 든다. 인수를 위해 모든 귀환자를 살리거나 소하와 연애해야 한다는 조건을 붙이지 않는다. 정확한 결말 접근은 World E를 따른다.

## 8. 제작 전말과 실제로 없애는 것

확정 제작 사실(World §12 정본): 한 달 전 5호 귀환자가 문틈으로 소하의 손목을 잡아 끌어당긴 뒤, 소하는 문 앞 팔 길이 안에 들어가지 못한다(D01). 그동안 문틈에 접시를 넣던 도엘이 19일 전 다리를 잃고 발을 소하에게 맡겼다. 같은 밤 소하는 오른발 없이 떠밀려 온 플레이어에게 그 발을 붙였다. 무연에게 배운 대로 받는 몸의 머리카락과 꿰는 자기 머리카락을 한 가닥씩 꼬아 꿰맸다. 이유는 문틈에 접시를 넣을 손이 필요해서였고, 그 발은 집에 있던 유일한 성한 발이었으며, 도엘에게는 알리지 않았다(D01). 전날 발을 찾으러 온 도엘에게 소하는 대답 대신 물을 틀고 늘 하던 대로 “빈 방이야”라고 했고, 도엘은 한 달 전부터 잠기지 않은 5호를 열었다. 5호의 같은 귀환자 몸 셋이 그를 세척 구덩이에 눕히고 의족 끈을 배수 추 걸쇠에 묶었다. 소하는 두드림을 들었지만 문을 열지 못한다(D02). 그녀가 감금 장치를 설계했거나 귀환자를 창조했다고 추가하지 않는다. 배수 추 걸쇠의 기계 구조는 소하가 모른다.

D01 이유(접시 넣을 손이 필요했다는 사정)와 “빈 방이야”가 도엘을 5호로 보낸 일(D02)은 소하 대사로 설명하지 않는다(never_explains). D01 이유 장부 하단은 실제 텍스트 자산에 포함하지 않는다. 물에 풀린 영역을 복원하면 읽히는 숨은 글자로 남기지 않는다(World §17 D01: 남는 조각은 `오른쪽. 발목 아래.` / `실 두 가닥을 같이` / `구두는 버리지`뿐이다). D02 붙잡는 장면은 회상·기록·꿈으로 복원하지 않는다. 플레이어에게 남는 것은 끈, 문 너머 두드림, 같은 매듭, 두 접시, 소하의 회피와 실제 구조 결과다. 완전한 제작 인과를 앞으로 보강하더라도 이 삭제 원칙은 유지한다.

## 9.5 지도 §5 8·9항 자체 표시 (v0.2)

- 8항(직업·비밀을 지워도 남는 개인 장면 둘, 하나 이상이 관계·사건을 실제로 바꿈): 이미 있음. **SH-D07(자기 그릇)** — 여관 주인이라는 직업과 귀환자를 숨긴 비밀을 지워도, 남에게 자기 그릇을 못 씻게 하고 바닥을 긁어 먹는 장면이 남는다. 이 장면의 성립이 관계를 Q2로 올린다(관계 이동함). **SH-D08(마당 돌)** — 앉던 돌의 좁은 쪽으로 몸을 옮기고 젖은 손을 바지에 닦는 장면. 수락이 확인되면 Q3로 이동(관계 이동함). 둘 다 무작위 기벽이 아니라 소하의 물·그릇·젖음이라는 몸에 붙어 있다.
- 9항(반복 서비스가 인물을 소모시키는가): **없음.** SH-MEAL·SH-REST·SH-WASH를 반복해도 소하의 수명·상태를 앞당기지 않는다. 소하의 위험은 반복 서비스가 아니라 귀환자 굶주림 말기+1–4호 전체 개방+식당 체류라는 별도 물질 조건에서만 온다(§7.1, [지도 §3.1](../00_MAP_AND_AUTHORING.md)). 반복 말걸기·재방문·실시간 대기는 어떤 시계도 올리지 않는다.

## 10. 통합 요청과 미납품

1. H0: §3의 앵커 및 접시/열쇠/물통의 소유 이전·문 앞 운반 지점을 배치한다. NPC 본체와 끈/문이 같은 상호작용 반경에 겹치지 않게 한다. 전체 문 개방은 객실 문인지 외부 통로인지 명시해야 한다. 외부 다섯 출구 개방으로 오판하면 안 된다.
2. H0/K12: 굶주림 말기의 사건 수치, 공격 발생 평가 시점, 플레이어 개입과 방치의 확정 조건, 안전 유인점·분리 경로의 유효성을 확정한다. 본문 대사만 보고 조작 가능하다고 구현 완료 처리하지 않는다.
3. N12 담당: 소하 수건 요청, 끈 먼저/발 먼저 결과, 구조 직후 실제 위치, 거짓 보고 반증 전달을 연결한다. 도엘 대사는 N12가 소유한다.
4. N02/N13/N03/N07: 실제 자원 공급·식사·봉합·운반의 입력/출력은 공통 C0/C1/C2와 연결한다. 소하가 대화 중 다른 NPC의 사망/이주를 확정하지 않는다.
5. root: 04 관계 그래프 모순은 [지도 §3.2](../00_MAP_AND_AUTHORING.md)가 상위 해석으로 잠갔고 이 파일이 그것을 따랐다(N01-5 반영). 남은 것은 새 관계/대화 stable ID·06 스키마 바인딩(Q6·Q7 `exclusions.max_final_state` 확인 포함)과 D01 제작 이유의 정본 보강이다. 해당 바인딩과 전체 캐릭터 비교는 미납품이다.
6. 표현: A만 참조, 소하 정체성·옷·색은 A 인물과 복제하지 않는다. 지면 하향 60도 현장 크기, 정면 대화 초상, 부상/사망/접시 운반 분리 자산이 필요하나 이미지 brief와 실제 자산은 아직 작성하지 않았다.

문서 자체 확인 과제: 최초 만남→배급 거절→첫 외출→도엘 생존 구조→접시 씻기→마당→동일한 애정 상태에서 소하 사망을 추적한다. 별도 경로로 도엘 먼저 사망·소하 Q4·식량 없음·열쇠 이미 획득·소하 직접 공격·결말 E 빈 여관을 확인한다. 이 과제는 플레이 완료 기록이 아니다.

## 연결 요청 (다른 파일 소유자에게)

이 파일에서 확정했으나 다른 소유 파일의 변경이 필요한 것들. 나(N01 담당)는 이 파일만 고쳤고 아래는 직접 손대지 않았다.

1. **H0 담당 (H0-6)**: SH-LURE가 참조할 식당 밖 유인점 좌표와 식당 안 공격 앵커 좌표가 아직 없다. H0가 v0.2에서 이 두 좌표를 정하면 SH-LURE와 §3 '공격 직전' 행을 그 좌표로 확정한다. 그전까지 두 곳은 '미확정'으로 둔다.
2. **06 스키마 담당**: Q6(함께 살림)·Q7(적대)이 둘 다 끝 상태다. 06 바인딩 때 `exclusions.max_final_state`가 1이면 둘 중 하나를 끝 상태에서 빼야 한다. 어느 쪽을 끝 상태로 유지할지 결정을 요청한다(권고: Q7 적대를 끝 상태로 유지, Q6은 결말 E 분기로 흡수).
3. **root (World §12)**: D01의 '왜 이식했는가' 제작 이유는 World §12가 정본이고 이미 채워져 있다. 추가 보강이 생기면 N01의 §8·knows를 대사가 아닌 제작 사실로만 맞춘다(never_explains 유지).

사용자 결정이 필요한 항목: 위 2번의 max_final_state 처리(Q6/Q7 중 어느 쪽을 최종 상태로 둘지)만 사용자 취향이 갈릴 수 있다. 아래 보고 본문의 번호 1번으로 물었다.
