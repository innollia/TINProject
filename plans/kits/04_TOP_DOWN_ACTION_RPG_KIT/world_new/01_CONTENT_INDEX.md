# 새 세계 상세 집필 인덱스

2026-09-26. 상태는 파일의 실제 납품과 통합 검수로 갱신한다. World의 인물표/지역표 한 행은 상세 집필 완료가 아니다. [지도·플로우 정본](00_MAP_AND_AUTHORING.md), [전체 World](../15_NEW_WORLD.md), [독립 검토](REVISION_REVIEW.md)를 먼저 읽는다.

## 소유권

통합 담당은 지도·사건 간 계약·사용자 결정과 이 인덱스를 소유한다. 각 상세 파일은 한 지역 또는 한 인물의 독립 담당이 소유한다. 작성 중인 타인 파일에 직접 수정하지 않는다. 통합 후 변경이 필요하면 변경 구간과 새 계약 버전을 전달한다.

## 납품 판정

- `집필 중`: 담당이 쓰는 중. root 미검수.
- `초안 납품`: 실제 파일 존재. 공통 계약과 인물/지역 경계를 검수해야 함.
- `수정 필요`: 구체 충돌·반복·미작성 필드가 있음.
- `통합 검토본`: 문서 간 연결을 대조한 상태. 사용자 내용 승인·구현·이미지·플레이 검증과 별개.

첫 지역/인물의 통합 검토 전에 다른 21개 상세를 자동 양산하지 않는다. 이는 전체 분량을 줄이는 결정이 아니다. 공통 입력의 오류를 먼저 수정하는 작성 순서다.
