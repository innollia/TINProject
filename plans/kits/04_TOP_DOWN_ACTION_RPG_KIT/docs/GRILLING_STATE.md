# RPG 콘텐츠 재기획 인터뷰

상태: ACTIVE — 사용자 전체 합의 확인 전. 기존 Kit를 제작 도구로 사용하며 새 콘텐츠를 기획한다. 코드 재사용 범위 조사·Kit 재구축은 이 인터뷰의 작업이 아니다.

## Settled — 2026-09-26

- Primary Reference는 BLACK SOULS 2. 불쾌함의 핵심은 역겨움이다. 레퍼런스로 확인할 수 있는 성질을 사용자에게 취향 선택지로 되묻지 않는다.
- 세계관·역사·사건의 인과는 제작용 정본에서 먼저 완성한다. 게임에는 세계관을 해설하지 않는다. 공간·사물·인물의 행동과 상호작용으로 경험하게 한다.
- 제작 후 게임 속 문서를 썩히고 대사를 자르고 맵 일부를 도려낸다. 단순히 설명 공개 시점을 늦추는 것이 아니다. 영구히 소실된 맥락과 이해 불가능한 부분을 허용한다. 제작 정본은 보존한다.
- 위 전달 방식은 사용자가 지정한 다크소울 스타일 적용점이다. 별도 Primary Reference로 추가하지 않는다.
- 애정·로맨스가 있어도 실수하면 상대가 죽을 수 있다. 관계 진행도에 의한 생존 보장이나 자동 구제는 없다. 구체 사망 조건은 원작 사례 조사 후 사건별로 설계하며 전원 사망을 강제하지 않는다.
- 앞선 확정 유지: 앨리스 제외, explicit sexual content 제외, romance/affection 유지, body horror 허용. 60도 탑다운과 기존 공통 화풍 기준은 이번 답변으로 변경하지 않는다.
- 기존 세계·인물·사건 초안은 사용자 콘텐츠 검수 완료가 아니다. 기존 구현의 존재를 새 콘텐츠의 승인으로 간주하지 않는다.

## Rejected

- 불쾌함을 에이전트가 임의로 순화하거나 윤리 문제를 해설하는 장치로만 사용하기.
- 모든 세계관 정보를 결국 해설하거나 모든 단서로 전모를 복원 가능하게 하기.
- 애정 관계를 안전한 별도 시스템으로 보호하기.
- 콘텐츠 재기획을 코드 결합도·재사용 범위 조사로 확대하기.

## Current Frontier

2026-09-26 추가 사용자 결정: 새 world 문서 실제 작성 착수. 기존 RPG 문서의 메타 계약은 엄격히 따르며 옛 세계의 구체 내용은 계승하지 않는다. 메모 활용 조건과 마법 규칙 모두 유지. 새 내용의 전체 검토 완료를 의미하지 않는다.

제작 순서는 큰 지도와 지점 배치 → 지점별 구체화이며, 지역/인물 병렬 집필에 앞서 복잡한 상호작용 연결과 플로우차트를 고정한다. 각 지역은 독립 서브에이전트가 전체 정보에 책임지고, 각 캐릭터는 한 독립 서브에이전트가 외형·대사·상호작용 전체에 책임진다. 전형적 상황과 '이상해 보이려고 하는 전형성' 모두 금지한다. 뒤틀림의 제작 규칙과 반복 탈락 기준을 문서에 둔다.

- 레퍼런스 조사: 역겨움을 만드는 실제 장면, 일상 행동과 잔혹한 결과의 접속, 관계 상대의 사망·적대 조건을 구체 사례로 정리한다. 사용자에게 다시 선택시키지 않는다.
- 이후 사용자 검토 대상: 새 콘텐츠의 구체적인 인물·행동·사건. 기존 추상적 세계 설명을 승인받는 방식으로 돌아가지 않는다. 현재 전체 콘텐츠 설계에 대한 shared understanding은 미확정이다.
